## 6.1 仿真输出分析的涵义（课件第 2—6 页）

### 6.1.1 为什么仿真结束后还需要统计分析

仿真运行可以给出某个系统的等待时间、产量、设备利用率或其他性能指标。但模型含有随机输入时，同一模型即使参数完全相同，换一组随机数后也可能得到不同结果。例如，某次仿真得到的平均等待时间只是这次随机运行的结果，并不天然等于系统真正的长期平均等待时间。

仿真输出分析要做的事，是利用运行产生的样本数据，估计系统的性能测度。课件重点讨论总体均值，也就是随机输出变量 `X` 的期望 `E(X)`。因此，必须区分三个量：

| 记号 | 含义 | 是否已知 |
| --- | --- | --- |
| `X` | 一次运行或一次观测对应的随机输出变量 | 分布通常未知 |
| `E(X)` 或 `μ` | 希望了解的总体均值 | 待估计 |
| `X̄` | 由已经获得的数据计算的样本均值 | 可以计算 |

课件第 2 页提出的“结果可信吗”“数据怎样生成”“能否反映实际情况”等问题，是对仿真分析可靠性的要求。本讲处理其中的统计问题：在给定模型和输入的前提下，怎样从随机结果中估计性能指标，并说明估计有多大不确定性。

### 6.1.2 独立同分布样本的均值与置信区间

先考虑经典统计情形：已经得到 `n` 个独立同分布观测值 `X₁,…,Xₙ`，用样本均值估计总体均值。

```math
\overline X_n=\frac{1}{n}\sum_{i=1}^{n}X_i
```

用样本方差估计单个观测值的方差：

```math
S^2=\frac{1}{n-1}\sum_{i=1}^{n}(X_i-\overline X_n)^2,
\qquad S=\sqrt{S^2}
```

样本均值的标准误为 `S/√n`。总体正态且方差未知时，下面的双侧 `t` 区间是精确的；若总体并非正态，样本量足够大时可将它作为近似区间。

```math
\boxed{
\overline X_n\pm
t_{1-\alpha/2}(n-1)\frac{S}{\sqrt n}
}
```

这里，`1−α` 是置信水平，例如 95% 对应 `α=0.05`；`t₁₋α/2(n−1)` 是自由度为 `n−1` 的 `t` 分布分位数。区间中心是样本均值，半长等于临界值乘以标准误。

这一公式不能不加区分地直接套到一次仿真中连续记录的所有数据上，因为相邻仿真输出往往存在自相关。例如，上一位顾客等候较久时，后续顾客也可能继续受到拥堵影响。课件后面采用独立重复运行或批平均的方法，目的之一就是处理这个问题。

### 6.1.3 终态仿真与稳态仿真

课件将仿真区分为两类。选择哪种统计方法，首先取决于研究的是哪一类仿真。

| 比较内容 | 终态仿真（Terminating Simulation） | 稳态仿真（Steady-State Simulation） |
| --- | --- | --- |
| 时间范围 | 有限时段 `[0,T_E]` | 关注仿真时间趋于无穷时的长期行为 |
| 是否存在明确终止条件 | 有，如一天结束或完成指定任务 | 通常不以某个自然终止事件定义研究对象 |
| 初始状态的影响 | 是研究结果的一部分，可能始终存在 | 理论上的长期稳态不依赖初始状态 |
| 输出分析的主要问题 | 用独立重复运行估计有限时段性能 | 同时处理初始瞬态与输出自相关 |

终态仿真并不是指“程序运行一段时间以后停止”这么简单。重点在于要研究的对象本来就有明确的有限结束条件。稳态仿真虽然实际也会在某个时刻停止计算，但其目标是估计长期运行的性能。

## 6.2 终态仿真输出分析（课件第 7—14 页）

### 6.2.1 独立重复运行的基本思路

用同样的初始条件与终止事件运行模型多次，每次采用不同且相互独立的随机数流。每一次运行称为一次独立重复（replication）。

这里有两个层次的数据，需要特别区分。

第一层是在同一次运行中收集的 `m` 个观测值。它们可能存在时间相关性，并不能仅因为记录了 `m` 个数就当作 `m` 个独立样本。

第二层是 `R` 次独立运行分别产生的 `R` 个运行均值。只要重复运行的设置一致、随机数流独立，这些运行均值就可以作为相互独立、同分布的统计样本。课件正是使用第二层样本构造置信区间。

### 6.2.2 固定样本量法：从原始输出到区间估计

假设共进行 `R≥2` 次独立重复，每次记录 `m` 个输出。用 `Xᵣᵢ` 表示第 `r` 次运行中的第 `i` 个观测值，其中 `r=1,…,R`、`i=1,…,m`。

第一步，计算每次运行的平均输出：

```math
\overline X_r=\frac{1}{m}\sum_{i=1}^{m}X_{ri},
\qquad r=1,2,\ldots,R
```

第二步，以 `R` 个运行均值为样本，计算总平均：

```math
\overline X
=\frac{1}{R}\sum_{r=1}^{R}\overline X_r
=\frac{1}{mR}\sum_{r=1}^{R}\sum_{i=1}^{m}X_{ri}
```

第三步，计算运行均值之间的样本方差：

```math
S^2=\frac{1}{R-1}
\sum_{r=1}^{R}(\overline X_r-\overline X)^2
```

这个 `S²` 衡量不同独立运行的均值有多分散，并不是把 `mR` 个原始观测直接混在一起求出的样本方差。

第四步，利用 `R` 个独立运行均值构造总体均值的置信区间：

```math
\boxed{
\overline X\pm
t_{1-\alpha/2}(R-1)\frac{S}{\sqrt R}
}
```

公式中的自由度是 `R−1`，标准误分母是 `√R`，不是 `√(mR)`。当单次运行的观测数量 `m` 足够大时，运行均值通常可以根据中心极限定理近似为正态变量，从而使用上述 `t` 区间。

### 6.2.3 课件例题：10 次重复运行的 90% 与 95% 置信区间

课件第 11 页给出以下汇总数据：

```math
R=10,\qquad \overline X=0.343,
\qquad S^2=0.167
```

首先由方差求标准差，再求平均值的标准误：

```math
S=\sqrt{0.167}\approx0.4087,
\qquad
\frac{S}{\sqrt{10}}\approx0.1292
```

计算 90% 置信区间时，`α=0.10`，自由度 `R−1=9`，查表得到 `t₀.₉₅(9)≈1.833`。

```math
\begin{aligned}
h_{90\%}&=1.833\times0.1292\approx0.237\\
CI_{90\%}&=0.343\pm0.237\\
&=\boxed{(0.106,\ 0.580)}
\end{aligned}
```

计算 95% 置信区间时，`α=0.05`，查表得到 `t₀.₉₇₅(9)≈2.262`。

```math
\begin{aligned}
h_{95\%}&=2.262\times0.1292\approx0.292\\
CI_{95\%}&=0.343\pm0.292\\
&=\boxed{(0.051,\ 0.635)}
\end{aligned}
```

两个区间都以 0.343 为中心；95% 置信区间比 90% 置信区间更宽，因为要求更高的覆盖水平时需要更大的临界值。这也说明，置信水平与估计精度不能孤立讨论。

### 6.2.4 规定绝对精度时，如何确定重复次数

固定样本量法先指定重复次数 `R`，再计算得到的区间半长。但在实际仿真实验中，常常先规定可接受误差，例如要求置信区间的半长不超过某个数 `β`。

课件将 `β` 称为绝对精度。相应的置信区间半长为：

```math
h(R)=t_{1-\alpha/2}(R-1)\frac{S}{\sqrt R}
```

希望达到的要求是 `h(R)≤β`。课件用下面的试算法确定重复次数。

第一步，先进行 `R₀=4～5` 次独立运行，计算其运行均值的标准差 `S₀` 和初始区间半长：

```math
\beta_0=t_{1-\alpha/2}(R_0-1)
\frac{S_0}{\sqrt{R_0}}
```

第二步，如果 `β₀≤β`，说明已经满足设定的区间半长要求。如果 `β₀>β`，则暂时用先导实验的 `S₀` 估算所需运行次数：

```math
\boxed{
R^*(\beta)=\min\left\{
i\geq R_0:\quad
t_{1-\alpha/2}(i-1)\frac{S_0}{\sqrt i}\leq\beta
\right\}}
```

这个表达式的含义是：从 `i=R₀` 起逐个尝试更大的整数运行次数，在固定先导标准差 `S₀` 的条件下，找到首个满足半长要求的 `i`。由于 `t` 临界值也随自由度变化，课件采用“试算”而不是只代一个固定常数。

第三步，补做的独立重复次数为：

```math
\Delta R=R^*(\beta)-R_0
```

补充运行后，应根据已经收集的全部运行均值重新计算实际的样本标准差与置信区间半长。这里的 `R*` 是基于先导标准差制定的运行计划，不是对最终半长的无条件保证。

## 6.3 稳态仿真输出分析（课件第 15—26 页）

### 6.3.1 稳态输出为什么有两个统计难点

稳态仿真关注长期行为。初始状态本来不应该决定长期性能，但模拟一开始通常需要人为设定初始条件，例如把排队系统设为空系统。如果直接把刚开始的输出与后面接近稳态的输出混合，可能使长期均值估计产生初始瞬态偏差。

因此，稳态输出分析需要处理两个不同的问题：

其一是初始瞬态问题（initial transient）：仿真开始时的系统尚未进入它的长期运行状态。

其二是自相关问题（autocorrelation）：即使系统进入稳态，按时间顺序记录的相邻输出也未必相互独立。

删除初始数据主要针对第一个问题；独立重复或构造批均值则有助于处理第二个问题。

### 6.3.2 删除初始观测值

假设一次运行记录了 `m` 个输出 `X₁,…,Xₘ`，决定删除前 `l` 个输出。剩下的数据均值为：

```math
\boxed{
\overline X(m,l)=\frac{1}{m-l}
\sum_{i=l+1}^{m}X_i
},\qquad 0\leq l<m
```

例如，`l` 是预热阶段末尾所对应的观测编号。这里的 `l` 表示删除多少个观测值，而不是必然等于某个时间长度；如果记录的是不等间隔事件输出，观测个数与经过的时间不能混为一谈。

问题在于：`l` 不能随意指定。删得太少，初始偏差可能仍存在；删得过多，又会白白损失仿真数据。课件采用图形法确定一个合理的截断位置。

### 6.3.3 图形法：重复运行、跨运行平均、再平滑

课件第 17—18 页的图形法共有四步。

第一步，进行 `n>4` 次独立重复仿真，每次收集 `m` 个按相同顺序定义的观测值。记 `Xᵢⱼ` 为第 `i` 次运行中的第 `j` 个观测值。

第二步，对同一观测编号 `j`，先在不同运行之间取平均：

```math
\overline X_j=\frac{1}{n}\sum_{i=1}^{n}X_{ij},
\qquad j=1,2,\ldots,m
```

这是为了抵消单次随机运行的偶然波动，从而更清楚地观察系统的平均变化趋势。注意，这里是“固定 `j`、跨不同运行求平均”，不是把一次运行里所有时刻直接平均。

第三步，对得到的序列再进行移动平均平滑。设平滑窗口向左右各延伸 `ω` 个观测位置，课件给出的处理方式为：

```math
\overline X_j^{(\omega)}=
\begin{cases}
\displaystyle\frac{1}{2j-1}
\sum_{s=-(j-1)}^{j-1}\overline X_{j+s},
&j=1,\ldots,\omega,\\[8pt]
\displaystyle\frac{1}{2\omega+1}
\sum_{s=-\omega}^{\omega}\overline X_{j+s},
&j=\omega+1,\ldots,m-\omega.
\end{cases}
```

在序列开头，左右两侧没有足够的观测值，因此使用较短的对称窗口；进入中间部分后使用固定长度 `2ω+1` 的窗口。平滑是为了看清趋势，不是用来改变原始观测的定义。

第四步，绘制 `X̄ⱼ^(ω)` 随 `j` 变化的轨迹，寻找曲线不再呈现明显初始过渡趋势的区域，选取相应的删除长度 `l`。课件使用的是图形判断，没有给出一个适用于所有系统的统一数值公式。

### 6.3.4 重复—删除法（Replication–Deletion）

这是一种将“独立重复运行”与“删除初始阶段”结合起来的方法。

进行 `n` 次独立重复仿真，每次得到 `m` 个观测值。在每次运行中都删除前 `l` 个，再分别计算保留数据的均值：

```math
\overline X_i(m,l)=\frac{1}{m-l}
\sum_{j=l+1}^{m}X_{ij},
\qquad i=1,2,\ldots,n
```

这样得到 `n` 个运行均值：

```math
\overline X_1(m,l),\ \overline X_2(m,l),\
\ldots,\ \overline X_n(m,l)
```

由于各次运行独立，可以把这些运行均值看作近似独立同分布的样本；当保留样本量足够大时，可使用正态近似与 `t` 区间。

设这 `n` 个运行均值的总平均和样本方差分别为：

```math
\begin{aligned}
\overline X_{RD}&=\frac{1}{n}\sum_{i=1}^{n}\overline X_i(m,l),\\
S_{RD}^2&=\frac{1}{n-1}
\sum_{i=1}^{n}\bigl(\overline X_i(m,l)-\overline X_{RD}\bigr)^2.
\end{aligned}
```

那么总体均值的近似置信区间是：

```math
\boxed{
\overline X_{RD}\pm
t_{1-\alpha/2}(n-1)\frac{S_{RD}}{\sqrt n}
}
```

课件第 21 页列出这种方法的两个缺点：每次独立运行都要重新删除前 `l` 个值，导致数据使用效率偏低；为了按次收集各次运行结果，需要对仿真过程进行重复启动与停止。

### 6.3.5 批平均值法（Batch Means）

重复—删除法使用多次独立运行。批平均值法改为只进行一次足够长的仿真，把一个长序列划分为若干批次，再分析各批的平均值。

课件首先引入协方差平稳过程的三个条件。设进入稳态后的输出为 `X₁,X₂,…`，则：

```math
\begin{aligned}
E(X_i)&=\mu,\qquad i=1,2,\ldots,\\
\operatorname{Var}(X_i)&=\sigma^2,\qquad i=1,2,\ldots,\\
\operatorname{Cov}(X_i,X_{i+j})&=C_j,\qquad i=1,2,\ldots
\end{aligned}
```

第一个条件表示均值不随观测位置改变；第二个表示方差不随观测位置改变；第三个表示两个输出之间的协方差只与它们相隔多少个观测位置有关，而不取决于它们具体发生在序列的哪个位置。协方差平稳不意味着原始相邻输出是独立的。

按照课件第 24—25 页，假设已经保留了 `m=nb` 个稳态观测，将其分成 `n` 批，每批 `b` 个。第 `i` 批平均值为：

```math
\boxed{
\overline X_i(b)=\frac{1}{b}
\sum_{j=1}^{b}X_{(i-1)b+j}
},\qquad i=1,2,\ldots,n
```

全部批均值的平均为：

```math
\overline X(n,b)=\frac{1}{n}
\sum_{i=1}^{n}\overline X_i(b)
```

各批均值之间的样本方差为：

```math
S_b^2=\frac{1}{n-1}
\sum_{i=1}^{n}
\bigl(\overline X_i(b)-\overline X(n,b)\bigr)^2
```

当每批长度 `b` 足够大，批均值之间的相关性可以忽略且其分布近似正态时，可以使用：

```math
\boxed{
\overline X(n,b)\pm
t_{1-\alpha/2}(n-1)\frac{S_b}{\sqrt n}
}
```

这里再次强调：自由度是批次数 `n` 减 1，而不是原始观测数 `m` 减 1。批平均法的基本思路是以批为统计单位，不能把所有原始相关观测直接当作独立样本。

### 6.3.6 预热删除、优点与难点

课件第 26 页特别说明：即使使用批平均值法，仍应先删除初始的 `l` 个观测值。正确的顺序是先剔除初始瞬态，再将后续长序列划分为批次。

与重复—删除法比较，批平均值法只需在一次长运行中删除一次初始数据，因而通常更节省输出数据。课件将其优点概括为数据使用效率较高、能够得到较精确的置信区间；但这些效果仍依赖于合理选择批长和批次数。

课件指出的实际困难是确定 `n` 和 `b`。`b` 太小，批均值仍可能明显相关；`n` 太少，估计样本方差和计算 `t` 区间时的信息量不足。因此不能只要求把运行时间拉长，还需要考虑如何分批。

## 6.4 方差衰减技术（课件第 27—38 页）

### 6.4.1 方差衰减的目的

仿真输出具有随机性。对同一个估计目标，输出估计量的方差越大，重复仿真得到的结果越分散，相应置信区间通常也越宽。方差衰减技术的目的，是通过设计随机输入或调整估计量，在不改变所估计总体均值的前提下减小估计方差。

本节课件讨论三种方法：公共随机数法、对偶变量法、控制变量法。前两种主要通过安排随机输入之间的关系来发挥作用；控制变量法则利用另一个具有已知期望的随机变量来校正输出。

### 6.4.2 公共随机数法（Common Random Numbers）

公共随机数法主要用于比较两个不同系统模型。例如，同一服务系统在原有规则与改进规则下的平均等待时间是否不同。

设模型 1 的输出为 `X₁`，模型 2 的输出为 `X₂`，希望估计二者总体均值之差：

```math
\mu=E(X_1)-E(X_2)
```

分别运行 `n` 次，令第 `i` 次配对运行的输出为 `X₁ᵢ` 与 `X₂ᵢ`。先计算每一对结果的差：

```math
Z_i=X_{1i}-X_{2i},\qquad
\overline Z_n=\frac{1}{n}\sum_{i=1}^{n}Z_i
```

由期望的线性性质，可以验证差值均值是目标差异的无偏估计：

```math
E(\overline Z_n)=E(X_1)-E(X_2)=\mu
```

两个随机变量相减的方差满足：

```math
\operatorname{Var}(Z_i)
=\operatorname{Var}(X_{1i})
+\operatorname{Var}(X_{2i})
-2\operatorname{Cov}(X_{1i},X_{2i})
```

如果不同配对之间相互独立，则：

```math
\operatorname{Var}(\overline Z_n)
=\frac{1}{n^2}\sum_{i=1}^{n}
\left[
\operatorname{Var}(X_{1i})
+\operatorname{Var}(X_{2i})
-2\operatorname{Cov}(X_{1i},X_{2i})
\right]
```

这个公式是理解公共随机数法的关键。两个模型使用相同随机输入后，如果相应输出呈正相关，协方差项为正，而公式中要减去两倍协方差，差值估计量的方差便会下降。

实施时，对两个系统中具有相同含义的随机输入使用相同的随机数发生器与种子值，使两种系统面对尽量一致的随机环境。例如，比较两种排队规则时，让它们使用同一组到达与服务随机情景。需要注意，方差下降取决于实际产生的输出相关性；如果配对后相关性为负，效果可能相反。

### 6.4.3 对偶变量法（Antithetic Variates）

对偶变量法主要用于估计同一个系统模型的性能。它不比较两个不同模型，而是构造两次相互关联的运行，使结果相互抵消一部分随机波动。

课件的做法是：第一次运行使用均匀随机数 `uₖ` 生成输入，第二次运行使用互补随机数 `1−uₖ` 生成相应输入，形成一对结果。

进行 `n` 对仿真。第 `i` 对得到 `Xᵢ^(1)` 和 `Xᵢ^(2)`，取这一对的平均：

```math
X_i=\frac{X_i^{(1)}+X_i^{(2)}}{2}
```

再对 `n` 个配对均值求总平均：

```math
\overline X_n=\frac{1}{n}\sum_{i=1}^{n}X_i
```

如果两次运行分别具有相同的目标均值 `μ`，那么：

```math
E(\overline X_n)=\mu
```

假设不同配对之间相互独立，配对均值的方差是：

```math
\operatorname{Var}(\overline X_n)
=\frac{1}{4n^2}\sum_{i=1}^{n}
\left[
\operatorname{Var}(X_i^{(1)})
+\operatorname{Var}(X_i^{(2)})
+2\operatorname{Cov}(X_i^{(1)},X_i^{(2)})
\right]
```

这里协方差项前面是加号，与公共随机数法的减号不同。因此，对偶变量法希望同一对的两个输出负相关，让两个结果的波动相互抵消。

课件用互补随机数实现这种设计。若输出随输入呈相应的单调变化，`u` 与 `1−u` 通常有助于形成负相关的输出；不过，并非所有复杂仿真模型都能保证两个最终输出必然负相关，因此是否有效应以实际方差为准。

### 6.4.4 控制变量法（Control Variates）

控制变量法同样用于估计同一个系统的总体均值。与前两种方法不同，它需要找到另一个和输出相关、且总体期望已知的随机变量。

假设目标输出为 `X`，要估计 `μ=E(X)`。另有随机变量 `Y` 与 `X` 相关，并且 `E(Y)=ν` 已知。构造新的估计量：

```math
\boxed{X_c=X-a(Y-\nu)}
```

其中 `a` 为待选择的常数。因为 `E(Y−ν)=0`，所以：

```math
\begin{aligned}
E(X_c)&=E[X-a(Y-\nu)]\\
&=E(X)-a\bigl(E(Y)-\nu\bigr)\\
&=\boxed{\mu}
\end{aligned}
```

这说明控制变量调整不会改变目标总体均值。它改变的是估计量的方差：

```math
\operatorname{Var}(X_c)
=\operatorname{Var}(X)
+a^2\operatorname{Var}(Y)
-2a\operatorname{Cov}(X,Y)
```

为了使方差最小，可对 `a` 求导并令其等于零：

```math
\begin{aligned}
\frac{\mathrm d\operatorname{Var}(X_c)}{\mathrm da}
&=2a\operatorname{Var}(Y)-2\operatorname{Cov}(X,Y)=0\\
a^*&=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(Y)}
\end{aligned}
```

将这个最优系数代回方差公式，可以得到课件给出的最小方差表达式：

```math
\boxed{
\operatorname{Var}(X_c)
=\operatorname{Var}(X)
-\frac{\operatorname{Cov}(X,Y)^2}{\operatorname{Var}(Y)}
}
```

只有当 `X` 与 `Y` 存在非零相关性时，这个理想的方差减少量才为正；相关性越强，可减少的部分通常越大。如果 `Var(Y)=0`，上面的最优系数公式不适用，因为常数变量不能提供方差信息。

课件第 38 页给出排队系统中的控制变量选择：如果 `X` 是平均等待时间，可以考虑用到达时间间隔 `Y` 作为控制变量，它通常与等待时间负相关；也可以考虑服务时间 `Y`，它通常与等待时间正相关。两者的分布在输入建模阶段往往已经确定，因此相应期望也已知，无须专门再生成一个新的随机变量。

这一表只整理课件已讲过的统计对象，便于在解题时选对公式。

| 课件方法 | 统计单位 | 主要处理的问题 | 均值估计与区间的关键 |
| --- | --- | --- | --- |
| 终态仿真固定样本量法 | 独立运行的均值，共 `R` 个 | 单次输出随机、连续观测可能相关 | `t` 区间自由度 `R−1` |
| 稳态仿真图形法 | 同一位置的跨运行平均，再平滑 | 选择删除长度 `l` | 找到初始过渡趋势结束的位置 |
| 稳态仿真重复—删除法 | 各次删除后的运行均值，共 `n` 个 | 初始瞬态与运行内相关 | `t` 区间自由度 `n−1` |
| 稳态仿真批平均值法 | 单次长运行的批均值，共 `n` 批 | 在删除初始瞬态后处理相关输出 | `t` 区间自由度 `n−1` |
| 公共随机数法 | 两个模型的配对差 | 比较模型时降低差值方差 | 使两模型输出正相关 |

| 控制变量法 | 经已知期望变量修正后的输出 | 通过相关变量减少估计方差 | `X_c=X−a(Y−ν)` |
