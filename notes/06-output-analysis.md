## 6.1 仿真输出分析的涵义（课件第 2—6 页）

### 6.1.1 为什么仿真结束后还需要统计分析

仿真运行可以给出某个系统的等待时间、产量、设备利用率或其他性能指标。但模型含有随机输入时，同一模型即使参数完全相同，换一组随机数后也可能得到不同结果。例如，某次仿真得到的平均等待时间只是这次随机运行的结果，并不天然等于系统真正的长期平均等待时间。

仿真输出分析要做的事，是利用运行产生的样本数据，估计系统的性能测度。课件重点讨论总体均值，也就是随机输出变量 `X` 的期望 `E(X)`。因此，必须区分三个量：

| 记号 | 含义 | 是否已知 |
| --- | --- | --- |
| `X` | 一次运行或一次观测对应的随机输出变量 | 分布通常未知 |
| `E(X)` 或 `μ` | 希望了解的总体均值 | 待估计 |
| `X̄` | 由已经获得的数据计算的样本均值 | 可以计算 |

课件第 2 页提出的“结果可信吗”“数据怎样生成”“能否反映实际情况”等问题，是对仿真分析可靠性的要求。本讲处理其中的统计问题：在给定模型和输入的前提下，怎样从随机结果中估计性能指标，并说明估计有多大不确定性。

### 6.1.2 独立同分布样本的均值与置信区间

先考虑经典统计情形：已经得到 `n` 个独立同分布观测值 `X₁,…,Xₙ`，用样本均值估计总体均值。

```math
\overline X_n=\frac{1}{n}\sum_{i=1}^{n}X_i
```

用样本方差估计单个观测值的方差：

```math
S^2=\frac{1}{n-1}\sum_{i=1}^{n}(X_i-\overline X_n)^2,
\qquad S=\sqrt{S^2}
```

样本均值的标准误为 `S/√n`。总体正态且方差未知时，下面的双侧 `t` 区间是精确的；若总体并非正态，样本量足够大时可将它作为近似区间。

```math
\boxed{
\overline X_n\pm
t_{1-\alpha/2}(n-1)\frac{S}{\sqrt n}
}
```

这里，`1−α` 是置信水平，例如 95% 对应 `α=0.05`；`t₁₋α/2(n−1)` 是自由度为 `n−1` 的 `t` 分布分位数。区间中心是样本均值，半长等于临界值乘以标准误。

这一公式不能不加区分地直接套到一次仿真中连续记录的所有数据上，因为相邻仿真输出往往存在自相关。例如，上一位顾客等候较久时，后续顾客也可能继续受到拥堵影响。课件后面采用独立重复运行或批平均的方法，目的之一就是处理这个问题。

### 6.1.3 终态仿真与稳态仿真

课件将仿真区分为两类。选择哪种统计方法，首先取决于研究的是哪一类仿真。

| 比较内容 | 终态仿真（Terminating Simulation） | 稳态仿真（Steady-State Simulation） |
| --- | --- | --- |
| 时间范围 | 有限时段 `[0,T_E]` | 关注仿真时间趋于无穷时的长期行为 |
| 是否存在明确终止条件 | 有，如一天结束或完成指定任务 | 通常不以某个自然终止事件定义研究对象 |
| 初始状态的影响 | 是研究结果的一部分，可能始终存在 | 理论上的长期稳态不依赖初始状态 |
| 输出分析的主要问题 | 用独立重复运行估计有限时段性能 | 同时处理初始瞬态与输出自相关 |

终态仿真并不是指“程序运行一段时间以后停止”这么简单。重点在于要研究的对象本来就有明确的有限结束条件。稳态仿真虽然实际也会在某个时刻停止计算，但其目标是估计长期运行的性能。

## 6.2 终态仿真输出分析（课件第 7—14 页）

### 6.2.1 独立重复运行的基本思路

用同样的初始条件与终止事件运行模型多次，每次采用不同且相互独立的随机数流。每一次运行称为一次独立重复（replication）。

这里有两个层次的数据，需要特别区分。

第一层是在同一次运行中收集的 `m` 个观测值。它们可能存在时间相关性，并不能仅因为记录了 `m` 个数就当作 `m` 个独立样本。

第二层是 `R` 次独立运行分别产生的 `R` 个运行均值。只要重复运行的设置一致、随机数流独立，这些运行均值就可以作为相互独立、同分布的统计样本。课件正是使用第二层样本构造置信区间。

### 6.2.2 固定样本量法：从原始输出到区间估计

假设共进行 `R≥2` 次独立重复，每次记录 `m` 个输出。用 `Xᵣᵢ` 表示第 `r` 次运行中的第 `i` 个观测值，其中 `r=1,…,R`、`i=1,…,m`。

第一步，计算每次运行的平均输出：

```math
\overline X_r=\frac{1}{m}\sum_{i=1}^{m}X_{ri},
\qquad r=1,2,\ldots,R
```

第二步，以 `R` 个运行均值为样本，计算总平均：

```math
\overline X
=\frac{1}{R}\sum_{r=1}^{R}\overline X_r
=\frac{1}{mR}\sum_{r=1}^{R}\sum_{i=1}^{m}X_{ri}
```

第三步，计算运行均值之间的样本方差：

```math
S^2=\frac{1}{R-1}
\sum_{r=1}^{R}(\overline X_r-\overline X)^2
```

这个 `S²` 衡量不同独立运行的均值有多分散，并不是把 `mR` 个原始观测直接混在一起求出的样本方差。

第四步，利用 `R` 个独立运行均值构造总体均值的置信区间：

```math
\boxed{
\overline X\pm
t_{1-\alpha/2}(R-1)\frac{S}{\sqrt R}
}
```

公式中的自由度是 `R−1`，标准误分母是 `√R`，不是 `√(mR)`。当单次运行的观测数量 `m` 足够大时，运行均值通常可以根据中心极限定理近似为正态变量，从而使用上述 `t` 区间。

### 6.2.3 课件例题：10 次重复运行的 90% 与 95% 置信区间

课件第 11 页给出以下汇总数据：

```math
R=10,\qquad \overline X=0.343,
\qquad S^2=0.167
```

首先由方差求标准差，再求平均值的标准误：

```math
S=\sqrt{0.167}\approx0.4087,
\qquad
\frac{S}{\sqrt{10}}\approx0.1292
```

计算 90% 置信区间时，`α=0.10`，自由度 `R−1=9`，查表得到 `t₀.₉₅(9)≈1.833`。

```math
\begin{aligned}
h_{90\%}&=1.833\times0.1292\approx0.237\\
CI_{90\%}&=0.343\pm0.237\\
&=\boxed{(0.106,\ 0.580)}
\end{aligned}
```

计算 95% 置信区间时，`α=0.05`，查表得到 `t₀.₉₇₅(9)≈2.262`。

```math
\begin{aligned}
h_{95\%}&=2.262\times0.1292\approx0.292\\
CI_{95\%}&=0.343\pm0.292\\
&=\boxed{(0.051,\ 0.635)}
\end{aligned}
```

两个区间都以 0.343 为中心；95% 置信区间比 90% 置信区间更宽，因为要求更高的覆盖水平时需要更大的临界值。这也说明，置信水平与估计精度不能孤立讨论。

### 6.2.4 规定绝对精度时，如何确定重复次数

固定样本量法先指定重复次数 `R`，再计算得到的区间半长。但在实际仿真实验中，常常先规定可接受误差，例如要求置信区间的半长不超过某个数 `β`。

课件将 `β` 称为绝对精度。相应的置信区间半长为：

```math
h(R)=t_{1-\alpha/2}(R-1)\frac{S}{\sqrt R}
```

希望达到的要求是 `h(R)≤β`。课件用下面的试算法确定重复次数。

第一步，先进行 `R₀=4～5` 次独立运行，计算其运行均值的标准差 `S₀` 和初始区间半长：

```math
\beta_0=t_{1-\alpha/2}(R_0-1)
\frac{S_0}{\sqrt{R_0}}
```

第二步，如果 `β₀≤β`，说明已经满足设定的区间半长要求。如果 `β₀>β`，则暂时用先导实验的 `S₀` 估算所需运行次数：

```math
\boxed{
R^*(\beta)=\min\left\{
i\geq R_0:\quad
t_{1-\alpha/2}(i-1)\frac{S_0}{\sqrt i}\leq\beta
\right\}}
```

这个表达式的含义是：从 `i=R₀` 起逐个尝试更大的整数运行次数，在固定先导标准差 `S₀` 的条件下，找到首个满足半长要求的 `i`。由于 `t` 临界值也随自由度变化，课件采用“试算”而不是只代一个固定常数。

第三步，补做的独立重复次数为：

```math
\Delta R=R^*(\beta)-R_0
```

补充运行后，应根据已经收集的全部运行均值重新计算实际的样本标准差与置信区间半长。这里的 `R*` 是基于先导标准差制定的运行计划，不是对最终半长的无条件保证。

## 6.3 稳态仿真输出分析（课件第 15—26 页）

### 6.3.1 稳态输出为什么有两个统计难点

稳态仿真关注长期行为。初始状态本来不应该决定长期性能，但模拟一开始通常需要人为设定初始条件，例如把排队系统设为空系统。如果直接把刚开始的输出与后面接近稳态的输出混合，可能使长期均值估计产生初始瞬态偏差。

因此，稳态输出分析需要处理两个不同的问题：

其一是初始瞬态问题（initial transient）：仿真开始时的系统尚未进入它的长期运行状态。

其二是自相关问题（autocorrelation）：即使系统进入稳态，按时间顺序记录的相邻输出也未必相互独立。

删除初始数据主要针对第一个问题；独立重复或构造批均值则有助于处理第二个问题。

### 6.3.2 删除初始观测值

假设一次运行记录了 `m` 个输出 `X₁,…,Xₘ`，决定删除前 `l` 个输出。剩下的数据均值为：

```math
\boxed{
\overline X(m,l)=\frac{1}{m-l}
\sum_{i=l+1}^{m}X_i
},\qquad 0\leq l<m
```

例如，`l` 是预热阶段末尾所对应的观测编号。这里的 `l` 表示删除多少个观测值，而不是必然等于某个时间长度；如果记录的是不等间隔事件输出，观测个数与经过的时间不能混为一谈。

问题在于：`l` 不能随意指定。删得太少，初始偏差可能仍存在；删得过多，又会白白损失仿真数据。课件采用图形法确定一个合理的截断位置。

### 6.3.3 图形法：重复运行、跨运行平均、再平滑

课件第 17—18 页的图形法共有四步。

第一步，进行 `n>4` 次独立重复仿真，每次收集 `m` 个按相同顺序定义的观测值。记 `Xᵢⱼ` 为第 `i` 次运行中的第 `j` 个观测值。

第二步，对同一观测编号 `j`，先在不同运行之间取平均：

```math
\overline X_j=\frac{1}{n}\sum_{i=1}^{n}X_{ij},
\qquad j=1,2,\ldots,m
```

这是为了抵消单次随机运行的偶然波动，从而更清楚地观察系统的平均变化趋势。注意，这里是“固定 `j`、跨不同运行求平均”，不是把一次运行里所有时刻直接平均。

第三步，对得到的序列再进行移动平均平滑。设平滑窗口向左右各延伸 `ω` 个观测位置，课件给出的处理方式为：

```math
\overline X_j^{(\omega)}=
\begin{cases}
\displaystyle\frac{1}{2j-1}
\sum_{s=-(j-1)}^{j-1}\overline X_{j+s},
&j=1,\ldots,\omega,\\[8pt]
\displaystyle\frac{1}{2\omega+1}
\sum_{s=-\omega}^{\omega}\overline X_{j+s},
&j=\omega+1,\ldots,m-\omega.
\end{cases}
```

在序列开头，左右两侧没有足够的观测值，因此使用较短的对称窗口；进入中间部分后使用固定长度 `2ω+1` 的窗口。平滑是为了看清趋势，不是用来改变原始观测的定义。

第四步，绘制 `X̄ⱼ^(ω)` 随 `j` 变化的轨迹，寻找曲线不再呈现明显初始过渡趋势的区域，选取相应的删除长度 `l`。课件使用的是图形判断，没有给出一个适用于所有系统的统一数值公式。

### 6.3.4 重复—删除法（Replication–Deletion）

这是一种将“独立重复运行”与“删除初始阶段”结合起来的方法。

进行 `n` 次独立重复仿真，每次得到 `m` 个观测值。在每次运行中都删除前 `l` 个，再分别计算保留数据的均值：

```math
\overline X_i(m,l)=\frac{1}{m-l}
\sum_{j=l+1}^{m}X_{ij},
\qquad i=1,2,\ldots,n
```

这样得到 `n` 个运行均值：

```math
\overline X_1(m,l),\ \overline X_2(m,l),\
\ldots,\ \overline X_n(m,l)
```

由于各次运行独立，可以把这些运行均值看作近似独立同分布的样本；当保留样本量足够大时，可使用正态近似与 `t` 区间。

设这 `n` 个运行均值的总平均和样本方差分别为：

```math
\begin{aligned}
\overline X_{RD}&=\frac{1}{n}\sum_{i=1}^{n}\overline X_i(m,l),\\
S_{RD}^2&=\frac{1}{n-1}
\sum_{i=1}^{n}\bigl(\overline X_i(m,l)-\overline X_{RD}\bigr)^2.
\end{aligned}
```

那么总体均值的近似置信区间是：

```math
\boxed{
\overline X_{RD}\pm
t_{1-\alpha/2}(n-1)\frac{S_{RD}}{\sqrt n}
}
```

课件第 21 页列出这种方法的两个缺点：每次独立运行都要重新删除前 `l` 个值，导致数据使用效率偏低；为了按次收集各次运行结果，需要对仿真过程进行重复启动与停止。

### 6.3.5 批平均值法（Batch Means）

重复—删除法使用多次独立运行。批平均值法改为只进行一次足够长的仿真，把一个长序列划分为若干批次，再分析各批的平均值。

课件首先引入协方差平稳过程的三个条件。设进入稳态后的输出为 `X₁,X₂,…`，则：

```math
\begin{aligned}
E(X_i)&=\mu,\qquad i=1,2,\ldots,\\
\operatorname{Var}(X_i)&=\sigma^2,\qquad i=1,2,\ldots,\\
\operatorname{Cov}(X_i,X_{i+j})&=C_j,\qquad i=1,2,\ldots
\end{aligned}
```

第一个条件表示均值不随观测位置改变；第二个表示方差不随观测位置改变；第三个表示两个输出之间的协方差只与它们相隔多少个观测位置有关，而不取决于它们具体发生在序列的哪个位置。协方差平稳不意味着原始相邻输出是独立的。

按照课件第 24—25 页，假设已经保留了 `m=nb` 个稳态观测，将其分成 `n` 批，每批 `b` 个。第 `i` 批平均值为：

```math
\boxed{
\overline X_i(b)=\frac{1}{b}
\sum_{j=1}^{b}X_{(i-1)b+j}
},\qquad i=1,2,\ldots,n
```

全部批均值的平均为：

```math
\overline X(n,b)=\frac{1}{n}
\sum_{i=1}^{n}\overline X_i(b)
```

各批均值之间的样本方差为：

```math
S_b^2=\frac{1}{n-1}
\sum_{i=1}^{n}
\bigl(\overline X_i(b)-\overline X(n,b)\bigr)^2
```

当每批长度 `b` 足够大，批均值之间的相关性可以忽略且其分布近似正态时，可以使用：

```math
\boxed{
\overline X(n,b)\pm
t_{1-\alpha/2}(n-1)\frac{S_b}{\sqrt n}
}
```

这里再次强调：自由度是批次数 `n` 减 1，而不是原始观测数 `m` 减 1。批平均法的基本思路是以批为统计单位，不能把所有原始相关观测直接当作独立样本。

### 6.3.6 预热删除、优点与难点

课件第 26 页特别说明：即使使用批平均值法，仍应先删除初始的 `l` 个观测值。正确的顺序是先剔除初始瞬态，再将后续长序列划分为批次。

与重复—删除法比较，批平均值法只需在一次长运行中删除一次初始数据，因而通常更节省输出数据。课件将其优点概括为数据使用效率较高、能够得到较精确的置信区间；但这些效果仍依赖于合理选择批长和批次数。

课件指出的实际困难是确定 `n` 和 `b`。`b` 太小，批均值仍可能明显相关；`n` 太少，估计样本方差和计算 `t` 区间时的信息量不足。因此不能只要求把运行时间拉长，还需要考虑如何分批。

## 6.4 方差衰减技术（课件第 27—38 页）

### 6.4.1 方差衰减的目的

仿真输出具有随机性。对同一个估计目标，输出估计量的方差越大，重复仿真得到的结果越分散，相应置信区间通常也越宽。方差衰减技术的目的，是通过设计随机输入或调整估计量，在不改变所估计总体均值的前提下减小估计方差。

本节课件讨论三种方法：公共随机数法、对偶变量法、控制变量法。前两种主要通过安排随机输入之间的关系来发挥作用；控制变量法则利用另一个具有已知期望的随机变量来校正输出。

### 6.4.2 公共随机数法（Common Random Numbers）

公共随机数法主要用于比较两个不同系统模型。例如，同一服务系统在原有规则与改进规则下的平均等待时间是否不同。

设模型 1 的输出为 `X₁`，模型 2 的输出为 `X₂`，希望估计二者总体均值之差：

```math
\mu=E(X_1)-E(X_2)
```

分别运行 `n` 次，令第 `i` 次配对运行的输出为 `X₁ᵢ` 与 `X₂ᵢ`。先计算每一对结果的差：

```math
Z_i=X_{1i}-X_{2i},\qquad
\overline Z_n=\frac{1}{n}\sum_{i=1}^{n}Z_i
```

由期望的线性性质，可以验证差值均值是目标差异的无偏估计：

```math
E(\overline Z_n)=E(X_1)-E(X_2)=\mu
```

两个随机变量相减的方差满足：

```math
\operatorname{Var}(Z_i)
=\operatorname{Var}(X_{1i})
+\operatorname{Var}(X_{2i})
-2\operatorname{Cov}(X_{1i},X_{2i})
```

如果不同配对之间相互独立，则：

```math
\operatorname{Var}(\overline Z_n)
=\frac{1}{n^2}\sum_{i=1}^{n}
\left[
\operatorname{Var}(X_{1i})
+\operatorname{Var}(X_{2i})
-2\operatorname{Cov}(X_{1i},X_{2i})
\right]
```

这个公式是理解公共随机数法的关键。两个模型使用相同随机输入后，如果相应输出呈正相关，协方差项为正，而公式中要减去两倍协方差，差值估计量的方差便会下降。

实施时，对两个系统中具有相同含义的随机输入使用相同的随机数发生器与种子值，使两种系统面对尽量一致的随机环境。例如，比较两种排队规则时，让它们使用同一组到达与服务随机情景。需要注意，方差下降取决于实际产生的输出相关性；如果配对后相关性为负，效果可能相反。

### 6.4.3 对偶变量法（Antithetic Variates）

对偶变量法主要用于估计同一个系统模型的性能。它不比较两个不同模型，而是构造两次相互关联的运行，使结果相互抵消一部分随机波动。

课件的做法是：第一次运行使用均匀随机数 `uₖ` 生成输入，第二次运行使用互补随机数 `1−uₖ` 生成相应输入，形成一对结果。

进行 `n` 对仿真。第 `i` 对得到 `Xᵢ^(1)` 和 `Xᵢ^(2)`，取这一对的平均：

```math
X_i=\frac{X_i^{(1)}+X_i^{(2)}}{2}
```

再对 `n` 个配对均值求总平均：

```math
\overline X_n=\frac{1}{n}\sum_{i=1}^{n}X_i
```

如果两次运行分别具有相同的目标均值 `μ`，那么：

```math
E(\overline X_n)=\mu
```

假设不同配对之间相互独立，配对均值的方差是：

```math
\operatorname{Var}(\overline X_n)
=\frac{1}{4n^2}\sum_{i=1}^{n}
\left[
\operatorname{Var}(X_i^{(1)})
+\operatorname{Var}(X_i^{(2)})
+2\operatorname{Cov}(X_i^{(1)},X_i^{(2)})
\right]
```

这里协方差项前面是加号，与公共随机数法的减号不同。因此，对偶变量法希望同一对的两个输出负相关，让两个结果的波动相互抵消。

课件用互补随机数实现这种设计。若输出随输入呈相应的单调变化，`u` 与 `1−u` 通常有助于形成负相关的输出；不过，并非所有复杂仿真模型都能保证两个最终输出必然负相关，因此是否有效应以实际方差为准。

### 6.4.4 控制变量法（Control Variates）

控制变量法同样用于估计同一个系统的总体均值。与前两种方法不同，它需要找到另一个和输出相关、且总体期望已知的随机变量。

假设目标输出为 `X`，要估计 `μ=E(X)`。另有随机变量 `Y` 与 `X` 相关，并且 `E(Y)=ν` 已知。构造新的估计量：

```math
\boxed{X_c=X-a(Y-\nu)}
```

其中 `a` 为待选择的常数。因为 `E(Y−ν)=0`，所以：

```math
\begin{aligned}
E(X_c)&=E[X-a(Y-\nu)]\\
&=E(X)-a\bigl(E(Y)-\nu\bigr)\\
&=\boxed{\mu}
\end{aligned}
```

这说明控制变量调整不会改变目标总体均值。它改变的是估计量的方差：

```math
\operatorname{Var}(X_c)
=\operatorname{Var}(X)
+a^2\operatorname{Var}(Y)
-2a\operatorname{Cov}(X,Y)
```

为了使方差最小，可对 `a` 求导并令其等于零：

```math
\begin{aligned}
\frac{\mathrm d\operatorname{Var}(X_c)}{\mathrm da}
&=2a\operatorname{Var}(Y)-2\operatorname{Cov}(X,Y)=0\\
a^*&=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(Y)}
\end{aligned}
```

将这个最优系数代回方差公式，可以得到课件给出的最小方差表达式：

```math
\boxed{
\operatorname{Var}(X_c)
=\operatorname{Var}(X)
-\frac{\operatorname{Cov}(X,Y)^2}{\operatorname{Var}(Y)}
}
```

只有当 `X` 与 `Y` 存在非零相关性时，这个理想的方差减少量才为正；相关性越强，可减少的部分通常越大。如果 `Var(Y)=0`，上面的最优系数公式不适用，因为常数变量不能提供方差信息。

课件第 38 页给出排队系统中的控制变量选择：如果 `X` 是平均等待时间，可以考虑用到达时间间隔 `Y` 作为控制变量，它通常与等待时间负相关；也可以考虑服务时间 `Y`，它通常与等待时间正相关。两者的分布在输入建模阶段往往已经确定，因此相应期望也已知，无须专门再生成一个新的随机变量。

## 6.5 几个需要补充的统计原理

### 6.5.1 按顾客平均与按时间平均不是同一回事

在排队仿真中，平均等待时间通常按顾客统计。若收集了 `n` 位顾客的等待时间 `W_{q,i}`，计算的是：

```math
\overline W_q=\frac{1}{n}\sum_{i=1}^{n}W_{q,i}
```

而平均排队人数是时间平均量。若 `L_q(t)` 表示时刻 `t` 正在等待的顾客数，观测窗口为 `[0,T]`，则：

```math
\overline L_q(T)=\frac{1}{T}\int_0^T L_q(t)\,dt
```

离散事件系统的状态通常呈阶梯状。记第 `j` 个时间区间的队长为 `q_j`，持续时间为 `\Delta t_j`，于是：

```math
\boxed{
\overline L_q(T)=\frac{\sum_j q_j\Delta t_j}{T}
}
```

<strong>例。</strong> 0—2 分钟队长为 0，2—5 分钟队长为 3，5—10 分钟队长为 1。队长曲线下的面积为：

```math
A=0\times2+3\times3+1\times5=14
```

所以正确的时间平均队长为 `14/10=1.4`。直接计算三个状态值的算术平均 `(0+3+1)/3=1.333\ldots` 是错误的，因为三个队长分别持续了不同的时间。

这一点与前面手工事件仿真中的队长阶梯图直接相关。应用第六讲的置信区间公式之前，要先明确<strong>每次运行输出 `X_r` 的统计定义</strong>：是每位顾客的平均值、某一时期的总产量，还是队长曲线的时间平均值。

### 6.5.2 为什么连续收集的大量输出不等于大量独立样本？

设系统进入稳态后，`X_1,\ldots,X_m` 是一个协方差平稳序列，其方差为 `\sigma^2`，滞后 `k` 阶自相关系数为 `\rho(k)`。对样本均值：

```math
\overline X_m=\frac{1}{m}\sum_{i=1}^{m}X_i
```

直接展开其方差，得到：

```math
\operatorname{Var}(\overline X_m)
=\frac{1}{m^2}\sum_{i=1}^{m}\sum_{j=1}^{m}
\operatorname{Cov}(X_i,X_j)
```

利用协方差平稳性将同一滞后阶的项合并，可得：

```math
\boxed{
\operatorname{Var}(\overline X_m)
=\frac{\sigma^2}{m}
\left[
1+2\sum_{k=1}^{m-1}
\left(1-\frac{k}{m}\right)\rho(k)
\right]
}
```

若原始观测独立，则所有正滞后相关系数都是 0，公式才简化为 `\sigma^2/m`。如果各滞后具有显著正相关，方括号可能远大于 1，直接使用独立样本公式就会低估均值的标准误。

作为数值演示，若假设 `\rho(k)=0.8^k`，且运行序列足够长，则：

```math
1+2\sum_{k=1}^{\infty}0.8^k
=1+2\frac{0.8}{1-0.8}=9
```

这表示样本均值的方差近似为独立样本估计公式的 9 倍，标准误约为 3 倍。即使记录了 900 个高度相关的输出，其均值精度也可能仅相当于约 100 个独立观测。这是理解批平均值法的关键。

### 6.5.3 删除预热数据与解决自相关是两件事

一个从空队列开始的稳态排队模型，最初的等待时间可能系统性偏低。删除前 `l` 个观测值，是为了减轻这种初始状态偏差。但是，删除完成后，后续顾客的等待时间仍可能相关。

| 问题 | 主要表现 | 对应方法 |
| --- | --- | --- |
| 初始瞬态 | 开头几段输出明显不同于长期水平 | 图形法与预热删除 |
| 输出自相关 | 相邻或相隔几步的输出存在依赖 | 独立重复、合理选择批长 |
| 独立统计单位过少 | 置信区间半长较大 | 增加运行次数或有效批次数 |
| 终态与稳态目标混淆 | 试图把一天的经营结果当无限期均值 | 先确定研究的时间边界 |

因此，“先删除预热期”是必要的统计处理，但不自动保证保留的原始观测可以直接当 IID 样本。

## 6.6 完整计算题：从题目到答案与推导

以下例题用于扩充原课件的练习，均给出明确的计算条件。

### 例题 1：终态仿真的 95% 置信区间

<strong>题目：</strong> 某系统做了五次独立重复，每次以相同初始状态开始并在同一终止条件结束。五次运行的平均等待时间分别是 6、8、7、9、5 分钟。求总体平均等待时间的 95% 双侧置信区间。已知 `t_{0.975}(4)=2.776`。

<strong>答案：</strong> 约为 `(5.037,\ 8.963)` 分钟。

第一步，把五次运行均值作为五个独立统计单位：

```math
\overline X=\frac{6+8+7+9+5}{5}=7
```

第二步，计算运行均值的样本方差：

```math
\begin{aligned}
S^2&=\frac{(6-7)^2+(8-7)^2+(7-7)^2
+(9-7)^2+(5-7)^2}{5-1}\\
&=\frac{1+1+0+4+4}{4}=2.5
\end{aligned}
```

第三步，求标准误和半长：

```math
\begin{aligned}
SE&=\frac{\sqrt{2.5}}{\sqrt5}
=\sqrt{0.5}\approx0.7071\\
h&=2.776\times0.7071\approx1.963
\end{aligned}
```

第四步，写出置信区间：

```math
\boxed{
CI_{95\%}=7\pm1.963
\approx(5.037,\ 8.963)
}
```

自由度是 `R-1=4`，不是每次运行内记录的顾客总数减 1。运行内的多个顾客观测即使相关，也已经在每次运行的平均指标中汇总。

### 例题 2：已知绝对精度，计算还要重复多少次

<strong>题目：</strong> 初步做 `R_0=5` 次独立运行，运行均值的标准差为 `S_0=2`。要求双侧 95% 置信区间半长不超过 `\beta=1`。用课件试算法估计总运行次数和补充次数。

已知 `t_{0.975}(4)=2.776`、`t_{0.975}(16)\approx2.120`、`t_{0.975}(17)\approx2.110`。

<strong>答案：</strong> 总次数约需 18 次，再补充 13 次。

先检查初始半长：

```math
\beta_0=2.776\frac{2}{\sqrt5}\approx2.483>1
```

继续假设先导标准差 `S_0=2` 近似代表未来运行波动，对 `i` 逐个试算：

```math
h(i)=t_{0.975}(i-1)\frac{2}{\sqrt i}
```

当 `i=17`：

```math
h(17)\approx2.120\frac{2}{\sqrt{17}}
\approx1.028>1
```

当 `i=18`：

```math
h(18)\approx2.110\frac{2}{\sqrt{18}}
\approx0.995\leq1
```

因此：

```math
R^*=18,\qquad
\Delta R=18-5=\boxed{13}
```

这里的 18 是基于先导 `S_0` 的计划次数。增加运行后要重新计算所有独立运行均值的样本标准差及实际半长，不能把试算值当作必然达到的最终精度。

### 例题 3：预热期图形法与移动平均

<strong>题目：</strong> 做五次独立仿真，并对同一序号的输出跨运行求平均，得到：

| `j` | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `\overline X_j` | 2.0 | 4.0 | 6.0 | 8.0 | 9.6 | 10.1 | 10.0 | 10.2 |

若采用左右各一个观测位置的移动平均（`\omega=1`），计算第 4、5、6 项的平滑值，并判断预热期的大致范围。

<strong>答案：</strong> 平滑值约为 7.867、9.233、9.900；前几项存在明显上升过渡，`l` 可以先在 4 附近试验，再结合更长的输出轨迹判断。

在内部观测位置，公式为：

```math
\overline X_j^{(1)}
=\frac{\overline X_{j-1}+\overline X_j+\overline X_{j+1}}{3}
```

逐项计算：

```math
\begin{aligned}
\overline X_4^{(1)}&=\frac{6+8+9.6}{3}\approx7.867\\
\overline X_5^{(1)}&=\frac{8+9.6+10.1}{3}\approx9.233\\
\overline X_6^{(1)}&=\frac{9.6+10.1+10.0}{3}=9.900
\end{aligned}
```

图形法没有唯一的机械判定阈值。不能因为第 5 项已经超过 9，就断言第 5 项必然是稳态起点；应同时考虑移动平均的整体走势和更长运行的稳定性。

### 例题 4：重复—删除法逐步计算

<strong>题目：</strong> 某稳态系统做四次独立运行，每次观察六个输出，删除前两项。数据如下：

| 运行 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 第一次 | 1 | 2 | 3 | 4 | 5 | 4 |
| 第二次 | 0 | 3 | 4 | 6 | 5 | 5 |
| 第三次 | 3 | 2 | 5 | 6 | 6 | 7 |
| 第四次 | 1 | 5 | 6 | 7 | 8 | 7 |

求删除后的运行均值、总体均值估计及 95% 置信区间。已知 `t_{0.975}(3)=3.182`。

<strong>答案：</strong> 运行均值依次为 4、5、6、7；总体估计为 5.5；置信区间约为 `(3.446,\ 7.554)`。

每次只保留第 3—6 个观测：

```math
\begin{aligned}
\overline X_1(6,2)&=\frac{3+4+5+4}{4}=4\\
\overline X_2(6,2)&=\frac{4+6+5+5}{4}=5\\
\overline X_3(6,2)&=\frac{5+6+6+7}{4}=6\\
\overline X_4(6,2)&=\frac{6+7+8+7}{4}=7
\end{aligned}
```

因此：

```math
\begin{aligned}
\overline X_{RD}&=\frac{4+5+6+7}{4}=5.5\\
S_{RD}^2&=\frac{(4-5.5)^2+(5-5.5)^2+
(6-5.5)^2+(7-5.5)^2}{3}
=\frac{5}{3}
\end{aligned}
```

再计算：

```math
\begin{aligned}
SE&=\sqrt{\frac{5/3}{4}}=\sqrt{\frac{5}{12}}\approx0.6455\\
h&=3.182\times0.6455\approx2.054\\
CI_{95\%}&=5.5\pm2.054
\approx\boxed{(3.446,\ 7.554)}
\end{aligned}
```

本题有 24 个原始观测，删除 8 个，保留 16 个，但独立统计单位仍为四次运行均值。因此区间自由度为 3。

<strong>题目：</strong> 已经删除初始瞬态后，某次长运行保留 12 个输出：

```math
2,\ 4,\ 3,\ 5,\ 4,\ 6,\ 3,\ 3,\ 6,\ 6,\ 5,\ 7
```

分成 4 批，每批 3 个观测，求四个批均值、总体均值及形式上的 95% 区间。已知 `t_{0.975}(3)=3.182`，假定各批均值近似独立。

<strong>答案：</strong> 批均值 3、5、4、6；总体均值估计 4.5；区间约为 `(2.446,\ 6.554)`。

| 批次 | 原始输出 | 批均值 |
| --- | --- | ---: |
| 1 | 2、4、3 | 3 |
| 2 | 5、4、6 | 5 |
| 3 | 3、3、6 | 4 |
| 4 | 6、5、7 | 6 |

```math
\overline X(4,3)=\frac{3+5+4+6}{4}=4.5
```

```math
\begin{aligned}
S_b^2&=\frac{(3-4.5)^2+(5-4.5)^2+
(4-4.5)^2+(6-4.5)^2}{3}\\
&=\frac{5}{3}
\end{aligned}
```

```math
\begin{aligned}
CI_{95\%}
&=4.5\pm3.182\sqrt{\frac{5}{12}}\\
&\approx\boxed{(2.446,\ 6.554)}
\end{aligned}
```

每批只有 3 项，是为了手算方便。真实系统的输出若具有强自相关，长度为 3 的批均值未必独立，不能直接认定这个区间具有标称的覆盖水平。应用时应增加批长、检查批均值相关性，并合理平衡批次数与批长。

### 例题 6：公共随机数法使用配对差

<strong>题目：</strong> 比较两种系统方案 A、B，使用相同随机输入进行四次配对运行：

| 配对 | 方案 A | 方案 B | 差值 A－B |
| --- | ---: | ---: | ---: |
| 1 | 12 | 10 | 2 |
| 2 | 14 | 13 | 1 |
| 3 | 18 | 15 | 3 |
| 4 | 16 | 13 | 3 |

求差值均值与其标准误，并说明配对的作用。

<strong>答案：</strong> `\overline Z=2.25`，`SE(\overline Z)\approx0.479`。

```math
\overline Z=\frac{2+1+3+3}{4}=2.25
```

```math
\begin{aligned}
S_Z^2&=\frac{(2-2.25)^2+(1-2.25)^2+
(3-2.25)^2+(3-2.25)^2}{3}\\
&=\frac{2.75}{3}\approx0.9167\\
SE(\overline Z)&=\sqrt{\frac{0.9167}{4}}\approx0.479
\end{aligned}
```

如果忽略配对关系，把两个方案各自样本均值当作独立估计，标准误的相应计算会是：

```math
\sqrt{\frac{S_A^2}{4}+\frac{S_B^2}{4}}
=\sqrt{\frac{6.667+4.250}{4}}
\approx1.652
```

本例通过同一随机场景配对，差值的标准误大幅减小。更一般地，公共随机数法是否有效取决于两个模型输出的实际协方差是否为正。

实务中还要注意随机数的<strong>业务对应关系</strong>：即使两套模型使用相同种子，如果模型调用随机数的顺序不同，未必保证相同顾客、相同工序获得相同的随机情景。

### 例题 7：对偶变量法为什么可以降低方差？

<strong>题目：</strong> 输出为 `X=U^2`，其中 `U\sim U(0,1)`。把 `U` 与 `1-U` 配成一对。如果某次生成 `u=0.2`，求配对输出均值；进一步比较这种配对与两次独立抽样的方差。

<strong>答案：</strong> 当 `u=0.2` 时配对均值为 0.34；在这个特定模型中，配对均值的方差为 `1/180`，是两次独立抽样平均值方差的八分之一。

单次配对结果：

```math
X^{(1)}=0.2^2=0.04,\quad
X^{(2)}=0.8^2=0.64
```

```math
\overline X_{\mathrm{pair}}
=\frac{0.04+0.64}{2}=0.34
```

计算单个输出的方差：

```math
\operatorname{Var}(U^2)
=E(U^4)-E(U^2)^2
=\frac{1}{5}-\frac{1}{9}
=\frac{4}{45}
```

再计算对偶输出的协方差：

```math
\begin{aligned}
\operatorname{Cov}(U^2,(1-U)^2)
&=E[U^2(1-U)^2]-\frac{1}{9}\\
&=\int_0^1u^2(1-u)^2\,du-\frac{1}{9}\\
&=\frac{1}{30}-\frac{1}{9}
=-\frac{7}{90}
\end{aligned}
```

因此：

```math
\begin{aligned}
\operatorname{Var}
\left(\frac{U^2+(1-U)^2}{2}\right)
&=\frac{1}{4}
\left(\frac{4}{45}+\frac{4}{45}-\frac{14}{90}\right)\\
&=\frac{1}{180}
\end{aligned}
```

但若是两个独立抽样输出的平均，方差为：

```math
\frac{1}{2}\operatorname{Var}(U^2)
=\frac{2}{45}
```

方差减少倍数为 `(2/45)/(1/180)=8`。两种方法均估计 `E(U^2)=1/3`，但利用对偶负相关可以降低误差。复杂仿真未必产生这种负相关，仍需实际验证。

### 例题 8：控制变量法求最优系数

<strong>题目：</strong> `\operatorname{Var}(X)=25`，已知控制变量 `Y` 满足 `E(Y)=5`、`\operatorname{Var}(Y)=16`、`\operatorname{Cov}(X,Y)=16`。构造 `X_c=X-a(Y-5)`，求最优系数、调整后的最小方差；若一次观测 `X=120,Y=7`，求该次调整结果。

<strong>答案：</strong> `a^*=1`，最小方差 9，该次调整结果 118。

先求：

```math
a^*=\frac{\operatorname{Cov}(X,Y)}
{\operatorname{Var}(Y)}
=\frac{16}{16}=1
```

代入：

```math
\begin{aligned}
\operatorname{Var}(X_c)
&=25-\frac{16^2}{16}=9\\
\frac{25-9}{25}&=64\%
\end{aligned}
```

这表明最优控制之后方差下降 64%。单次调整结果为：

```math
x_c=120-1(7-5)=118
```

从总体上看，`E(Y-5)=0`，所以控制变量调整不会改变 `E(X)`。若最优 `a` 已知，还可将最小方差写成：

```math
\operatorname{Var}(X_c)
=\operatorname{Var}(X)(1-\rho_{XY}^2)
```

本题相关系数 `\rho_{XY}=16/\sqrt{25\times16}=0.8`，于是方差剩余比例为 `1-0.8^2=0.36`，与 `9/25` 一致。

在真实实验中，最优系数往往需要估计。如果直接用同一小批数据估计 `a` 再构造修正后的样本均值，其有限样本性质要另行检查；前面的严格无偏推导是针对系数事先固定的情况。

### 例题 9：区分三种方差衰减方法

<strong>题目：</strong> 判断下列情形的对应方法。

甲：比较两种生产规则，让两个模型面对同一批到达间隔与服务时间。

乙：估计同一个模型的平均成本，一次使用随机数 `u_i`，下一次使用 `1-u_i`。

丙：估计平均等待时间，记录一个与之相关且理论均值已知的服务时间指标，对等待时间作线性校正。

<strong>答案：</strong> 甲是公共随机数法；乙是对偶变量法；丙是控制变量法。

<strong>解释：</strong> 公共随机数法关注<strong>不同模型输出的差</strong>，希望对应输出正相关；对偶变量法关注<strong>同一模型的均值</strong>，希望成对输出负相关；控制变量法利用辅助变量的<strong>已知期望与相关性</strong>来调整估计量。

## 6.7 选公式时先看题目的数据结构

| 题目条件 | 首先想到的方法 | 重点核查 |
| --- | --- | --- |
| 一天、一批订单或一个项目，存在自然结束条件 | 终态仿真 | 运行的初始条件、终止条件是否一致 |
| 进行 `R` 次独立运行，每次内部还有多条相关观测 | 用运行均值建立 `t` 区间 | 自由度是 `R-1` |
| 要求区间半长不超过 `\beta` | 规定精度试算法 | 先导 `S_0` 和随 `R` 变化的 `t` 分位数 |
| 单次长运行从空系统开始，起初输出偏小 | 稳态与预热期 | 先选删除长度 `l` |
| 多次独立运行，每次都删除前 `l` 项 | 重复—删除法 | 每次先删，再求各运行均值 |
| 单次长运行分为 `n` 批，每批 `b` 个观测 | 批平均值法 | 批均值是否可近似视为独立 |
| 两个方案使用相同随机场景 | 公共随机数法 | 计算每对输出之差 |
| 同一系统使用 `u` 和 `1-u` | 对偶变量法 | 计算每对输出之均值 |
| 给出了 `E(Y)`、`Var(Y)` 和 `Cov(X,Y)` | 控制变量法 | `a^*=Cov(X,Y)/Var(Y)` |

遇到综合题可以组合方法。例如比较两种稳态排队规则时，可以先删除各自的预热期，再在两种规则中使用公共随机数形成配对差，最后对多次独立配对差建立置信区间。预热删除解决初始状态问题，配对设计解决方案比较的随机误差，置信区间说明剩余估计不确定性。

## 6.8 期末串讲的层级数据计算题：三次运行，每次四个观测

这道题与[课堂录音期末复习章节](../exam-review/2026-final-review.md)中讨论的统计结构一致。它的真正难点不在于求一个算术平均数，而在于理解<strong>12 个原始数与 3 次独立仿真之间的层级关系</strong>。将这道题放进第六讲，是为了让终态仿真置信区间的计算公式可以独立复习。

### 6.8.1 数据结构和题目要求

一个系统独立运行三次，每次运行都收集四个连续观测。各次运行的初始条件、终止规则与性能指标定义相同，运行内部的四个数可能彼此相关，但不同运行采用独立随机输入。

| 独立运行 | 第 1 个观测 | 第 2 个观测 | 第 3 个观测 | 第 4 个观测 | 本次运行均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第 1 次 | 7 | 8 | 8 | 9 | 8 |
| 第 2 次 | 9 | 10 | 10 | 11 | 10 |
| 第 3 次 | 11 | 12 | 12 | 13 | 12 |

题目要求使用独立重复运行的方法估计系统平均性能；再假定希望 95% 置信区间的绝对半长不超过 `β=1`，用先导标准差试算至少需要的独立运行次数。已知 `t_{0.975}(2)=4.303`、`t_{0.975}(16)=2.120`、`t_{0.975}(17)=2.110`。

### 6.8.2 第一层：每次运行内部先求一个性能指标

第一、第二、第三次运行分别得到：

```math
\begin{aligned}
Y_1&=(7+8+8+9)/4=8,\\
Y_2&=(9+10+10+11)/4=10,\\
Y_3&=(11+12+12+13)/4=12
\end{aligned}
```

这一步把每次运行内部的四个观测压缩成一个有明确意义的“运行均值”。在本题假设下，能够用于后面独立重复统计的样本是 `Y₁、Y₂、Y₃`，而不是 12 个未经区分的原始观测。

### 6.8.3 第二层：对三个运行均值求样本均值和样本标准差

先求运行均值的总体样本均值：

```math
\overline Y=\frac{8+10+12}{3}=10
```

再对这三个运行均值求无偏样本方差与标准差：

```math
\begin{aligned}
S_0^2&=\frac{(8-10)^2+(10-10)^2+(12-10)^2}{3-1}
=\frac{8}{2}=4,\\
S_0&=\sqrt4=2
\end{aligned}
```

这里的 `S₀=2` 描述的是<strong>三个运行均值之间</strong>的波动。如果对 12 个原始观测直接求样本方差，并把样本量填成 12，就相当于把同一次运行内部的相关数据错误地视作 12 次独立重复。

### 6.8.4 第三层：初始三次运行的 95% 置信区间

当前只有 `R₀=3` 次独立运行，所以自由度是 `R₀−1=2`：

```math
\begin{aligned}
h_0&=t_{0.975}(2)\frac{S_0}{\sqrt{R_0}}
=4.303\frac{2}{\sqrt3}\approx4.969,\\
CI_{95\%}&=10\pm4.969
\approx(5.031,14.969)
\end{aligned}
```

区间较宽，意味着三次独立运行提供的总体均值估计仍然不够精确。这里的 `95%` 是区间构造方法在相应统计假设下的长期覆盖解释，不意味着这次已计算出的固定区间有“95% 的概率包含固定参数”。

### 6.8.5 第四层：按规定精度用试算法寻找最少总运行次数

要求半长 `β≤1`。用初始标准差 `S₀=2` 作为计划依据，在候选总次数 `r` 下计算：

```math
h_{\mathrm{plan}}(r)
=t_{0.975}(r-1)\frac{2}{\sqrt r}
```

为了不用从 3 一项项试到十几，可以先用标准正态值做粗估：

```math
r\approx\left(\frac{1.96\times2}{1}\right)^2
=15.3664
```

这一近似只用于寻找试算起点，不是最后答案；真正的试算法仍需要用相应自由度的 `t` 临界值。向上继续试算：

```math
\begin{aligned}
h_{\mathrm{plan}}(17)&=2.120\frac{2}{\sqrt{17}}
\approx1.028>1,\\
h_{\mathrm{plan}}(18)&=2.110\frac{2}{\sqrt{18}}
\approx0.995\leq1
\end{aligned}
```

因此，按先导标准差计算，`17` 次不足以达到要求，而 `18` 次达到要求。<strong>至少总共 18 次，还要补做 `18−3=15` 次独立运行。</strong>

回答“至少需要多少次”时，最好写出临界附近相邻两个整数的试算，说明为什么 18 是第一个满足条件的整数，而不只是写一句“试得 18”。这一结果是<strong>运行次数计划</strong>；补做之后仍应利用全部运行均值重新计算实际标准差与区间半长。

### 6.8.6 用一个简单的相关模型说明为什么不能把 12 个数直接合并

设第 `r` 次运行中第 `j` 个观测可以写为：

```math
X_{rj}=\mu+B_r+\varepsilon_{rj}
```

其中 `Bᵣ` 是第 `r` 次运行共同经历的随机环境影响，具有方差 `τ²`；`εᵣⱼ` 是独立的个别波动，具有方差 `σ²`。不同运行之间的 `Bᵣ` 相互独立，并且与全部 `εᵣⱼ` 独立。则同一次运行中即使有很多观测，它们仍共享同一个 `Bᵣ`。

在每次 `m` 个观测、共 `R` 次独立运行时，所有观测的总平均等于运行均值的平均，但其真实方差是：

```math
\operatorname{Var}(\overline X)
=\frac{\tau^2}{R}+\frac{\sigma^2}{Rm}
```

如果错误地把 `Rm` 个原始数当作彼此独立，得到的方差却是 `(τ²+σ²)/(Rm)`，这把各次运行共同的随机影响额外除以了 `m`，会使标准误被低估。例如 `R=3、m=4、τ²=9、σ²=1` 时，正确方差为 `9/3+1/12≈3.083`；错误公式仅给出 `10/12≈0.833`。

这个层级模型只是解释为什么要先求运行均值的教学扩展，不要求通过它代替前面的课件试算法。它说明：<strong>观测数量多，不必然代表独立信息量也多。</strong>

## 6.9 当考试改变精度要求或比较对象时，公式怎样跟着变

### 6.9.1 绝对精度和相对精度有不同的分母

“要求区间半长不超过 1 分钟”给定的是绝对精度，直接比较 `h(R)≤1`；“要求半长不超过均值估计的 10%”给定的是相对精度，需要比较：

```math
\frac{h(R)}{|\overline Y|}\leq0.10
```

例如总均值为 10、半长为 1 时，相对半长为 `1/10=10%`。如果均值接近零，这个相对指标可能极不稳定甚至没有意义，因此不能在所有题目中机械地把绝对半长除以样本均值。若题目未说明“相对精度”，默认不应自行把绝对精度换成百分比。

### 6.9.2 比较两个系统时，应先决定能否配对

如果方案 A、B 使用共同随机数进行配对运行，正确的统计单位是每对的差值 `Dᵣ=Aᵣ−Bᵣ`。假设四次配对差分别是 `2、1、3、3`，则 `D̄=2.25`，差值方差为 `S_D²=2.75/3≈0.9167`。若给定 `t_{0.975}(3)=3.182`，可继续建立差值均值的近似 95% 置信区间：

```math
CI_{95\%}=2.25\pm3.182\sqrt{\frac{0.9167}{4}}
\approx(0.727,3.773)
```

这个区间估计的是两个方案的<strong>总体平均差</strong>，不是方案 A、B 各自均值的独立区间。配对比较利用的是同一随机场景中两个输出之间的相关性；如果两组样本实际上并未配对，则不能无依据地使用差值样本方差。

### 6.9.3 每次运行的结果必须对应同一个统计目标

构造独立重复的 `t` 区间之前，还要检查每一次运行的输出究竟是否是同一个随机变量。若一次统计的是前 30 分钟平均队长，另一次统计的是前 60 分钟平均队长，又将二者当作相同条件下的两次独立重复，那么即使两个数可以算平均，其共同估计目标也未必明确。

终态实验一般应固定相同的系统规则、初始条件、终止方式与指标定义；稳态实验则应进一步说明预热删除和收集阶段。随机数流要让不同重复彼此独立，但当明确采用共同随机数比较两种方案时，<strong>同一对方案之间的随机输入可以有意对应，独立性要求落在不同配对之间</strong>。
