## 8.1 仿真优化的基本概念（课件第 2—13 页）

### 8.1.1 一般优化问题由哪三部分组成

先考虑一个能够直接写出数学表达式的普通优化问题。课件第 2 页采用如下形式：

```math
\begin{aligned}
\min_{X}\quad &f(X)\\
\mathrm{s.t.}\quad &g(X)\leq0
\end{aligned}
```

这里，`X=(x₁,x₂,…,xₖ)` 是决策变量，代表研究者能够选择和调整的方案；`f(X)` 是目标函数，用来评价该方案的优劣；`g(X)≤0` 是约束条件，用来规定哪些方案能够实际采用。

所有满足约束的决策向量构成可行域：

```math
D=\{X\mid g(X)\leq0\}
```

因此，优化并不是简单地找到一个能让目标值下降的数值，而是要在可行域内找到目标函数尽可能小的方案。如果决策变量不满足资源、容量或运行条件，即使目标值看上去很好，也不能当作可行解。

### 8.1.2 为什么仿真优化与一般优化不同

普通优化问题往往假设目标函数与约束可以直接计算。例如给定 `X`，把它代入已知的 `f(X)` 就能得到结果。

课件第 3 页指出，很多实际系统的目标函数和约束无法用一个显式表达式表示。系统中可能包含随机到达、资源竞争、等待队列和复杂事件规则，只有实际运行仿真模型，才能估计某个决策方案对应的性能。

因此，仿真优化需要把仿真模型当作评价决策方案的工具：选择一组决策变量，运行模型获得性能响应，再依据响应决定下一步考察什么方案。

### 8.1.3 仿真模型中的可控因素与不可控因素

课件第 4 页把仿真模型写成：

```math
y(X,\omega)=y(x_1,x_2,\ldots,x_K;\omega)
```

其中：

| 符号 | 含义 | 在仿真中的作用 |
| --- | --- | --- |
| `X=(x₁,…,xₖ)` | 可控因素，也就是决策变量 | 研究者需要优化的设置 |
| `ω` | 不可控因素或随机扰动 | 随机到达、随机服务等可能引起的波动 |
| `y(X,ω)` | 仿真模型的输出 | 在给定方案和随机情景下生成的系统响应 |

模型输出可以是一个数字，也可以是一个包含若干指标的向量：

```math
y(X,\omega)=
\bigl(y_1(X,\omega),y_2(X,\omega),\ldots,y_p(X,\omega)\bigr)
```

例如，仿真一次可能同时得到平均等待时间、设备利用率和订单完成数量。最终要优化的性能指标，则可以由这些输出与决策变量共同确定：

```math
f\bigl(X,y(X,\omega)\bigr)
```

这也说明仿真输出 `y` 与目标函数 `f` 不是同一个概念。仿真可以产生多个输出，而优化问题需要明确以哪个指标、或者按照怎样的组合评价这些输出。

### 8.1.4 确定型与随机型仿真优化

课件第 6—7 页区分了两类问题，关键区别是相同的决策变量 `X` 是否总会得到相同输出。

确定型仿真优化不含不可控随机扰动。每个 `X` 对应一个确定的系统输出 `y(X)`，因此目标值也唯一确定：

```math
\begin{aligned}
\min_{X}\quad&f\bigl(X,y(X)\bigr)\\
\mathrm{s.t.}\quad&X\in D
\end{aligned}
```

随机型仿真优化含有不可控因素 `ω`。给定相同 `X`，换一组随机数运行模型，得到的 `y(X,ω)` 和目标响应仍可能变化。一次运行提供的只是一个随机样本，不能把它直接视为真实的期望性能。

此时课件用目标响应的条件期望作为优化目标：

```math
\boxed{
\begin{aligned}
\min_{X}\quad&F(X)
=E\bigl[f\bigl(X,y(X,\omega)\bigr)\mid X\bigr]\\
\mathrm{s.t.}\quad&X\in D
\end{aligned}
}
```

固定方案 `X` 后，每次运行得到的 `f(X,y(X,ω))` 称为一次目标响应。若进行 `R` 次相互独立的重复运行，分别得到响应 `Z₁(X),…,Zᵣ(X)`，可以计算样本平均来估计 `F(X)`：

```math
\widehat F_R(X)=\frac{1}{R}\sum_{r=1}^{R}Z_r(X)
```

重复运行的意义在于减少单次随机波动对性能判断的影响。此处的 `F(X)` 是理论期望目标，带帽子的 `F̂ᵣ(X)` 才是有限次仿真实验得到的估计量。

### 8.1.5 课件排队系统例子：先定义性能测度

课件第 8 页使用 `GI/G/1` 排队系统作为例子，服务规则为先到先服务（FIFO）。其中 `GI` 表示一般独立同分布的到达间隔，`G` 表示一般服务时间分布，`1` 表示一个服务台。

课件规定：

| 记号 | 含义 |
| --- | --- |
| `Dᵢ` | 第 `i` 位顾客从进入到离开系统的逗留时间 |
| `L(t)` | 时刻 `t` 系统内的顾客数量 |
| `X` | 平均服务时间，是可以调整的决策变量 |
| `Y(X)` | 所研究的平均系统逗留时间这一性能测度 |

请注意，`X` 是平均服务时间，不是服务率。如果缩短 `X`，意味着平均处理一位顾客所需时间减少，对应的服务率提高。

#### 终态仿真：第 N 位顾客完成服务时结束

课件第 9 页规定终止事件为第 `N` 位顾客完成服务。一次运行中，前 `N` 位顾客的平均系统逗留时间为：

```math
y(X,\omega)=\frac{1}{N}\sum_{i=1}^{N}D_i
```

由于终态仿真的输出可能与初始状态有关，若初始系统人数固定为 `L(0)=\ell_0`，所研究的性能可表示为：

```math
Y(X)=E\left[
\frac{1}{N}\sum_{i=1}^{N}D_i
\ \middle|\ L(0)=\ell_0
\right]
```

期望符号的意思是：在相同模型设置与初始状态下进行多次独立运行，再考察这些运行平均逗留时间的总体期望。不是只运行一次，然后把得到的平均数直接当作 `Y(X)`。

#### 稳态仿真：关注长期平均逗留时间

课件第 10 页把稳态性能表示为顾客数量持续增加时的长期平均：

```math
Y(X)=E\left[
\lim_{N\to\infty}
\frac{1}{N}\sum_{i=1}^{N}D_i
\right]
```

这与上一讲的稳态输出分析相对应：优化时要比较的是各方案的长期性能，而不是人为初始状态造成的暂时性差异。实际仿真时间有限，仍需要使用适当的稳态输出分析方法估计该长期指标。

### 8.1.6 以系统总成本为目标的排队优化模型

排队系统不仅要减少顾客逗留时间，也需要考虑提高服务能力的成本。课件第 11 页定义：

`C_C` 为顾客单位等待时间成本系数；`C_S` 为标准服务成本，即平均服务时间 `X=1` 时采用的服务成本基准。

课件采用下面的简化总成本函数：

```math
\boxed{F(X)=C_CY(X)+\frac{C_S}{X}}
```

第一项与平均逗留时间有关；第二项随 `X` 缩短而增加，体现提高服务速度需要付出的代价。因此，不能一味降低服务时间而不考虑资源成本。

设顾客平均到达率为 `λ`。为了避免平均服务时间过小或接近系统稳定边界，课件给出带有一个很小正数 `δ` 的可行范围：

```math
\boxed{
\begin{aligned}
\min_X\quad &C_CY(X)+\frac{C_S}{X}\\
\mathrm{s.t.}\quad&\delta\leq X\leq\frac{1}{\lambda}-\delta
\end{aligned}
}
```

这里 `λ` 是到达率，`1/λ` 是平均到达间隔。在单服务台系统中，如果平均服务时间 `X` 过大，以致 `λX` 接近或超过 1，系统将接近或越过稳定运行条件。`δ` 的作用是让可行区间避开零点和稳定边界。

### 8.1.7 M/M/1 特殊情形：为什么能求出解析最优解

对于一般 `GI/G/1`，课件指出平均逗留时间 `Y(X)` 往往没有简单解析表达式，需要仿真求估计值。但在特殊的 `M/M/1` 稳态情形下，可以使用已知的排队公式。

服务时间服从指数分布时，单服务台的平均服务率是：

```math
\mu=\frac{1}{X}
```

`M/M/1` 的平均系统逗留时间是 `1/(μ−λ)`，代入 `μ=1/X`，可得：

```math
\boxed{
Y(X)=\frac{1}{1/X-\lambda}
=\frac{X}{1-\lambda X}
}
```

因此总成本函数变为能够直接求导的形式：

```math
F(X)=C_C\frac{X}{1-\lambda X}+\frac{C_S}{X}
```

下面补齐课件第 12—13 页之间的计算步骤。

第一步，对第一项求导。使用商的求导法则：

```math
\frac{\mathrm d}{\mathrm dX}
\left(\frac{X}{1-\lambda X}\right)
=\frac{(1-\lambda X)+\lambda X}{(1-\lambda X)^2}
=\frac{1}{(1-\lambda X)^2}
```

第二步，对整个成本函数求导：

```math
F'(X)=\frac{C_C}{(1-\lambda X)^2}
-\frac{C_S}{X^2}
```

第三步，令一阶导数为零：

```math
\frac{C_C}{(1-\lambda X)^2}
=\frac{C_S}{X^2}
```

在 `0<X<1/λ` 且成本系数为正的范围内，两边都为正，可取正平方根：

```math
\frac{\sqrt{C_C}}{1-\lambda X}
=\frac{\sqrt{C_S}}{X}
```

第四步，交叉相乘并整理：

```math
\begin{aligned}
X\sqrt{C_C}&=(1-\lambda X)\sqrt{C_S}\\
X\bigl(\sqrt{C_C}+\lambda\sqrt{C_S}\bigr)
&=\sqrt{C_S}
\end{aligned}
```

于是得到课件第 13 页的解析最优点：

```math
\boxed{
X^*=\frac{1}{\lambda+\sqrt{C_C/C_S}}
}
```

这个结果说明：顾客时间成本系数 `C_C` 越大，越倾向于缩短最优平均服务时间；服务成本系数 `C_S` 越大，越倾向于延长平均服务时间，以减少投入。

在上述正成本系数及稳定范围内，二阶导数为：

```math
F''(X)=\frac{2\lambda C_C}{(1-\lambda X)^3}
+\frac{2C_S}{X^3}>0
```

因此，若 `X*` 落在给定可行区间内，它就是该成本函数在可行域中的最优解；若被约束排除，还需要比较相应可行边界。课件给出的 `X*` 是从无约束一阶条件求出的候选解，这一步检查能够避免把不可行点当成最优方案。

## 8.2 求解仿真优化问题的基本方法（课件第 14—35 页）

大多数仿真优化问题的目标函数没有可直接使用的解析式，随机响应还会造成估计误差，所以不能简单照搬传统的解析求导方法。课件介绍了直接搜索技术和响应曲面法。

### 8.2.1 直接搜索技术的基本思想

直接搜索（Direct Search）的特点是寻找改进方案时不需要预先知道目标函数的导数。对于只能通过运行模型估计性能的仿真优化问题，这一特点很有价值。

课件第 16 页将搜索过程分成两个动作：

局部探测搜索：在当前方案附近试探不同方向，判断是否存在能够改善目标函数的移动方向。

模式搜索：在找到可能改进的方向后，沿这一方向采用一定步长移动，形成新的候选方案。

每个候选点都需要运行仿真模型，得到相应的性能指标估计值，然后与当前方案比较。对于随机型仿真，比较时应尽量采用一致的重复运行和统计精度，避免仅凭某次随机波动判断方案优劣。

课件第 17 页给出的整体算法流程可以写成：

1. 设定初始可行解及搜索参数。
2. 在当前方案运行仿真，获得性能指标。
3. 判断是否达到规定的停止或最优性条件。
4. 如果尚未达到条件，探测可能改善的方向。
5. 构造并评价新的可行解，再返回第 2 步。

这里的“最优条件”在没有解析目标函数的场景中通常是算法采用的停止判断，不能仅凭算法停止就断言已经找到了全局最优解。

### 8.2.2 模式搜索法：基点、步长与坐标方向

课件第 18—22 页进一步介绍模式搜索法。设决策向量包含 `K` 个分量：

```math
X=(x_1,x_2,\ldots,x_K)
```

首先选定初始基点 `b₁` 和初始步长 `δ`。对第 `j` 个坐标方向，令：

```math
\delta_j=(0,\ldots,0,\underbrace{\delta}_{j\text{th}},0,\ldots,0)
```

`δⱼ` 只改变第 `j` 个决策分量，其余分量不变。这样就可以依次判断每一个坐标方向上的正向或反向移动是否改善目标函数。

课件用 `Y(b₁)` 表示在基点 `b₁` 通过仿真得到的性能响应。若模型随机，实际比较的是运行后得到的统计估计，而不是一个没有误差的确定值。

### 8.2.3 第一轮探测：正向、反向与保留原点

第一步，从基点 `b₁` 出发，沿第一个坐标方向作正向探测，候选点为：

```math
X^+=b_1+\delta_1
```

如果 `Y(X⁺)≤Y(b₁)`，说明这个正向点不比基点差，课件将它选作本轮参考点 `t₁,₁`。

如果正向不能改进，再沿同一个方向尝试反向候选点：

```math
X^-=b_1-\delta_1
```

如果 `Y(X⁻)≤Y(b₁)`，则取 `t₁,₁=X⁻`；如果两个方向均不能改进，就保留原基点，即 `t₁,₁=b₁`。

这一轮的选择规则可写为：

```math
t_{1,1}=\begin{cases}
b_1+\delta_1,
&Y(b_1+\delta_1)\leq Y(b_1),\\[4pt]
b_1-\delta_1,
&Y(b_1+\delta_1)>Y(b_1),\ 
Y(b_1-\delta_1)\leq Y(b_1),\\[4pt]
b_1,&\text{otherwise}.
\end{cases}
```

在此过程中还必须检查候选点是否位于可行域内。不可行的候选点不能因为目标函数可能更小就直接接受。

### 8.2.4 沿其他坐标方向继续探测

课件第 20 页将上述规则推广到所有坐标方向。假设已经得到第 `j−1` 次探测后的参考点 `t₁,ⱼ₋₁`，则从这个更新后的参考点出发，分别检查：

```math
t_{1,j-1}+\delta_j,
\qquad t_{1,j-1}-\delta_j
```

若正向降低目标值，则接受正向点；否则检查反向；如果两个方向都不能改善，就保持原点。依次完成 `j=1,2,…,K` 个分量的探测，最终得到本轮参考点 `t₁,ₖ`。

需要注意，每一个分量的探测起点是上一个分量探测后的参考点，而不是始终退回最初的 `b₁`。如果前一个坐标方向已经带来改进，后一个方向是在改进后的方案基础上继续尝试。

### 8.2.5 更新基点与模式移动

探测完所有分量后，将最终参考点与原基点比较。课件第 21 页的判断是：

```math
b_2=\begin{cases}
t_{1,K},&Y(t_{1,K})<Y(b_1),\\
b_1,&\text{otherwise}.
\end{cases}
```

如果整轮坐标探测找到了改进点 `b₂`，则用两个基点的差 `b₂−b₁` 表示本次观察到的有效移动方向，并构造模式移动点：

```math
\boxed{t_{2,0}=b_1+2(b_2-b_1)}
```

这相当于从 `b₂` 出发，再沿 `b₂−b₁` 的方向前进一步。这样做的目的，是在已经找到改进趋势的情况下，尝试走得更远，而不必从头重新沿每一个方向搜索。

课件第 22 页进一步比较模式点与当前新基点。如果：

```math
Y(t_{2,0})<Y(b_2)
```

且模式点可行，就可以将 `b₂` 更新为 `t₂,₀`。若模式点没有改善，则保留原来的 `b₂`，继续下一轮探测。

### 8.2.6 当前步长找不到改进时怎么办

如果相邻两轮基点没有变化，即：

```math
b_{i+1}=b_i
```

表示在当前探测步长下，没有找到可以改善目标的方向。课件的处理方法是缩小步长：

```math
\boxed{\delta_{\mathrm{new}}=
\lambda_s\delta_{\mathrm{old}}},
\qquad 0\leq\lambda_s\leq1
```

课件将这个缩步长比例记作 `λ`。这里用 `λₛ` 区分它与前面排队系统的到达率，两者不是同一个参数。通常选取小于 1 的正比例，使下一轮能够在更小的邻域内寻找改进。

按照课件第 22 页，重复局部探测、模式移动和步长调整，直到不能进一步找到符合精度要求的改进方案为止。

这一方法的主要计算逻辑不是解方程，而是“提出候选点—运行仿真—比较性能—更新决策点”。因此，掌握每一步的参考点和比较对象，比记住算法名称更重要。

### 8.2.7 响应曲面法：用可计算的函数近似真实仿真响应

课件第 23 页介绍第二种方法：响应曲面法（Response Surface Methodology）。

假设需要优化的系统性能可以写为某个未知多元函数：

```math
Y(X)=Y(x_1,x_2,\ldots,x_K)
```

虽然不知道 `Y` 的解析表达式，但给定一组决策变量 `X`，可以通过仿真实验得到相应的目标响应估计。变量空间中的每一个 `X` 都称为一个试验点；试验点及其性能响应构成需要考察的响应曲面。

优化的任务，是在这个响应曲面上寻找满足约束的较优位置。对于课件采用的最小化问题，要寻找的是较低的响应值；如果原问题是最大化收益，则要寻找较高的响应值。

课件第 25 页将目标写为：

```math
\begin{aligned}
\min_X\quad &Y(X)=E\bigl[y(X,f(X,\omega))\mid X\bigr]\\
\mathrm{s.t.}\quad &X\in D
\end{aligned}
```

这说明响应曲面是随机型仿真优化中目标期望与决策变量之间的关系；它不是某一次随机运行的单个数据点。

### 8.2.8 从泰勒展开理解一阶与二阶响应曲面

课件第 26—29 页使用泰勒展开说明，为什么可以用较简单的多项式近似原本没有解析表达式的目标函数。

设目标函数在某个基准点 `X⁰=(x₁⁰,…,xₖ⁰)` 附近连续可微，并满足进行二阶展开所需的光滑性条件。定义每个分量的变化量：

```math
\Delta x_i=x_i-x_i^0
```

在基准点附近，二阶泰勒近似可写为：

```math
\begin{aligned}
Y(X)\approx{}&Y(X^0)
+\sum_{i=1}^{K}\left.\frac{\partial Y}{\partial x_i}
\right|_{X^0}\Delta x_i\\
&+\frac{1}{2}\sum_{i=1}^{K}\sum_{j=1}^{K}
\left.\frac{\partial^2Y}{\partial x_i\partial x_j}
\right|_{X^0}\Delta x_i\Delta x_j
\end{aligned}
```

第一行包含常数项与一次项，第二行则包含平方项和不同变量之间的交互项。将相应的系数统一记为 `β`，便得到课件讨论的两类响应曲面。

一阶响应曲面：

```math
\boxed{Y_1(X)=\beta_0+\sum_{i=1}^{K}\beta_i x_i}
```

二阶响应曲面：

```math
\boxed{
Y_2(X)=\beta_0+
\sum_{i=1}^{K}\beta_i x_i+
\sum_{i=1}^{K}\sum_{j=1}^{K}\beta_{ij}x_i x_j
}
```

这里的 `β` 系数不是已经知道的真实物理参数，而是根据仿真实验得到的响应数据估计出来的近似函数系数。

一阶曲面只能描述局部的线性变化趋势；二阶曲面可以描述弯曲的趋势，以及多个决策变量共同变化时的交互作用。因此，当目标接近极值点、曲面的弯曲程度变得重要时，二阶近似通常更合适。

### 8.2.9 响应曲面法的两阶段逼近过程

课件第 30—34 页的核心是分阶段逼近真实响应曲面，两个阶段的目标和仿真投入不同。

第一阶段：初始点离极值点较远。课件认为，在这一阶段可以先用一阶响应曲面描述局部趋势，再依据一阶曲面的梯度寻找下降方向，沿该方向移动到新的试验区域。

对一阶曲面：

```math
Y_1(X)=\beta_0+\beta_1x_1+\cdots+\beta_Kx_K
```

其梯度就是各个一次项系数组成的向量：

```math
\nabla Y_1(X)=(\beta_1,\ldots,\beta_K)^{\mathsf T}
```

对于最小化目标，在可行条件允许的情况下，可以沿负梯度方向寻找下降趋势。移动以后，重新设计试验点并拟合新的局部一阶曲面，直到当前的一阶近似不能充分描述响应变化为止。

第一阶段可能需要多次迭代，因此课件强调应尽量控制每次迭代中的重复仿真次数，以提高搜索效率。

第二阶段：搜索已进入接近极值点的区域。一阶平面可能无法表现局部弯曲形态，需要使用二阶响应曲面进行更细致的近似，再利用二阶模型分析极值位置。

第二阶段的重点不再是频繁进行大范围方向搜索，而是提高局部响应估计的准确性。课件因此建议通过较多次独立重复运行，获得更可靠的响应数据，以便较准确地确定优化解。

在同一优化过程中，两个阶段的安排可以概括为：先用较简单的一阶曲面确定改进方向并向较优区域移动，再用二阶曲面细化极值位置。

### 8.2.10 响应曲面法的优点与不足

课件第 35 页指出，响应曲面法的优点是通用性强，因为它不要求事先写出目标函数的解析式，而是用仿真获得试验点的响应，再对目标函数进行近似。

主要不足是计算效率可能偏低。每次估计目标函数的改进方向，需要在多个试验点重复运行仿真；当模型单次运行时间较长、决策变量数量较多时，这部分实验成本可能很高。

这也引出最后一节的问题：既然仿真目标函数往往无法直接求导，怎样在尽量减少仿真运行次数的情况下估计梯度？

## 8.3 仿真优化中的梯度估计（课件第 36—40 页）

### 8.3.1 梯度代表什么，为什么需要估计

对于包含 `K` 个决策变量的目标函数，梯度是它分别对每个决策分量的一阶偏导数组成的向量：

```math
\nabla Y(X)=\left(
\frac{\partial Y}{\partial x_1},
\frac{\partial Y}{\partial x_2},
\ldots,
\frac{\partial Y}{\partial x_K}
\right)^{\mathsf T}
```

梯度的第 `k` 个分量表示：在其他决策变量保持不变、只对第 `k` 个变量作很小调整时，目标函数在局部如何变化。

但在仿真优化中，目标函数通常不能写成显式公式，因此无法直接对它求导。课件第 36 页提出用仿真实验去估计梯度，接着介绍两种有限差分方法。

### 8.3.2 有限差分法（Finite Differences）

有限差分法的思想是：在当前点附近向某个坐标方向移动一小段距离，比较移动前后的目标响应，用变化量除以变量变化幅度，近似得到偏导数。

课件第 37—38 页使用的是中心差分。设当前决策向量为 `Xⁱ`，用于扰动的正数步长为 `cᵢ`，第 `k` 个标准基向量为：

```math
e_k=(0,\ldots,0,1,0,\ldots,0)^{\mathsf T}
```

其中仅第 `k` 个分量为 1。对第 `k` 个方向，分别考察两组决策方案：

```math
X^i+c_i e_k,
\qquad X^i-c_i e_k
```

运行仿真后，得到这两个点的目标响应估计 `Ŷ`。第 `k` 个梯度分量可用下式近似：

```math
\boxed{
\widehat{\nabla_kY}(X^i)=
\frac{\widehat Y(X^i+c_i e_k)
-\widehat Y(X^i-c_i e_k)}{2c_i}
},\quad k=1,2,\ldots,K
```

分子是目标响应的变化，分母 `2cᵢ` 是正向点与反向点在第 `k` 个坐标上的距离。两侧取点的目的，是估计当前点在该方向上的局部斜率。

如果一共有 `K` 个决策变量，每个方向需要正、反两个试验点，因此估计整条梯度向量共需要：

```math
\boxed{2K}
```

例如变量数增加，所需评价次数就随 `K` 线性增加。课件特别提醒这一计算成本。这里的 `2K` 是每个方向一正一反的基本评价次数；如果每个点还需要独立重复仿真来稳定响应估计，实际运行次数会进一步增加。

### 8.3.3 同步扰动有限差分法（SPSA）

课件第 39—40 页介绍同步扰动有限差分法。它与普通中心差分的主要区别，是不再对每一个坐标方向分别构造一对仿真点，而是一次同时扰动所有决策变量。

设第 `i` 次迭代中生成随机扰动向量：

```math
\Delta_i=(\Delta_{i1},\Delta_{i2},\ldots,\Delta_{iK})^{\mathsf T}
```

课件要求这些扰动分量满足一定条件，并且相互独立同分布。为了能使用下面的公式，分母中的每个 `Δᵢₖ` 都必须非零。

给定当前决策点 `Xⁱ` 和步长 `cᵢ`，只构造两个同时扰动全部分量的候选点：

```math
X^i+c_i\Delta_i,
\qquad X^i-c_i\Delta_i
```

运行两次仿真，得到两个目标响应估计。对任意第 `k` 个梯度分量，课件给出的估计公式为：

```math
\boxed{
\widehat{\nabla_kY}(X^i)=
\frac{\widehat Y(X^i+c_i\Delta_i)
-\widehat Y(X^i-c_i\Delta_i)}{2c_i\Delta_{ik}}
},\quad k=1,2,\ldots,K
```

理解这个公式时，最重要的细节是：无论要求第几个梯度分量，分子始终是相同的两个仿真结果之差，只有分母中的 `Δᵢₖ` 随分量 `k` 改变。

因此，哪怕有很多决策变量，估计整条梯度也只需要在两组扰动方案下评价目标响应：

```math
\boxed{2}
```

这就是同步扰动法相较于逐坐标有限差分法的计算优势。它不是说两个仿真结果能够精确给出真实梯度，而是利用随机扰动构造梯度估计，使每轮梯度估计所需的仿真评价次数不随变量数量 `K` 增长。

### 8.3.4 课件中两种梯度估计方法的对应关系

| 比较项目 | 普通有限差分法 | 同步扰动有限差分法 |
| --- | --- | --- |
| 扰动方式 | 每次只改变一个决策分量 | 一次同时扰动所有决策分量 |
| 第 `k` 个分量的计算 | 使用第 `k` 个方向独有的一对响应值 | 各分量共享同一对响应值 |
| 梯度向量的基本评价次数 | `2K` | `2` |
| 课件强调的特点 | 直接用邻近点的差近似偏导 | 降低高维梯度估计的评价次数 |

两种方法都服务于同一个目的：当仿真模型无法给出解析目标函数时，通过有限次仿真实验估计目标函数在当前方案附近的变化方向。

## 8.4 优化模型怎样从管理问题中建立起来

课件第 2—7 页的抽象符号已经完整，但如果只记住“目标函数、决策变量、约束”三个名词，实际建模时仍然容易把它们混在一起。下面把同一个服务系统从业务问题逐步写成数学模型。

### 8.4.1 先确定什么可以改变，什么只能观察

假设一家物流分拣站要调整服务能力，希望控制订单等待成本及新增处理能力成本。站点不能改变订单真实到达的时刻，却可以安排服务台数量、处理速度和排班时间。此时各类变量的角色分别是：

| 业务对象 | 数学角色 | 举例 |
| --- | --- | --- |
| 服务台数量 | 决策变量 | `m∈{1,2,3,4}` |
| 单台设备的平均处理时间 | 决策变量 | `X`，单位为分钟/件 |
| 顾客到达间隔 | 不可控随机输入 | 由现场数据拟合的分布产生 |
| 每件货物实际处理时间 | 不可控随机输入，分布参数受决策影响 | 例如均值取 `X` 的某个服务时间分布 |
| 平均排队时间、平均系统逗留时间 | 仿真输出 | 每次运行由事件过程计算 |
| 等待损失加设备投入 | 优化目标 | 在可行方案中尽可能小 |
| 人员上限、预算、稳定性 | 约束条件 | 例如服务台至多 4 台 |

首先要保证量纲与含义一致。平均处理时间是时间，服务率是其倒数。如果 `X=0.5` 分钟/件，那么服务率就是每分钟 2 件，不能在成本函数中把 `X` 又解释成服务率。

其次，不能把仿真输出直接当成决策变量。例如平均等待时间取决于到达流量、资源配置和排队规则，建模人员一般不能直接命令模型“等待时间等于 1 分钟”。他能改变的是资源方案，然后观察等待时间是否下降。

### 8.4.2 从一组仿真响应到一个目标函数

设在方案 `X` 下，第 `r` 次独立重复运行产生目标成本 `Z_r(X)`。若成本主要由平均逗留时间与资源费用构成，可以采用：

```math
Z_r(X)=C_C\overline D_r(X)+C_S(X)
```

其中 `\overline D_r(X)` 是这一轮的平均系统逗留时间，`C_S(X)` 是资源成本。方案真正需要比较的是该成本的期望值：

```math
F(X)=E[Z_r(X)]
```

有限次仿真能直接得到的是估计量：

```math
\widehat F_R(X)=\frac{1}{R}\sum_{r=1}^{R}Z_r(X)
```

如果题目给出方案 A 的一次仿真成本为 90、方案 B 的一次仿真成本为 88，不能马上断言 B 的期望成本更低。两次输出可能来自不同随机扰动；在较大随机波动下，2 个单位的差异不一定稳定。第六讲的独立重复、置信区间和配对比较，正好可以用于这一阶段。

### 8.4.3 随机约束与普通约束不是一回事

课件将可行域记为 `D`，在基础例题中通常直接判断方案是否满足参数边界。但实际问题还可能要求“发生严重拥堵的概率不能超过 5%”。这类约束与 `m≤4` 不同，因为即使固定方案，也只能通过随机运行估计违反约束的概率。

例如可以将服务水平要求表示为：

```math
P\bigl(W_q(X)>10\bigr)\leq0.05
```

这里的 `W_q(X)` 指在相应抽样机制下定义的顾客等待时间，具体是单个顾客还是一次运行的平均值，建模时必须事先说明。该式属于概率约束的扩展示例，并非课件要求证明的内容。它提醒我们：有些方案的固定资源约束完全可行，但仍可能不能满足服务水平要求。

## 8.5 M/M/1 成本优化完整计算题

课件第 11—13 页给出了最常用的解析案例。前面的笔记已经推导了最优平均服务时间，现在把它变成一道可以直接作答的计算题。

### 8.5.1 题目：求最优平均服务时间和最低总成本

设顾客到达过程和服务时间均符合 `M/M/1` 假设，到达率为 `λ=0.5` 人/分钟，单位顾客系统逗留时间成本为 `C_C=16`，标准服务成本系数为 `C_S=4`。将平均服务时间 `X` 作为决策变量，使用课件给出的总成本函数：

```math
F(X)=16Y(X)+\frac{4}{X}
```

已知系统稳定要求 `0<X<2`。求最优平均服务时间、对应服务率，以及最低总成本。

<strong>第一步，写出逗留时间函数。</strong>

```math
Y(X)=\frac{X}{1-0.5X}
```

因此：

```math
F(X)=16\frac{X}{1-0.5X}+\frac{4}{X}
```

<strong>第二步，求一阶导数并令其为零。</strong>

```math
F'(X)=\frac{16}{(1-0.5X)^2}-\frac{4}{X^2}
```

```math
\frac{16}{(1-0.5X)^2}=\frac{4}{X^2}
```

在稳定区域内取正平方根并整理：

```math
\frac{4}{1-0.5X}=\frac{2}{X}
```

```math
4X=2-X
\quad\Longrightarrow\quad
\boxed{X^*=0.4}
```

这也可以直接代入课件的最优点公式：

```math
X^*=\frac{1}{0.5+\sqrt{16/4}}=0.4
```

<strong>第三步，检查可行性。</strong>由于 `0<0.4<2`，候选点处于稳定范围内。第二导数在该范围为正，因此这是该凸成本函数的最小值点。

<strong>第四步，计算对应服务率。</strong>

```math
\mu^*=\frac{1}{X^*}=\frac{1}{0.4}=2.5
```

因此，最优平均服务时间是 0.4 分钟/人，最优平均服务率是 2.5 人/分钟，两者不能互换单位。

<strong>第五步，计算目标函数。</strong>

```math
Y(0.4)=\frac{0.4}{1-0.5\times0.4}=0.5
```

```math
F(0.4)=16\times0.5+\frac{4}{0.4}
=8+10=\boxed{18}
```

为了核对，把附近几个方案也代入：

| 平均服务时间 `X` | 平均系统逗留时间 `Y(X)` | 总成本 `F(X)` |
| ---: | ---: | ---: |
| 0.25 | 0.2857 | 20.5714 |
| 0.40 | 0.5000 | 18.0000 |
| 0.50 | 0.6667 | 18.6667 |

可以看到，服务速度并不是越快越好。若进一步缩短 `X`，虽然顾客逗留时间变少，但服务能力投入成本 `4/X` 增加得更快；若放慢服务速度，资源投入减少，但顾客逗留成本上升。

### 8.5.2 进阶：如果解析最优点不在允许范围内

继续使用上述参数，但假设设备受技术约束，平均服务时间只能在 `[0.6,1.4]` 分钟/人之间选择。刚刚求出的无约束最优点 `X*=0.4` 已经不满足条件。

因为成本函数在稳定区间内严格凸，并且在 `X>0.4` 时递增，所以限制在 `[0.6,1.4]` 以后，最小值出现在左边界：

```math
\boxed{X^*_{\mathrm{feasible}}=0.6}
```

相应成本为：

```math
F(0.6)=16\frac{0.6}{1-0.5\times0.6}
+\frac{4}{0.6}
\approx20.381
```

这个例子说明，令导数为零只是在寻找内部最优候选点。最后还必须检查候选点是否符合约束；若不符合，要在可行边界或其他可能的最优位置继续比较。

### 8.5.3 课件成本函数的一个语义边界

`Y(X)` 在这个模型中明确指平均<strong>系统逗留时间</strong>，包含排队等待与接受服务两部分。课件将 `C_C` 称为顾客单位等待时间成本，又用 `C_CY(X)` 计算费用。按本讲的数学模型进行考试计算时，应遵照课件给出的函数；如果用于真实项目，则需要明确成本究竟按纯排队时间 `W_q` 还是按整个系统逗留时间 `W` 计费。

两者在 `M/M/1` 下满足：

```math
W_q=W-X
```

若业务只对排队等待计费，目标函数就会发生改变，最优方案也可能改变。不能在解释上说只计排队等待，却在计算上包含服务时间而不作说明。

## 8.6 模式搜索法：完整的二维计算示例

课件第 18—22 页的步骤容易停留在抽象符号 `b_i`、`t_{i,j}`、`\delta_j` 上。下面选用一个可手算的目标函数，完整展示第一次局部探测、模式移动和下一次探测。实际仿真优化时，函数值应由仿真估计；这里给出解析表达式，只是为了能够逐项核对算法。

设需要最小化：

```math
Y(x_1,x_2)=(x_1-1)^2+2(x_2+2)^2
```

以 `b_1=(0,0)` 为初始基点，初始步长为 `δ=1`。两个坐标方向的扰动向量分别是：

```math
\delta_1=(1,0),\qquad\delta_2=(0,1)
```

<strong>第一步，评价基点。</strong>

```math
Y(0,0)=(0-1)^2+2(0+2)^2=9
```

<strong>第二步，沿第一坐标方向探测。</strong>先做正向移动：

```math
b_1+\delta_1=(1,0)
```

```math
Y(1,0)=0+2\times2^2=8<9
```

正向已经改善目标，于是保留参考点：

```math
t_{1,1}=(1,0)
```

按照课件的正向优先规则，此时不必再尝试第一个坐标方向的反向点。

<strong>第三步，在刚得到的参考点上探测第二坐标。</strong>注意，起点已经从 `(0,0)` 更新成 `(1,0)`。

正向候选点为：

```math
t_{1,1}+\delta_2=(1,1),
\qquad Y(1,1)=18
```

由于 `18>8`，正向未改善。再考察反向候选点：

```math
t_{1,1}-\delta_2=(1,-1),
\qquad Y(1,-1)=2
```

由于 `2<8`，接受反向点，得到：

```math
t_{1,2}=(1,-1)
```

<strong>第四步，更新基点。</strong>两轮坐标探测完成，比较 `Y(t_{1,2})=2` 与 `Y(b_1)=9`，得到：

```math
b_2=(1,-1)
```

<strong>第五步，计算模式移动点。</strong>课件给出的模式移动公式是：

```math
t_{2,0}=b_1+2(b_2-b_1)
```

代入数值：

```math
t_{2,0}=(0,0)+2[(1,-1)-(0,0)]=(2,-2)
```

```math
Y(2,-2)=(2-1)^2+0=1
```

因为 `1<2`，模式移动点优于刚得到的基点，因而可以进一步采用 `(2,-2)` 作为新的搜索位置。

<strong>第六步，继续在新位置做局部探测。</strong>沿第一个坐标反向移动一步得到 `(1,-2)`：

```math
Y(1,-2)=(1-1)^2+2(-2+2)^2=0
```

这个例子中，`(1,-2)` 已达到目标函数的理论全局最小值；实际黑箱仿真场景通常无法预先知道全局最优点，因此要根据步长、评价精度与停止规则判断是否继续搜索。

把上述过程放在同一张表内：

| 步骤 | 候选点 | 目标值 | 处理结果 |
| --- | --- | ---: | --- |
| 初始基点 | `(0,0)` | 9 | 作为参考 |
| 第 1 方向正向 | `(1,0)` | 8 | 改善，接受 |
| 第 2 方向正向 | `(1,1)` | 18 | 变差，不接受 |
| 第 2 方向反向 | `(1,-1)` | 2 | 改善，更新 `b₂` |
| 模式移动 | `(2,-2)` | 1 | 继续改善 |
| 后续局部探测 | `(1,-2)` | 0 | 本例达到最小值 |

这个算法的关键是每次比较时的<strong>基准点</strong>。第 2 方向的正反探测要以 `(1,0)` 为基准；模式移动要使用两个基点的差；不能把所有候选点都与最初的 `(0,0)` 比较，否则很容易在复杂流程中接受错误的方案。

### 8.6.1 为什么搜索步长会影响结果

步长太大，可能直接跨过局部较优区域；步长太小，可能需要很多次评价才能移动到较远区域。当当前步长的正反方向都不能改善目标时，课件采用缩小步长的做法：

```math
\delta_{\mathrm{new}}=\lambda_s\delta_{\mathrm{old}},
\qquad0<\lambda_s<1
```

例如初始 `δ=1`，取缩步系数 `λ_s=0.5`，则下一轮试探步长改为 `0.5`。若进一步需要精细搜索，可以再次缩为 `0.25`。是否缩步还应结合随机仿真输出的可信度判断：如果只是由于随机误差看不出改善，过早缩步可能导致算法停留在不合适的位置。

### 8.6.2 随机型模式搜索必须处理比较误差

假设某次搜索中，两个候选方案的仿真估计成本分别为 `10.1` 和 `9.9`。如果每个估计的标准误都为 `1.0`，这 0.2 的差距可能不足以支持明确的优劣判断。直接把单次估计较低的方案当作更优，会增加错误移动的概率。

在计算预算允许时，可以对相近方案增加独立重复次数、使用公共随机数进行配对比较，或为候选差值建立置信区间。直接搜索不需要目标函数导数，但它仍然需要合理地处理仿真输出不确定性。

## 8.7 响应曲面法：从试验点拟合出可优化的函数

### 8.7.1 一个变量的二次响应曲面怎么算

假设有一个连续决策变量 `x`，通过仿真试验得到三个设计点的平均响应：

| 决策变量 `x` | 估计平均响应 `Y(x)` |
| ---: | ---: |
| 1 | 2 |
| 2 | 1 |
| 3 | 2 |

为了得到一个能反映弯曲趋势的局部近似，设响应曲面为：

```math
\widehat Y_2(x)=\beta_0+\beta_1x+\beta_2x^2
```

三个点恰好提供三个方程：

```math
\begin{aligned}
\beta_0+\beta_1+\beta_2&=2\\
\beta_0+2\beta_1+4\beta_2&=1\\
\beta_0+3\beta_1+9\beta_2&=2
\end{aligned}
```

用第二个方程减去第一个方程，再用第三个减去第二个：

```math
\begin{aligned}
\beta_1+3\beta_2&=-1\\
\beta_1+5\beta_2&=1
\end{aligned}
```

两式相减可得 `2β₂=2`，所以 `β₂=1`；代回第一条差分方程得到 `β₁=-4`，再代回原方程得到 `β₀=5`。因此拟合曲面为：

```math
\boxed{\widehat Y_2(x)=5-4x+x^2}
```

若要最小化拟合曲面的响应，对近似函数求导：

```math
\frac{\mathrm d\widehat Y_2}{\mathrm dx}
=-4+2x
```

令导数为零，得到 `x=2`。二阶导数为 `2>0`，故这是该二次近似的最小值点，对应估计响应为 `1`。

这里必须区分：我们只是找到了<strong>拟合曲面</strong>的最优点，并非自动证明真实仿真期望目标也在 `x=2` 处取得全局最优。实际中应在候选最优点附近增加试验、用独立重复估计验证，必要时重新拟合局部曲面。

### 8.7.2 二变量二阶响应曲面包含哪些系数

当决策变量有两个时，常见的完整二次近似形式是：

```math
\widehat Y_2(x_1,x_2)=
\beta_0+\beta_1x_1+\beta_2x_2
+\beta_{11}x_1^2+\beta_{22}x_2^2
+\beta_{12}x_1x_2
```

其中，`x₁x₂` 是交互项，用来描述一个变量的变化如何改变另一个变量对响应的影响。不能只写两个平方项而遗漏交互项，然后把模型称为完整的二阶曲面。

如果拟合结果可写成矩阵形式：

```math
\widehat Y_2(X)=\beta_0+b^{\mathsf T}X
+\frac{1}{2}X^{\mathsf T}HX
```

那么梯度和 Hessian 矩阵分别为：

```math
\nabla\widehat Y_2(X)=b+HX,
\qquad
\nabla^2\widehat Y_2(X)=H
```

若 `H` 正定且无约束，候选极小点满足：

```math
b+HX^*=0
\quad\Longrightarrow\quad
X^*=-H^{-1}b
```

这属于二阶曲面的常用解析处理。若 `H` 非正定，驻点可能是极大点或鞍点；若有变量边界、整数限制或其他约束，还需把候选点放回实际可行域内检查。

### 8.7.3 为什么要在一阶曲面与二阶曲面之间切换

一阶曲面只有斜率信息，适合描述某个局部区域里“往哪个方向改变决策更可能下降”；但是一个平面本身通常没有内部极小点，无法完整描述曲面的转折。

二阶曲面能够反映弯曲程度，在接近极值点时有利于估计极值位置；代价是需要估计更多系数。`K` 个决策变量的完整二次响应面（含常数、一次项、平方与两两交互）共有：

```math
1+K+K+\frac{K(K-1)}{2}
=\frac{(K+1)(K+2)}{2}
```

个回归系数。例如 `K=2` 时有 6 个系数，`K=5` 时有 21 个系数。原则上，试验点的设计矩阵必须具备足够的秩才能识别这些系数；即使点数刚好够用，也未必足以评估拟合误差与随机波动。

在实际仿真中，往往通过设计多个试验点、对每点进行若干重复，再用回归估计曲面系数。接近极值区域时应增加重复运行，以免拟合出的曲率主要来自仿真噪声而非系统真实规律。

## 8.8 普通有限差分与 SPSA：同一道题的完整计算

课件最后两页的关键不是记住两个分式，而是理解它们分别扰动哪些变量、需要多少次仿真，以及每个梯度分量从何而来。下面使用同一个二变量目标函数比较两种算法。

### 8.8.1 已知函数与需要估计的位置

设目标函数为：

```math
Y(x_1,x_2)=x_1^2+3x_2^2
```

需要在当前点 `X=(1,2)` 估计梯度，差分步长取 `c=0.1`。为便于核对，本题真实梯度可以直接求出：

```math
\nabla Y(X)=\begin{pmatrix}2x_1\\6x_2\end{pmatrix}
```

所以：

```math
\nabla Y(1,2)=\begin{pmatrix}2\\12\end{pmatrix}
```

真实仿真优化问题通常没有这个解析式，下面则分别假设只能通过输入决策变量、运行模型来得到目标值。

### 8.8.2 普通中心有限差分：逐个坐标扰动

先估计第一个分量。保持 `x₂=2` 不变，只把 `x₁` 调成 `1.1` 和 `0.9`。

```math
Y(1.1,2)=1.1^2+3\times2^2=13.21
```

```math
Y(0.9,2)=0.9^2+3\times2^2=12.81
```

因此：

```math
\widehat{\nabla_1Y}(1,2)
=\frac{13.21-12.81}{2\times0.1}
=\boxed{2}
```

再估计第二个分量。保持 `x₁=1` 不变，把 `x₂` 调成 `2.1` 和 `1.9`。

```math
Y(1,2.1)=1+3\times2.1^2=14.23
```

```math
Y(1,1.9)=1+3\times1.9^2=11.83
```

因此：

```math
\widehat{\nabla_2Y}(1,2)
=\frac{14.23-11.83}{2\times0.1}
=\boxed{12}
```

两次正向、两次反向，共 4 次目标函数评价，得到：

```math
\boxed{\widehat{\nabla Y}(1,2)=(2,12)^{\mathsf T}}
```

该例恰好是二次函数，中心差分在无噪声的情况下给出精确导数。对一般非二次目标函数，它只是近似；对于随机仿真，每个点的目标值还包含抽样误差。

### 8.8.3 SPSA：所有坐标同时扰动，只做两次评价

采用常见的双点对称扰动方案，令每个扰动分量独立地以相同概率取 `+1` 或 `-1`。先假设这一次抽到：

```math
\Delta=(1,-1)^{\mathsf T}
```

同步扰动后的正向点是：

```math
X+c\Delta=(1,2)+0.1(1,-1)=(1.1,1.9)
```

反向点是：

```math
X-c\Delta=(0.9,2.1)
```

只计算这两个目标函数值：

```math
Y(1.1,1.9)=1.1^2+3\times1.9^2=12.04
```

```math
Y(0.9,2.1)=0.9^2+3\times2.1^2=14.04
```

因此，两个方向公用的分子为：

```math
Y(X+c\Delta)-Y(X-c\Delta)=12.04-14.04=-2
```

第一个分量的扰动值为 `Δ₁=1`：

```math
\widehat{\nabla_1Y}(X)
=\frac{-2}{2\times0.1\times1}
=\boxed{-10}
```

第二个分量的扰动值为 `Δ₂=-1`：

```math
\widehat{\nabla_2Y}(X)
=\frac{-2}{2\times0.1\times(-1)}
=\boxed{10}
```

所以，这一次 SPSA 估计给出：

```math
\boxed{\widehat{\nabla Y}(X)=(-10,10)^{\mathsf T}}
```

这是本讲需要特别理解的结果：SPSA 的单次梯度估计可以与真实梯度 `(2,12)` 差很多，即使被评价的目标函数没有任何仿真噪声。这不是公式错误，而是用一个同时扰动方向估计多维梯度，本来就会混入其他方向的信息。

### 8.8.4 再做一次 SPSA，看看随机方向为什么有用

现在改用另一组扰动：

```math
\Delta'=(1,1)^{\mathsf T}
```

两次评价对应的点是 `(1.1,2.1)` 与 `(0.9,1.9)`：

```math
Y(1.1,2.1)=1.21+3\times4.41=14.44
```

```math
Y(0.9,1.9)=0.81+3\times3.61=11.64
```

相减得到 `2.8`。两分量的扰动都取 `1`，故各自梯度估计为：

```math
\widehat{\nabla Y}_{\Delta'}(X)
=\left(\frac{2.8}{0.2},\frac{2.8}{0.2}\right)^{\mathsf T}
=(14,14)^{\mathsf T}
```

将这两次随机扰动的梯度估计取平均：

```math
\frac{(-10,10)+(14,14)}{2}
=(2,12)
```

在这个特意选择的无噪声二次函数例题中，两种扰动方向平均后刚好得到真实梯度；在一般问题中不能指望只做两轮就能精确恢复梯度。SPSA 的统计原理是：通过满足相应对称性和矩条件的随机扰动，使不同坐标方向的交叉影响在适当意义下平均抵消，并在优化迭代过程中利用带噪声的梯度估计。

### 8.8.5 两种方法的评价次数比较

若模型有 `K` 个连续决策变量，每次函数评价又需要 `R` 次独立重复仿真才能获得稳定的目标估计，那么一轮中心有限差分至少需要 `2KR` 次仿真，一轮 SPSA 需要 `2R` 次仿真。

| 决策变量维度 | 有限差分的评价点数 | SPSA 的评价点数 | 若每点重复 10 次：有限差分 / SPSA |
| ---: | ---: | ---: | --- |
| `K=2` | 4 | 2 | 40 / 20 |
| `K=10` | 20 | 2 | 200 / 20 |
| `K=50` | 100 | 2 | 1000 / 20 |

这说明 SPSA 的优势主要体现为高维情况下每轮评价次数较少；它的单次梯度估计通常更不稳定，因此不能仅凭评价次数少就断言总体优化效率一定更高。优化表现还取决于噪声水平、步长选择、重复次数和迭代次数。

### 8.8.6 步长越小，梯度估计一定越准确吗

对一个足够光滑的确定性目标函数，中心差分的截断误差通常随步长的平方缩小：

```math
\text{bias of central difference}=O(c^2)
```

因此，在没有评价噪声时，减小 `c` 往往能够改善局部导数近似；但是随机仿真还有另一种误差来源。

设正、反两个试验点分别运行 `R` 次独立重复，两个样本均值的方差均为 `σ²/R`，并且两个点的估计误差相互独立。那么中心差分估计量的方差为：

```math
\begin{aligned}
\operatorname{Var}(\widehat g)
&=\frac{\operatorname{Var}(\widehat Y_+)
+\operatorname{Var}(\widehat Y_-)}{(2c)^2}\\
&=\frac{2\sigma^2/R}{4c^2}
=\frac{\sigma^2}{2Rc^2}
\end{aligned}
```

步长 `c` 越小，分母 `2c` 越小，同样大小的随机误差便会被进一步放大。此时会出现一种取舍：减小步长有助于降低有限差分的近似偏差，却可能提高梯度估计的方差。通常需要结合重复次数 `R`、噪声水平和函数平滑程度选择步长。

如果两侧仿真使用公共随机数，正反点的估计误差可能正相关，方差表达式中应再减去协方差项：

```math
\operatorname{Var}(\widehat g)
=\frac{\operatorname{Var}(\widehat Y_+)
+\operatorname{Var}(\widehat Y_-)
-2\operatorname{Cov}(\widehat Y_+,\widehat Y_-)}{4c^2}
```

当协方差为正时，可以缓解随机波动对差分结果的影响。这也是第六讲的公共随机数技术与第八讲的梯度估计能够联系起来的地方。正反点使用同一个随机数序列并不保证一定降低方差；实际效果取决于两组输出产生的相关关系。

## 8.9 公式和方法选择：按题目结构而不是按章节标题

| 已知条件或题目要求 | 适用思路 | 需要记住的关系 |
| --- | --- | --- |
| 给出目标、约束、可控因素，要求写模型 | 数学建模 | 决策变量、目标、可行域分别定义 |
| 相同决策输入会得到不同的响应 | 随机型仿真优化 | 优化的是目标响应的期望值 |
| 给出 `M/M/1` 到达率、逗留成本与服务成本 | 解析成本优化 | `Y=X/(1-λX)`，`X*=1/(λ+√(C_C/C_S))` |
| 没有解析目标函数，需要在相邻点搜索 | 直接搜索 | 正反探测、更新基点、模式移动、缩步长 |
| 有一组试验点及对应响应值 | 响应曲面法 | 一阶平面确定方向，二阶曲面刻画弯曲 |
| 需要估计 `K` 个偏导，逐个坐标正反扰动 | 中心有限差分 | `2K` 次基本目标评价 |
| 所有坐标同时以随机向量扰动 | SPSA | 所有梯度分量共享两次目标评价 |
| 想通过减小差分步长提高精度 | 偏差与方差权衡 | 截断误差可减小，仿真噪声放大风险增加 |

### 8.9.1 五道快速判断题

<strong>题目一。</strong>研究者调整服务台数量 `m`，固定 `m=3` 连续运行两次仿真，发现等待时间分别为 4.2 和 5.0 分钟。这一定属于确定型仿真优化吗？

参考判断：不是。相同决策输入产生不同响应，说明系统存在随机扰动或其他未固定因素，应按照随机型问题构造目标估计。

<strong>题目二。</strong>已知 `M/M/1` 系统平均服务时间 `X=0.6`，到达率 `λ=2`，可直接代入稳态公式 `X/(1-λX)` 求平均逗留时间吗？

参考判断：不能。此时 `λX=1.2>1`，违反稳态稳定性条件，公式不能作为有效的有限稳态平均逗留时间。

<strong>题目三。</strong>模式搜索在 `(1,2)` 的正向探测失败，是否应直接缩小步长？

参考判断：不能直接缩步。首先要按算法检查该坐标的反向移动，并继续其他坐标方向的探测；只有规定的整轮搜索未获得改善，才考虑相应缩步规则。

<strong>题目四。</strong>两个决策变量的二阶响应曲面只有 `1,x₁,x₂,x₁²,x₂²` 五项，是否已经包含完整的二次影响？

参考判断：没有，还缺少交互项 `x₁x₂`。其系数描述两个变量之间的交互影响。

<strong>题目五。</strong>SPSA 对 100 个决策变量只使用两次目标函数评价，是否意味着两次运行就能够得到真实的 100 维梯度？

参考判断：不是。它得到的是一次随机梯度估计；“2 次评价”指一次同步扰动下评价目标的基本次数，不保证估计精度，也不包括每点为减少仿真噪声而做的重复运行。

### 8.9.2 将前后章节连起来理解

第五讲决定怎样估计仿真输入分布；第六讲决定怎样估计某个固定方案的期望性能及不确定性；第七讲检查模型的程序逻辑和实际代表性；第八讲则在这些基础上使用模型比较和寻找更优方案。

如果输入分布失真、程序逻辑出错或者输出估计方差很大，那么即使优化算法在数学上执行正确，也可能找到错误的管理方案。因此，第八讲的算法选择不能脱离前几讲的输入分析、模型确认和输出统计。

## 8.10 决策变量只能取整数时：用重复仿真比较三个服务台方案

前面的 M/M/1 成本例题把平均服务时间当作连续决策变量，求导便可以得到解析候选点。但现实管理问题常常需要决定<strong>开设多少个服务台</strong>。服务台数量 `m` 只能取 `1、2、3、…`，不能因为连续优化计算出 `m=2.4`，就直接开设 2.4 台设备。

设某服务中心只能从 `m=1、2、3` 三种配置中选择。每台服务台在一个运营周期内的固定成本为 120 元；每增加 1 分钟的平均等待时间，按 30 元计入这一周期的综合等待损失。这里将每周期等待损失约定为 `30×W_q`，因此候选方案的期望成本模型为：

```math
C(m)=120m+30E\!\left[W_q(m)\right],
\qquad m\in\{1,2,3\}
```

这一目标函数是示例中人为规定的统一周期成本口径；它不等同于把每个顾客的等待成本直接相加。只有统一了成本单位，才可以正确比较不同方案。

### 8.10.1 同一组随机场景下的四次配对运行

为提高比较精度，三个方案使用相同编号的四组随机到达、服务需求场景。每行代表一组独立场景；同一行内三种方案的等待时间指标相互对应。

| 独立场景 | `m=1` 平均等待 | `m=2` 平均等待 | `m=3` 平均等待 |
| --- | ---: | ---: | ---: |
| 1 | 9 | 4 | 2 |
| 2 | 11 | 5 | 3 |
| 3 | 10 | 5 | 2 |
| 4 | 9 | 4 | 3 |
| 样本均值 | 9.75 | 4.50 | 2.50 |

由此估计三种方案的平均成本：

```math
\begin{aligned}
\widehat C(1)&=120+30(9.75)=412.5,\\
\widehat C(2)&=240+30(4.50)=375,\\
\widehat C(3)&=360+30(2.50)=435
\end{aligned}
```

按当前四组场景的样本均值，<strong>两个服务台方案成本最低</strong>。注意第三台服务台虽然进一步降低了等待时间，但节约的等待损失不足以抵消新增固定成本。这说明“等待时间最短”不必然等于“总成本最低”。

### 8.10.2 两种方案差多少，应优先比较同一场景的成本差

由于三种方案使用同一组随机场景，可以直接计算 `m=1` 与 `m=2` 的逐场景成本差：

```math
\begin{aligned}
D_r&=C_r(1)-C_r(2)\\
&=-120+30\left(W_{q,r}(1)-W_{q,r}(2)\right)
\end{aligned}
```

四个差值分别是 `30、60、30、30` 元，均值是 37.5 元，样本标准差为 15 元，标准误为 `15/√4=7.5` 元。若采用配对差值的 `t` 区间并给定 `t_{0.975}(3)=3.182`，可得：

```math
\begin{aligned}
CI_{95\%}
&=37.5\pm3.182\frac{15}{\sqrt4}\\
&\approx[13.64,61.37]
\end{aligned}
```

在独立场景与近似正态差值的假设下，这个区间完全大于零，表示 `m=1` 的平均成本比 `m=2` 更高。四次重复很少，区间适用性需要谨慎，但方法本身展示了第六讲的<strong>公共随机数法</strong>怎样用于第八讲的<strong>候选方案比较</strong>。

本例中的枚举比较适合候选数量很少的整数决策。如果有几十种排班方案或多个组合决策变量，穷举可能需要大量仿真运行，才需要进一步考虑搜索算法、近似响应曲面或者其他仿真优化方法。

## 8.11 随机约束：样本比例达标不等于可以确信方案可行

确定型约束可以写成 `m≤4`、`预算≤1000`，只要给定决策方案就能确定是否违反。但某些管理约束的执行结果本身随机，例如“顾客等待超过 8 分钟的概率不高于 5%”。这是一类<strong>机会约束（chance constraint）</strong>：

```math
P\!\left(W_q(m)>8\right)\leq0.05
```

这里 `W_q(m)` 专指随机抽取一名顾客的排队等待时间；第 8.10 节表格中的数值则是每次运行的平均等待时间。二者统计对象不同，不能将“某次运行的均值超过 8 分钟”直接当作“顾客等待超过 8 分钟”。

假设对某一服务配置收集到 `n=100` 个在本例中可视为独立、同分布的等待指标，其中 3 个超过 8 分钟，则超限概率的点估计为：

```math
\widehat p=\frac{3}{100}=0.03
```

从点估计看 `0.03<0.05`，但这不是“已证明超限概率小于 5%”。因为一次实验有有限样本，真实超限率即使高于 5%，也可能碰巧在这 100 个独立指标中只观察到 3 次超限。

若需要具有置信保障的可行性判断，可以给出超限概率的一侧置信上界。对独立伯努利指标，使用 Wilson 近似上界的一个计算形式为：

```math
p_U=
\frac{
\widehat p+\dfrac{z^2}{2n}
+z\sqrt{\dfrac{\widehat p(1-\widehat p)}{n}
+\dfrac{z^2}{4n^2}}
}{1+z^2/n}
```

取一侧 95% 置信水平的 `z=1.645`，代入 `n=100、p̂=0.03`：

```math
p_U\approx0.0727
```

因为上界约为 7.27%，并未低于约束阈值 5%，所以这批数据<strong>还不足以在该置信标准下确认可行</strong>。它也不意味着方案被证明不满足约束；若这个边界对决策重要，应增加独立样本量、改进试验设计或调整资源配置。

这里的 Wilson 公式属于第八讲随机约束的拓展训练，并非原课件指定的计算要求。考卷若只要求写出目标函数和约束条件，首先必须正确说明约束的是<strong>概率</strong>，而不是把每一次随机等待时间都强制写成 `W_q≤8`。

还要注意，如果数据来自同一次长时间仿真且顾客等待值序列存在相关性，就不能直接把原始的 100 个等待值当作独立伯努利样本。可以考虑足够独立的重复运行、批平均等适合数据结构的方法；直接套用独立比例公式可能低估误差。

## 8.12 排队系统接近满负荷时，为什么梯度会变得很大

第八讲的有限差分与 SPSA 都围绕一个问题：决策变量发生小变化时，系统目标会改变多少。对于排队系统，这种变化可能非常不均匀。靠近系统容量极限时，服务时间增加一点，等待时间却可能大幅上升。

以第 8.1 节的 `M/M/1` 系统为例，设顾客到达率 `λ` 固定，平均服务时长 `X` 为可控连续变量。在稳态存在的条件 `0<λX<1` 下，平均排队等待时间为：

```math
W_q(X)=\frac{\lambda X^2}{1-\lambda X}
```

这里必须区分平均<strong>排队等待时间</strong> `W_q` 和平均<strong>系统逗留时间</strong> `W`：

```math
W(X)=\frac{X}{1-\lambda X},
\qquad W_q(X)=W(X)-X
```

对 `W_q(X)` 使用商法则求导：

```math
\begin{aligned}
\frac{dW_q}{dX}
&=\frac{2\lambda X(1-\lambda X)
+\lambda^2X^2}{(1-\lambda X)^2}\\
&=\frac{\lambda X(2-\lambda X)}{(1-\lambda X)^2}
\end{aligned}
```

取 `λ=2` 次/分钟、`X=0.4` 分钟，则服务台利用率 `ρ=λX=0.8`，平均排队等待时间为：

```math
W_q(0.4)=\frac{2(0.4)^2}{1-2(0.4)}
=\frac{0.32}{0.2}=1.6
```

因此平均排队等待时间为 1.6 分钟。

此处的导数值为：

```math
\left.\frac{dW_q}{dX}\right|_{X=0.4}
=\frac{2(0.4)[2-2(0.4)]}{[1-2(0.4)]^2}
=24
```

因此，若平均服务时长在该点附近增加 `0.01` 分钟，按一阶近似，平均排队等待时间可能增加约 `24×0.01=0.24` 分钟。这里的 24 是局部导数，不是保证在任意幅度变化下都成立的固定倍数。

随着 `λX` 趋近 1，分母 `(1-λX)²` 趋近零，梯度绝对值可能急剧增大；一旦 `λX≥1`，原来的有限稳态均值公式便不再适用。此时若使用有限差分计算梯度，不仅要选择合适的扰动步长，还必须检查<strong>正反扰动后的点是否均落在稳定可行域内</strong>。例如 `λ=2` 时 `X<0.5` 才满足稳态条件，不能在 `X=0.49` 处使用 `c=0.02` 的对称中心差分，因为 `X+c=0.51` 已经越过稳定边界。

这一分析说明梯度估计题不仅要把数代进公式，还应先检查函数定义域、系统稳定性和决策约束。尤其在接近容量上限时，仿真输入的微小估计误差和输出的随机波动，都更容易影响最终优化判断。
