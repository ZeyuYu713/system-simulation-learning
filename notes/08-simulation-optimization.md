## 8.1 仿真优化的基本概念（课件第 2—13 页）

### 8.1.1 一般优化问题由哪三部分组成

先考虑一个能够直接写出数学表达式的普通优化问题。课件第 2 页采用如下形式：

```math
\begin{aligned}
\min_{X}\quad &f(X)\\
\mathrm{s.t.}\quad &g(X)\leq0
\end{aligned}
```

这里，`X=(x₁,x₂,…,xₖ)` 是决策变量，代表研究者能够选择和调整的方案；`f(X)` 是目标函数，用来评价该方案的优劣；`g(X)≤0` 是约束条件，用来规定哪些方案能够实际采用。

所有满足约束的决策向量构成可行域：

```math
D=\{X\mid g(X)\leq0\}
```

因此，优化并不是简单地找到一个能让目标值下降的数值，而是要在可行域内找到目标函数尽可能小的方案。如果决策变量不满足资源、容量或运行条件，即使目标值看上去很好，也不能当作可行解。

### 8.1.2 为什么仿真优化与一般优化不同

普通优化问题往往假设目标函数与约束可以直接计算。例如给定 `X`，把它代入已知的 `f(X)` 就能得到结果。

课件第 3 页指出，很多实际系统的目标函数和约束无法用一个显式表达式表示。系统中可能包含随机到达、资源竞争、等待队列和复杂事件规则，只有实际运行仿真模型，才能估计某个决策方案对应的性能。

因此，仿真优化需要把仿真模型当作评价决策方案的工具：选择一组决策变量，运行模型获得性能响应，再依据响应决定下一步考察什么方案。

### 8.1.3 仿真模型中的可控因素与不可控因素

课件第 4 页把仿真模型写成：

```math
y(X,\omega)=y(x_1,x_2,\ldots,x_K;\omega)
```

其中：

| 符号 | 含义 | 在仿真中的作用 |
| --- | --- | --- |
| `X=(x₁,…,xₖ)` | 可控因素，也就是决策变量 | 研究者需要优化的设置 |
| `ω` | 不可控因素或随机扰动 | 随机到达、随机服务等可能引起的波动 |
| `y(X,ω)` | 仿真模型的输出 | 在给定方案和随机情景下生成的系统响应 |

模型输出可以是一个数字，也可以是一个包含若干指标的向量：

```math
y(X,\omega)=
\bigl(y_1(X,\omega),y_2(X,\omega),\ldots,y_p(X,\omega)\bigr)
```

例如，仿真一次可能同时得到平均等待时间、设备利用率和订单完成数量。最终要优化的性能指标，则可以由这些输出与决策变量共同确定：

```math
f\bigl(X,y(X,\omega)\bigr)
```

这也说明仿真输出 `y` 与目标函数 `f` 不是同一个概念。仿真可以产生多个输出，而优化问题需要明确以哪个指标、或者按照怎样的组合评价这些输出。

### 8.1.4 确定型与随机型仿真优化

课件第 6—7 页区分了两类问题，关键区别是相同的决策变量 `X` 是否总会得到相同输出。

确定型仿真优化不含不可控随机扰动。每个 `X` 对应一个确定的系统输出 `y(X)`，因此目标值也唯一确定：

```math
\begin{aligned}
\min_{X}\quad&f\bigl(X,y(X)\bigr)\\
\mathrm{s.t.}\quad&X\in D
\end{aligned}
```

随机型仿真优化含有不可控因素 `ω`。给定相同 `X`，换一组随机数运行模型，得到的 `y(X,ω)` 和目标响应仍可能变化。一次运行提供的只是一个随机样本，不能把它直接视为真实的期望性能。

此时课件用目标响应的条件期望作为优化目标：

```math
\boxed{
\begin{aligned}
\min_{X}\quad&F(X)
=E\bigl[f\bigl(X,y(X,\omega)\bigr)\mid X\bigr]\\
\mathrm{s.t.}\quad&X\in D
\end{aligned}
}
```

固定方案 `X` 后，每次运行得到的 `f(X,y(X,ω))` 称为一次目标响应。若进行 `R` 次相互独立的重复运行，分别得到响应 `Z₁(X),…,Zᵣ(X)`，可以计算样本平均来估计 `F(X)`：

```math
\widehat F_R(X)=\frac{1}{R}\sum_{r=1}^{R}Z_r(X)
```

重复运行的意义在于减少单次随机波动对性能判断的影响。此处的 `F(X)` 是理论期望目标，带帽子的 `F̂ᵣ(X)` 才是有限次仿真实验得到的估计量。

### 8.1.5 课件排队系统例子：先定义性能测度

课件第 8 页使用 `GI/G/1` 排队系统作为例子，服务规则为先到先服务（FIFO）。其中 `GI` 表示一般独立同分布的到达间隔，`G` 表示一般服务时间分布，`1` 表示一个服务台。

课件规定：

| 记号 | 含义 |
| --- | --- |
| `Dᵢ` | 第 `i` 位顾客从进入到离开系统的逗留时间 |
| `L(t)` | 时刻 `t` 系统内的顾客数量 |
| `X` | 平均服务时间，是可以调整的决策变量 |
| `Y(X)` | 所研究的平均系统逗留时间这一性能测度 |

请注意，`X` 是平均服务时间，不是服务率。如果缩短 `X`，意味着平均处理一位顾客所需时间减少，对应的服务率提高。

#### 终态仿真：第 N 位顾客完成服务时结束

课件第 9 页规定终止事件为第 `N` 位顾客完成服务。一次运行中，前 `N` 位顾客的平均系统逗留时间为：

```math
y(X,\omega)=\frac{1}{N}\sum_{i=1}^{N}D_i
```

由于终态仿真的输出可能与初始状态有关，若初始系统人数固定为 `L(0)=\ell_0`，所研究的性能可表示为：

```math
Y(X)=E\left[
\frac{1}{N}\sum_{i=1}^{N}D_i
\ \middle|\ L(0)=\ell_0
\right]
```

期望符号的意思是：在相同模型设置与初始状态下进行多次独立运行，再考察这些运行平均逗留时间的总体期望。不是只运行一次，然后把得到的平均数直接当作 `Y(X)`。

#### 稳态仿真：关注长期平均逗留时间

课件第 10 页把稳态性能表示为顾客数量持续增加时的长期平均：

```math
Y(X)=E\left[
\lim_{N\to\infty}
\frac{1}{N}\sum_{i=1}^{N}D_i
\right]
```

这与上一讲的稳态输出分析相对应：优化时要比较的是各方案的长期性能，而不是人为初始状态造成的暂时性差异。实际仿真时间有限，仍需要使用适当的稳态输出分析方法估计该长期指标。

### 8.1.6 以系统总成本为目标的排队优化模型

排队系统不仅要减少顾客逗留时间，也需要考虑提高服务能力的成本。课件第 11 页定义：

`C_C` 为顾客单位等待时间成本系数；`C_S` 为标准服务成本，即平均服务时间 `X=1` 时采用的服务成本基准。

课件采用下面的简化总成本函数：

```math
\boxed{F(X)=C_CY(X)+\frac{C_S}{X}}
```

第一项与平均逗留时间有关；第二项随 `X` 缩短而增加，体现提高服务速度需要付出的代价。因此，不能一味降低服务时间而不考虑资源成本。

设顾客平均到达率为 `λ`。为了避免平均服务时间过小或接近系统稳定边界，课件给出带有一个很小正数 `δ` 的可行范围：

```math
\boxed{
\begin{aligned}
\min_X\quad &C_CY(X)+\frac{C_S}{X}\\
\mathrm{s.t.}\quad&\delta\leq X\leq\frac{1}{\lambda}-\delta
\end{aligned}
}
```

这里 `λ` 是到达率，`1/λ` 是平均到达间隔。在单服务台系统中，如果平均服务时间 `X` 过大，以致 `λX` 接近或超过 1，系统将接近或越过稳定运行条件。`δ` 的作用是让可行区间避开零点和稳定边界。

### 8.1.7 M/M/1 特殊情形：为什么能求出解析最优解

对于一般 `GI/G/1`，课件指出平均逗留时间 `Y(X)` 往往没有简单解析表达式，需要仿真求估计值。但在特殊的 `M/M/1` 稳态情形下，可以使用已知的排队公式。

服务时间服从指数分布时，单服务台的平均服务率是：

```math
\mu=\frac{1}{X}
```

`M/M/1` 的平均系统逗留时间是 `1/(μ−λ)`，代入 `μ=1/X`，可得：

```math
\boxed{
Y(X)=\frac{1}{1/X-\lambda}
=\frac{X}{1-\lambda X}
}
```

因此总成本函数变为能够直接求导的形式：

```math
F(X)=C_C\frac{X}{1-\lambda X}+\frac{C_S}{X}
```

下面补齐课件第 12—13 页之间的计算步骤。

第一步，对第一项求导。使用商的求导法则：

```math
\frac{\mathrm d}{\mathrm dX}
\left(\frac{X}{1-\lambda X}\right)
=\frac{(1-\lambda X)+\lambda X}{(1-\lambda X)^2}
=\frac{1}{(1-\lambda X)^2}
```

第二步，对整个成本函数求导：

```math
F'(X)=\frac{C_C}{(1-\lambda X)^2}
-\frac{C_S}{X^2}
```

第三步，令一阶导数为零：

```math
\frac{C_C}{(1-\lambda X)^2}
=\frac{C_S}{X^2}
```

在 `0<X<1/λ` 且成本系数为正的范围内，两边都为正，可取正平方根：

```math
\frac{\sqrt{C_C}}{1-\lambda X}
=\frac{\sqrt{C_S}}{X}
```

第四步，交叉相乘并整理：

```math
\begin{aligned}
X\sqrt{C_C}&=(1-\lambda X)\sqrt{C_S}\\
X\bigl(\sqrt{C_C}+\lambda\sqrt{C_S}\bigr)
&=\sqrt{C_S}
\end{aligned}
```

于是得到课件第 13 页的解析最优点：

```math
\boxed{
X^*=\frac{1}{\lambda+\sqrt{C_C/C_S}}
}
```

这个结果说明：顾客时间成本系数 `C_C` 越大，越倾向于缩短最优平均服务时间；服务成本系数 `C_S` 越大，越倾向于延长平均服务时间，以减少投入。

在上述正成本系数及稳定范围内，二阶导数为：

```math
F''(X)=\frac{2\lambda C_C}{(1-\lambda X)^3}
+\frac{2C_S}{X^3}>0
```

因此，若 `X*` 落在给定可行区间内，它就是该成本函数在可行域中的最优解；若被约束排除，还需要比较相应可行边界。课件给出的 `X*` 是从无约束一阶条件求出的候选解，这一步检查能够避免把不可行点当成最优方案。

## 8.2 求解仿真优化问题的基本方法（课件第 14—35 页）

大多数仿真优化问题的目标函数没有可直接使用的解析式，随机响应还会造成估计误差，所以不能简单照搬传统的解析求导方法。课件介绍了直接搜索技术和响应曲面法。

### 8.2.1 直接搜索技术的基本思想

直接搜索（Direct Search）的特点是寻找改进方案时不需要预先知道目标函数的导数。对于只能通过运行模型估计性能的仿真优化问题，这一特点很有价值。

课件第 16 页将搜索过程分成两个动作：

局部探测搜索：在当前方案附近试探不同方向，判断是否存在能够改善目标函数的移动方向。

模式搜索：在找到可能改进的方向后，沿这一方向采用一定步长移动，形成新的候选方案。

每个候选点都需要运行仿真模型，得到相应的性能指标估计值，然后与当前方案比较。对于随机型仿真，比较时应尽量采用一致的重复运行和统计精度，避免仅凭某次随机波动判断方案优劣。

课件第 17 页给出的整体算法流程可以写成：

1. 设定初始可行解及搜索参数。
2. 在当前方案运行仿真，获得性能指标。
3. 判断是否达到规定的停止或最优性条件。
4. 如果尚未达到条件，探测可能改善的方向。
5. 构造并评价新的可行解，再返回第 2 步。

这里的“最优条件”在没有解析目标函数的场景中通常是算法采用的停止判断，不能仅凭算法停止就断言已经找到了全局最优解。

### 8.2.2 模式搜索法：基点、步长与坐标方向

课件第 18—22 页进一步介绍模式搜索法。设决策向量包含 `K` 个分量：

```math
X=(x_1,x_2,\ldots,x_K)
```

首先选定初始基点 `b₁` 和初始步长 `δ`。对第 `j` 个坐标方向，令：

```math
\delta_j=(0,\ldots,0,\underbrace{\delta}_{j\text{th}},0,\ldots,0)
```

`δⱼ` 只改变第 `j` 个决策分量，其余分量不变。这样就可以依次判断每一个坐标方向上的正向或反向移动是否改善目标函数。

课件用 `Y(b₁)` 表示在基点 `b₁` 通过仿真得到的性能响应。若模型随机，实际比较的是运行后得到的统计估计，而不是一个没有误差的确定值。

### 8.2.3 第一轮探测：正向、反向与保留原点

第一步，从基点 `b₁` 出发，沿第一个坐标方向作正向探测，候选点为：

```math
X^+=b_1+\delta_1
```

如果 `Y(X⁺)≤Y(b₁)`，说明这个正向点不比基点差，课件将它选作本轮参考点 `t₁,₁`。

如果正向不能改进，再沿同一个方向尝试反向候选点：

```math
X^-=b_1-\delta_1
```

如果 `Y(X⁻)≤Y(b₁)`，则取 `t₁,₁=X⁻`；如果两个方向均不能改进，就保留原基点，即 `t₁,₁=b₁`。

这一轮的选择规则可写为：

```math
t_{1,1}=\begin{cases}
b_1+\delta_1,
&Y(b_1+\delta_1)\leq Y(b_1),\\[4pt]
b_1-\delta_1,
&Y(b_1+\delta_1)>Y(b_1),\ 
Y(b_1-\delta_1)\leq Y(b_1),\\[4pt]
b_1,&\text{otherwise}.
\end{cases}
```

在此过程中还必须检查候选点是否位于可行域内。不可行的候选点不能因为目标函数可能更小就直接接受。

### 8.2.4 沿其他坐标方向继续探测

课件第 20 页将上述规则推广到所有坐标方向。假设已经得到第 `j−1` 次探测后的参考点 `t₁,ⱼ₋₁`，则从这个更新后的参考点出发，分别检查：

```math
t_{1,j-1}+\delta_j,
\qquad t_{1,j-1}-\delta_j
```

若正向降低目标值，则接受正向点；否则检查反向；如果两个方向都不能改善，就保持原点。依次完成 `j=1,2,…,K` 个分量的探测，最终得到本轮参考点 `t₁,ₖ`。

需要注意，每一个分量的探测起点是上一个分量探测后的参考点，而不是始终退回最初的 `b₁`。如果前一个坐标方向已经带来改进，后一个方向是在改进后的方案基础上继续尝试。

### 8.2.5 更新基点与模式移动

探测完所有分量后，将最终参考点与原基点比较。课件第 21 页的判断是：

```math
b_2=\begin{cases}
t_{1,K},&Y(t_{1,K})<Y(b_1),\\
b_1,&\text{otherwise}.
\end{cases}
```

如果整轮坐标探测找到了改进点 `b₂`，则用两个基点的差 `b₂−b₁` 表示本次观察到的有效移动方向，并构造模式移动点：

```math
\boxed{t_{2,0}=b_1+2(b_2-b_1)}
```

这相当于从 `b₂` 出发，再沿 `b₂−b₁` 的方向前进一步。这样做的目的，是在已经找到改进趋势的情况下，尝试走得更远，而不必从头重新沿每一个方向搜索。

课件第 22 页进一步比较模式点与当前新基点。如果：

```math
Y(t_{2,0})<Y(b_2)
```

且模式点可行，就可以将 `b₂` 更新为 `t₂,₀`。若模式点没有改善，则保留原来的 `b₂`，继续下一轮探测。

### 8.2.6 当前步长找不到改进时怎么办

如果相邻两轮基点没有变化，即：

```math
b_{i+1}=b_i
```

表示在当前探测步长下，没有找到可以改善目标的方向。课件的处理方法是缩小步长：

```math
\boxed{\delta_{\mathrm{new}}=
\lambda_s\delta_{\mathrm{old}}},
\qquad 0\leq\lambda_s\leq1
```

课件将这个缩步长比例记作 `λ`。这里用 `λₛ` 区分它与前面排队系统的到达率，两者不是同一个参数。通常选取小于 1 的正比例，使下一轮能够在更小的邻域内寻找改进。

按照课件第 22 页，重复局部探测、模式移动和步长调整，直到不能进一步找到符合精度要求的改进方案为止。

这一方法的主要计算逻辑不是解方程，而是“提出候选点—运行仿真—比较性能—更新决策点”。因此，掌握每一步的参考点和比较对象，比记住算法名称更重要。

### 8.2.7 响应曲面法：用可计算的函数近似真实仿真响应

课件第 23 页介绍第二种方法：响应曲面法（Response Surface Methodology）。

假设需要优化的系统性能可以写为某个未知多元函数：

```math
Y(X)=Y(x_1,x_2,\ldots,x_K)
```

虽然不知道 `Y` 的解析表达式，但给定一组决策变量 `X`，可以通过仿真实验得到相应的目标响应估计。变量空间中的每一个 `X` 都称为一个试验点；试验点及其性能响应构成需要考察的响应曲面。

优化的任务，是在这个响应曲面上寻找满足约束的较优位置。对于课件采用的最小化问题，要寻找的是较低的响应值；如果原问题是最大化收益，则要寻找较高的响应值。

课件第 25 页将目标写为：

```math
\begin{aligned}
\min_X\quad &Y(X)=E\bigl[y(X,f(X,\omega))\mid X\bigr]\\
\mathrm{s.t.}\quad &X\in D
\end{aligned}
```

这说明响应曲面是随机型仿真优化中目标期望与决策变量之间的关系；它不是某一次随机运行的单个数据点。

### 8.2.8 从泰勒展开理解一阶与二阶响应曲面

课件第 26—29 页使用泰勒展开说明，为什么可以用较简单的多项式近似原本没有解析表达式的目标函数。

设目标函数在某个基准点 `X⁰=(x₁⁰,…,xₖ⁰)` 附近连续可微，并满足进行二阶展开所需的光滑性条件。定义每个分量的变化量：

```math
\Delta x_i=x_i-x_i^0
```

在基准点附近，二阶泰勒近似可写为：

```math
\begin{aligned}
Y(X)\approx{}&Y(X^0)
+\sum_{i=1}^{K}\left.\frac{\partial Y}{\partial x_i}
\right|_{X^0}\Delta x_i\\
&+\frac{1}{2}\sum_{i=1}^{K}\sum_{j=1}^{K}
\left.\frac{\partial^2Y}{\partial x_i\partial x_j}
\right|_{X^0}\Delta x_i\Delta x_j
\end{aligned}
```

第一行包含常数项与一次项，第二行则包含平方项和不同变量之间的交互项。将相应的系数统一记为 `β`，便得到课件讨论的两类响应曲面。

一阶响应曲面：

```math
\boxed{Y_1(X)=\beta_0+\sum_{i=1}^{K}\beta_i x_i}
```

二阶响应曲面：

```math
\boxed{
Y_2(X)=\beta_0+
\sum_{i=1}^{K}\beta_i x_i+
\sum_{i=1}^{K}\sum_{j=1}^{K}\beta_{ij}x_i x_j
}
```

这里的 `β` 系数不是已经知道的真实物理参数，而是根据仿真实验得到的响应数据估计出来的近似函数系数。

一阶曲面只能描述局部的线性变化趋势；二阶曲面可以描述弯曲的趋势，以及多个决策变量共同变化时的交互作用。因此，当目标接近极值点、曲面的弯曲程度变得重要时，二阶近似通常更合适。

### 8.2.9 响应曲面法的两阶段逼近过程

课件第 30—34 页的核心是分阶段逼近真实响应曲面，两个阶段的目标和仿真投入不同。

第一阶段：初始点离极值点较远。课件认为，在这一阶段可以先用一阶响应曲面描述局部趋势，再依据一阶曲面的梯度寻找下降方向，沿该方向移动到新的试验区域。

对一阶曲面：

```math
Y_1(X)=\beta_0+\beta_1x_1+\cdots+\beta_Kx_K
```

其梯度就是各个一次项系数组成的向量：

```math
\nabla Y_1(X)=(\beta_1,\ldots,\beta_K)^{\mathsf T}
```

对于最小化目标，在可行条件允许的情况下，可以沿负梯度方向寻找下降趋势。移动以后，重新设计试验点并拟合新的局部一阶曲面，直到当前的一阶近似不能充分描述响应变化为止。

第一阶段可能需要多次迭代，因此课件强调应尽量控制每次迭代中的重复仿真次数，以提高搜索效率。

第二阶段：搜索已进入接近极值点的区域。一阶平面可能无法表现局部弯曲形态，需要使用二阶响应曲面进行更细致的近似，再利用二阶模型分析极值位置。

第二阶段的重点不再是频繁进行大范围方向搜索，而是提高局部响应估计的准确性。课件因此建议通过较多次独立重复运行，获得更可靠的响应数据，以便较准确地确定优化解。

在同一优化过程中，两个阶段的安排可以概括为：先用较简单的一阶曲面确定改进方向并向较优区域移动，再用二阶曲面细化极值位置。

### 8.2.10 响应曲面法的优点与不足

课件第 35 页指出，响应曲面法的优点是通用性强，因为它不要求事先写出目标函数的解析式，而是用仿真获得试验点的响应，再对目标函数进行近似。

主要不足是计算效率可能偏低。每次估计目标函数的改进方向，需要在多个试验点重复运行仿真；当模型单次运行时间较长、决策变量数量较多时，这部分实验成本可能很高。

这也引出最后一节的问题：既然仿真目标函数往往无法直接求导，怎样在尽量减少仿真运行次数的情况下估计梯度？

## 8.3 仿真优化中的梯度估计（课件第 36—40 页）

### 8.3.1 梯度代表什么，为什么需要估计

对于包含 `K` 个决策变量的目标函数，梯度是它分别对每个决策分量的一阶偏导数组成的向量：

```math
\nabla Y(X)=\left(
\frac{\partial Y}{\partial x_1},
\frac{\partial Y}{\partial x_2},
\ldots,
\frac{\partial Y}{\partial x_K}
\right)^{\mathsf T}
```

梯度的第 `k` 个分量表示：在其他决策变量保持不变、只对第 `k` 个变量作很小调整时，目标函数在局部如何变化。

但在仿真优化中，目标函数通常不能写成显式公式，因此无法直接对它求导。课件第 36 页提出用仿真实验去估计梯度，接着介绍两种有限差分方法。

### 8.3.2 有限差分法（Finite Differences）

有限差分法的思想是：在当前点附近向某个坐标方向移动一小段距离，比较移动前后的目标响应，用变化量除以变量变化幅度，近似得到偏导数。

课件第 37—38 页使用的是中心差分。设当前决策向量为 `Xⁱ`，用于扰动的正数步长为 `cᵢ`，第 `k` 个标准基向量为：

```math
e_k=(0,\ldots,0,1,0,\ldots,0)^{\mathsf T}
```

其中仅第 `k` 个分量为 1。对第 `k` 个方向，分别考察两组决策方案：

```math
X^i+c_i e_k,
\qquad X^i-c_i e_k
```

运行仿真后，得到这两个点的目标响应估计 `Ŷ`。第 `k` 个梯度分量可用下式近似：

```math
\boxed{
\widehat{\nabla_kY}(X^i)=
\frac{\widehat Y(X^i+c_i e_k)
-\widehat Y(X^i-c_i e_k)}{2c_i}
},\quad k=1,2,\ldots,K
```

分子是目标响应的变化，分母 `2cᵢ` 是正向点与反向点在第 `k` 个坐标上的距离。两侧取点的目的，是估计当前点在该方向上的局部斜率。

如果一共有 `K` 个决策变量，每个方向需要正、反两个试验点，因此估计整条梯度向量共需要：

```math
\boxed{2K}
```

例如变量数增加，所需评价次数就随 `K` 线性增加。课件特别提醒这一计算成本。这里的 `2K` 是每个方向一正一反的基本评价次数；如果每个点还需要独立重复仿真来稳定响应估计，实际运行次数会进一步增加。

### 8.3.3 同步扰动有限差分法（SPSA）

课件第 39—40 页介绍同步扰动有限差分法。它与普通中心差分的主要区别，是不再对每一个坐标方向分别构造一对仿真点，而是一次同时扰动所有决策变量。

设第 `i` 次迭代中生成随机扰动向量：

```math
\Delta_i=(\Delta_{i1},\Delta_{i2},\ldots,\Delta_{iK})^{\mathsf T}
```

课件要求这些扰动分量满足一定条件，并且相互独立同分布。为了能使用下面的公式，分母中的每个 `Δᵢₖ` 都必须非零。

给定当前决策点 `Xⁱ` 和步长 `cᵢ`，只构造两个同时扰动全部分量的候选点：

```math
X^i+c_i\Delta_i,
\qquad X^i-c_i\Delta_i
```

运行两次仿真，得到两个目标响应估计。对任意第 `k` 个梯度分量，课件给出的估计公式为：

```math
\boxed{
\widehat{\nabla_kY}(X^i)=
\frac{\widehat Y(X^i+c_i\Delta_i)
-\widehat Y(X^i-c_i\Delta_i)}{2c_i\Delta_{ik}}
},\quad k=1,2,\ldots,K
```

理解这个公式时，最重要的细节是：无论要求第几个梯度分量，分子始终是相同的两个仿真结果之差，只有分母中的 `Δᵢₖ` 随分量 `k` 改变。

因此，哪怕有很多决策变量，估计整条梯度也只需要在两组扰动方案下评价目标响应：

```math
\boxed{2}
```

这就是同步扰动法相较于逐坐标有限差分法的计算优势。它不是说两个仿真结果能够精确给出真实梯度，而是利用随机扰动构造梯度估计，使每轮梯度估计所需的仿真评价次数不随变量数量 `K` 增长。

### 8.3.4 课件中两种梯度估计方法的对应关系

| 比较项目 | 普通有限差分法 | 同步扰动有限差分法 |
| --- | --- | --- |
| 扰动方式 | 每次只改变一个决策分量 | 一次同时扰动所有决策分量 |
| 第 `k` 个分量的计算 | 使用第 `k` 个方向独有的一对响应值 | 各分量共享同一对响应值 |
| 梯度向量的基本评价次数 | `2K` | `2` |
| 课件强调的特点 | 直接用邻近点的差近似偏导 | 降低高维梯度估计的评价次数 |

两种方法都服务于同一个目的：当仿真模型无法给出解析目标函数时，通过有限次仿真实验估计目标函数在当前方案附近的变化方向。
