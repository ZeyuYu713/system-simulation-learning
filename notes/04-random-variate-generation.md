## 学习本讲之前：随机数和随机变量不是一回事

上一讲研究如何得到质量合格的 `U(0,1)` 伪随机数序列。仿真真正需要的输入，往往是服从其他分布的随机变量，例如指数分布的故障间隔、三角分布的工序时间、正态分布的测量误差、离散分布的需求量。

本讲要解决的是：<strong>已知某个目标分布，如何利用一个或几个独立的均匀随机数，得到服从这一分布的样本。</strong>

| 方法 | 核心思路 | 课件对应位置 | 典型对象 |
| --- | --- | --- | --- |
| 逆变法 | 把均匀数代入目标分布的反分布函数 | 4.1，第 4—12 页 | 均匀、指数、三角分布 |
| 函数变换法 | 对已知分布的随机变量施加函数，推导结果分布 | 4.2，第 13—24 页 | Box–Muller 正态生成 |
| 近似法 | 利用极限定理，用易生成的变量近似目标分布 | 4.3，第 25—26 页 | 近似标准正态 |
| 卷积法 | 将多个独立随机变量相加 | 4.4，第 27—29 页 | 爱尔朗分布 |

| 连续经验分布法 | 对观测值或分组频数构造分段线性分布 | 4.6，第 45—51 页 | 无现成理论分布的数据 |

以下记 `U` 为连续均匀随机变量，`U\sim U(0,1)`。写作 `u=0.3` 时，则表示某次实际生成的随机数取值。`IID` 表示独立同分布（independent and identically distributed）。

## 4.1 逆变法：从分布函数反推随机变量（第 4—12 页）

### 4.1.1 为什么反分布函数可以用来抽样？

设目标随机变量 `X` 的累计分布函数为：

```math
F(x)=P(X\leq x)
```

如果 `F` 连续且严格单调递增，则存在反函数 `F^{-1}`。从 `U(0,1)` 中抽出一个均匀随机数，再令：

```math
X=F^{-1}(U)
```

就能得到目标分布。原因可以直接用概率说明：

```math
\begin{aligned}
P(X\leq x)
&=P(F^{-1}(U)\leq x)\\
&=P(U\leq F(x))\\
&=F(x)
\end{aligned}
```

最后一步成立，是因为对 `0\leq t\leq1`，均匀变量满足 `P(U\leq t)=t`。

这个推导也说明了逆变法的真正含义：<strong>`U` 决定处于分布累计概率的哪个位置，`F^{-1}` 再把这个概率位置映射到具体取值。</strong> 例如，`U=0.8` 生成的是目标分布的第 80 百分位值，不意味着生成值等于 0.8。

如果分布函数有平坦区间、跳跃点或者不严格单调，应使用广义反函数：

```math
F^{-1}(u)=\inf\{x:F(x)\geq u\}
```

广义反函数也能处理离散分布。它是第 4.7 节累计概率抽样法的共同基础。

算法只需两步：先生成独立的 `u_i\sim U(0,1)`，再令 `x_i=F^{-1}(u_i)`。若输入 `u_i` 相互独立，逐项确定性变换后的 `x_i` 也相互独立。

### 4.1.2 均匀分布 `U(a,b)`

设 `a<b`。目标分布的密度和累计分布函数为：

```math
f(x)=
\begin{cases}
\dfrac{1}{b-a},&a\leq x\leq b\\
0,&\text{otherwise}
\end{cases}
```

```math
F(x)=
\begin{cases}
0,&x<a\\
\dfrac{x-a}{b-a},&a\leq x\leq b\\
1,&x>b
\end{cases}
```

令 `u=(x-a)/(b-a)`，解出 `x`，得到抽样公式：

```math
\boxed{X=a+(b-a)U}
```

例如，假设加工时长在 8 到 14 分钟之间服从均匀分布，抽得 `u=0.35`，则：

```math
x=8+(14-8)\times0.35=10.1
```

这次得到的工序时长为 10.1 分钟。应区分参数 `a,b` 是取值范围的端点，而非均值和方差。

### 4.1.3 指数分布 `E(\lambda)`

课件使用<strong>率参数</strong> `\lambda>0`，即 `X\sim E(\lambda)` 的密度与分布函数分别为：

```math
f(x)=
\begin{cases}
\lambda e^{-\lambda x},&x\geq0\\
0,&x<0
\end{cases}
```

```math
F(x)=
\begin{cases}
0,&x<0\\
1-e^{-\lambda x},&x\geq0
\end{cases}
```

将 `u=1-e^{-\lambda x}` 逐步求解：

```math
\begin{aligned}
1-u&=e^{-\lambda x}\\
\ln(1-u)&=-\lambda x\\
x&=-\frac{\ln(1-u)}{\lambda}
\end{aligned}
```

因而：

```math
\boxed{X=-\frac{\ln(1-U)}{\lambda}}
```

由于 `1-U` 仍服从 `U(0,1)`，也常见等分布形式：

```math
X=-\frac{\ln U}{\lambda}
```

这两个公式生成的<strong>边缘分布相同，但对同一个给定 `u` 得到的数值通常不同</strong>。做手算题时，应使用题目规定的那一种；做共同随机数方案比较时，尤其不能随意替换映射关系。

<strong>算例。</strong> 机器故障间隔服从 `E(0.5)`，时间单位为小时，生成 `u=0.75`：

```math
x=-\frac{\ln(1-0.75)}{0.5}
=-\frac{\ln0.25}{0.5}
\approx2.773
```

所得故障间隔是约 2.773 小时。分布的理论均值是 `1/\lambda=2` 小时，不能把某次抽样结果误认为均值。

### 4.1.4 三角分布 `Tri(a,m,b)`

三角分布适合只有最小值、最可能值、最大值等有限信息的工时估计。它的三个参数满足：

```math
a<m<b
```

其中 `a` 是下界，`m` 是密度达到峰值的位置（众数），`b` 是上界。课件给出的密度为：

```math
f(x)=
\begin{cases}
\dfrac{2(x-a)}{(b-a)(m-a)},&a\leq x<m\\
\dfrac{2(b-x)}{(b-a)(b-m)},&m\leq x\leq b\\
0,&\text{otherwise}
\end{cases}
```

对密度积分，得到分段累计分布函数：

```math
F(x)=
\begin{cases}
0,&x<a\\
\dfrac{(x-a)^2}{(b-a)(m-a)},&a\leq x<m\\
1-\dfrac{(b-x)^2}{(b-a)(b-m)},&m\leq x\leq b\\
1,&x>b
\end{cases}
```

首先求众数处的累计概率：

```math
c=F(m)=\frac{m-a}{b-a}
```

这里的 `c` 不是 0.5 的固定值；当三角形左右宽度不对称时，`m` 左侧的概率不一定占一半。

分别对左右两段求反函数，可得抽样公式：

```math
\boxed{
X=
\begin{cases}
a+\sqrt{U(b-a)(m-a)},&0\leq U<c\\
b-\sqrt{(1-U)(b-a)(b-m)},&c\leq U\leq1
\end{cases}
}
```

<strong>算例。</strong> 某工序时间服从 `Tri(2,5,10)`，则：

```math
c=\frac{5-2}{10-2}=\frac{3}{8}=0.375
```

若 `u=0.25<0.375`，使用左侧公式：

```math
x=2+\sqrt{0.25\times8\times3}
=2+\sqrt6\approx4.449
```

若 `u=0.75>0.375`，使用右侧公式：

```math
x=10-\sqrt{0.25\times8\times5}
=10-\sqrt{10}\approx6.838
```

解题时要先计算分支阈值 `c`，再决定用哪个公式，不能看到 `u<0.5` 就默认走左侧。

## 4.2 函数变换法：由已知分布推导新分布（第 13—24 页）

### 4.2.1 一维函数变换的密度公式

设 `X` 的密度为 `f_X(x)`，构造：

```math
Y=g(X)
```

当 `g` 在有关区间严格单调、存在可微反函数 `x=h(y)=g^{-1}(y)` 时，概率密度的变换公式是：

```math
\boxed{
f_Y(y)=f_X(h(y))\left|h'(y)\right|
}
```

<strong>绝对值不能省略。</strong> 当 `g` 递减时，`h'(y)` 可能为负，但概率密度必须非负。课件中的表达式着重展示了变换结构，实际计算应使用导数的绝对值。

如果直接从 `U(0,1)` 出发，`f_U(u)=1`，因此在输出支持集内：

```math
f_Y(y)=\left|\frac{d}{dy}g^{-1}(y)\right|
```

这种方法和逆变法虽然都在“变换随机数”，但求解方向不同：

逆变法先给定目标 `F_Y`，再寻找生成函数 `g=F_Y^{-1}`；函数变换法先选定一个函数 `g`，再计算它产生什么分布。

<strong>例：`Y=U^2` 的分布。</strong> 设 `U\sim U(0,1)`，令 `Y=U^2`。在 `0<y<1` 时，反函数为 `u=\sqrt y`，于是：

```math
f_Y(y)=1\times\left|\frac{d\sqrt y}{dy}\right|
=\frac{1}{2\sqrt y},
\qquad 0<y<1
```

可以用分布函数再次核验：

```math
P(Y\leq y)=P(U^2\leq y)
=P(U\leq\sqrt y)=\sqrt y
```

对 `\sqrt y` 求导，同样得到 `1/(2\sqrt y)`。可见对均匀变量平方后，并不会继续服从均匀分布，反而更容易生成接近 0 的值。

若 `g` 不单调，不能只使用一支反函数。例如 `Y=X^2`、`X\sim N(0,1)` 时，`y>0` 对应 `x=\sqrt y` 与 `x=-\sqrt y` 两个原像，应把各支密度贡献相加：

```math
f_Y(y)=\sum_{x:g(x)=y}\frac{f_X(x)}{|g'(x)|}
```

这个求和公式适用于各个原像局部可逆且导数非零的情形。

### 4.2.2 二维变换与 Jacobian 行列式

课件第 16—17 页把函数变换扩展到两个随机变量。设 `(X_1,X_2)` 具有联合密度 `f_X(x_1,x_2)`，且：

```math
\begin{cases}
Y_1=g_1(X_1,X_2)\\
Y_2=g_2(X_1,X_2)
\end{cases}
```

若存在一一对应的反变换：

```math
\begin{cases}
X_1=h_1(Y_1,Y_2)\\
X_2=h_2(Y_1,Y_2)
\end{cases}
```

则新变量的联合密度为：

```math
f_Y(y_1,y_2)=
f_X(h_1(y_1,y_2),h_2(y_1,y_2))
\left|J\right|
```

其中：

```math
J=
\begin{vmatrix}
\dfrac{\partial x_1}{\partial y_1}&
\dfrac{\partial x_1}{\partial y_2}\\
\dfrac{\partial x_2}{\partial y_1}&
\dfrac{\partial x_2}{\partial y_2}
\end{vmatrix}
```

Jacobian 的几何意义是局部面积的伸缩倍数。概率质量不因坐标变化而增减，但一个小区域的面积会变化，所以密度要乘以相应的面积调整系数。二维正态生成的 Box–Muller 方法正是这种变换的应用。

### 4.2.3 Box–Muller：用两个均匀数生成两个独立正态变量

希望得到两个独立的标准正态随机变量 `Z_1,Z_2\sim N(0,1)`。若它们独立，则联合密度应为：

```math
f(z_1,z_2)=
\frac{1}{2\pi}
\exp\left(-\frac{z_1^2+z_2^2}{2}\right)
```

采用极坐标表示：

```math
Z_1=R\cos\Theta,\qquad
Z_2=R\sin\Theta
```

此时 `z_1^2+z_2^2=R^2`，从笛卡尔坐标变到极坐标的面积因子为 `R`，因此：

```math
\begin{aligned}
f_{R,\Theta}(r,\theta)
&=\frac{r}{2\pi}e^{-r^2/2}\\
&=\left(re^{-r^2/2}\right)
\left(\frac{1}{2\pi}\right),
\quad r>0,\ 0\leq\theta<2\pi
\end{aligned}
```

它分解为两个密度的乘积，说明 `R` 与 `\Theta` 独立。角度均匀分布，`\Theta\sim U(0,2\pi)`；半径的分布函数满足：

```math
P(R\leq r)=1-e^{-r^2/2},
\qquad r\geq0
```

所以可以分别抽取两个独立的均匀数 `U_1,U_2`，令：

```math
\Theta=2\pi U_1,\qquad
R=\sqrt{-2\ln U_2}
```

进而得到 Box–Muller 生成公式：

```math
\boxed{
\begin{aligned}
Z_1&=\sqrt{-2\ln U_2}\cos(2\pi U_1)\\
Z_2&=\sqrt{-2\ln U_2}\sin(2\pi U_1)
\end{aligned}
}
```

两项不仅各自服从标准正态，而且<strong>彼此独立</strong>。判断“是否独立”不能只检查两项都长得像正态；它依靠前面推导的联合密度分解来保证。

<strong>一个可以手算的例子。</strong> 取 `u_1=1/4`、`u_2=e^{-1/2}`，则：

```math
\begin{aligned}
\Theta&=2\pi\times\frac{1}{4}=\frac{\pi}{2}\\
R&=\sqrt{-2\ln(e^{-1/2})}=1\\
z_1&=\cos\frac{\pi}{2}=0\\
z_2&=\sin\frac{\pi}{2}=1
\end{aligned}
```

得到一对正态变量的实现值 `(0,1)`。这个特殊输入仅为手算演示，不代表正态样本总是等于 0 或 1。

如果目标正态分布为 `N(\mu,\sigma^2)`，只需继续线性变换：

```math
X=\mu+\sigma Z,\qquad \sigma>0
```

要注意 `\sigma` 是标准差，`\sigma^2` 才是方差。程序中 `U_2` 不能取到 0，否则 `\ln U_2` 没有有限值；这也是实现此算法时要正确处理随机数取值端点的原因。

## 4.3 近似法：用中心极限定理生成近似正态变量（第 25—26 页）

有些分布的精确生成公式不便直接计算，可以先构造一个计算简单、分布近似相同的随机变量。课件以标准正态分布为例。

若 `U_1,\ldots,U_n` 为独立同分布的 `U(0,1)` 变量，每个变量满足：

```math
E(U_i)=\frac{1}{2},
\qquad
\operatorname{Var}(U_i)=\frac{1}{12}
```

则总和 `S_n=\sum_{i=1}^nU_i` 的均值和方差为：

```math
E(S_n)=\frac{n}{2},
\qquad
\operatorname{Var}(S_n)=\frac{n}{12}
```

中心极限定理表明，当 `n` 足够大时，标准化后的总和近似服从 `N(0,1)`：

```math
\boxed{
Z_n=\frac{\sum_{i=1}^nU_i-n/2}{\sqrt{n/12}}
\ \overset{\mathrm{approx.}}{\sim}\ N(0,1)
}
```

当 `n=12`，计算会特别简单：

```math
\boxed{Z_{12}=\sum_{i=1}^{12}U_i-6}
```

<strong>例。</strong> 如果 12 个均匀数的和为 6.83，就生成近似标准正态取值 `z=0.83`；如果和为 4.25，得到 `z=-1.75`。

这里要区分“均值与方差匹配”和“分布完全相同”。`Z_n` 的均值确实等于 0、方差确实等于 1，但对于有限 `n`，它不可能是精确的标准正态：因为均匀数和有界，`Z_n` 只能落在：

```math
-\sqrt{3n}\leq Z_n\leq\sqrt{3n}
```

而真正的正态分布在整个实数轴上都有正密度。因此，<strong>12 个均匀数相加减 6 是近似正态生成法，不是 Box–Muller 的等价替代</strong>，尤其在研究极端尾部概率时更应注意。

## 4.4 卷积法：相加得到爱尔朗分布（第 27—29 页）

卷积法利用这样一个性质：若有多个独立随机变量，想生成它们的和，就可以先分别生成每一项，再相加。两个独立连续随机变量 `X_1,X_2` 的和 `Y=X_1+X_2`，密度满足：

```math
f_Y(y)=\int_{-\infty}^{+\infty}
f_{X_1}(x)f_{X_2}(y-x)\,dx
```

这个积分称为卷积。课件最主要的应用是爱尔朗分布。

### 4.4.1 爱尔朗分布从哪里来？

若 `X_1,\ldots,X_n` 相互独立，且都服从相同率参数的指数分布 `E(\lambda)`，定义：

```math
Y=X_1+\cdots+X_n
```

则 `Y` 服从 `n` 阶爱尔朗分布 `E_n(\lambda)`。它的密度为：

```math
f_Y(y)=
\begin{cases}
\dfrac{\lambda^n y^{n-1}e^{-\lambda y}}{(n-1)!},&y>0\\
0,&y\leq0
\end{cases}
```

其均值和方差分别为：

```math
E(Y)=\frac{n}{\lambda},
\qquad
\operatorname{Var}(Y)=\frac{n}{\lambda^2}
```

在泊松到达过程中，相邻事件间隔为独立同分布的指数变量，因此等待第 `n` 次事件发生所需的总时间就是爱尔朗分布。这能帮助理解为什么“多个指数等待时间相加”形成了新的分布。

### 4.4.2 卷积法抽样公式

先用逆变法生成每个指数变量：

```math
X_i=-\frac{\ln U_i}{\lambda}
```

于是：

```math
\begin{aligned}
Y&=\sum_{i=1}^nX_i\\
&=-\frac{1}{\lambda}\sum_{i=1}^n\ln U_i\\
&=-\frac{1}{\lambda}\ln\left(\prod_{i=1}^nU_i\right)
\end{aligned}
```

因此课件第 29 页的算法可写为：

```math
\boxed{Y=-\frac{1}{\lambda}\ln(U_1U_2\cdots U_n)}
```

<strong>算例。</strong> 设 `n=3,\lambda=2`，抽到 `u_1=0.5`、`u_2=0.8`、`u_3=0.25`。先求积：

```math
u_1u_2u_3=0.5\times0.8\times0.25=0.1
```

再计算：

```math
y=-\frac{\ln0.1}{2}
=\frac{\ln10}{2}\approx1.1513
```

实现时可以直接累加 `-\ln U_i`，不必真的先乘出 `U_1U_2\cdots U_n`。因为当 `n` 很大时，许多小于 1 的数相乘可能造成计算机浮点下溢。

爱尔朗分布本质上也是 Gamma 分布在形状参数为正整数时的特例。接下来的取舍法可以处理更一般的 Gamma 形状参数。

## 4.5 取舍法：不能方便地反求分布时如何抽样（第 30—44 页）

### 4.5.1 一般接受—拒绝算法

假设要生成目标密度 `f(x)`，但它的分布函数或反函数不容易计算。可以寻找一个容易抽样的覆盖函数 `t(x)`，满足对所有 `x`：

```math
t(x)\geq f(x),\qquad
C=\int_{-\infty}^{+\infty}t(x)\,dx<+\infty
```

由于 `f` 是概率密度，对其积分为 1，因此必有 `C\geq1`。将覆盖函数归一化，得到一个真正的概率密度：

```math
r(x)=\frac{t(x)}{C}
```

现在按下列过程反复尝试：

1. 从易生成的密度 `r(x)` 抽取一个候选值 `X`。
2. 独立生成 `U\sim U(0,1)`。
3. 如果 `U\leq f(X)/t(X)`，接受候选值，令输出 `Y=X`；否则舍弃本次候选，重新从第 1 步开始。

这里的比例 `f(X)/t(X)` 处在 0 和 1 之间，所以能够作为条件接受概率。也可以写成经典形式：若存在常数 `C`，使 `f(x)\leq C r(x)`，则使用接受条件 `U\leq f(X)/(Cr(X))`。

### 4.5.2 为什么被接受的样本服从目标分布？

候选值 `X` 落在 `x` 附近且被接受的密度权重正比于：

```math
r(x)\frac{f(x)}{t(x)}
=\frac{t(x)}{C}\frac{f(x)}{t(x)}
=\frac{f(x)}{C}
```

对全体 `x` 积分可得单次试验的接受概率：

```math
P(\text{accept})=\int\frac{f(x)}{C}\,dx
=\frac{1}{C}
```

再用接受概率归一化，已接受结果的条件密度就是：

```math
f_{Y}(x)=\frac{f(x)/C}{1/C}=f(x)
```

因此取舍法不是“随便扔掉一些样本”；它根据密度比率进行取舍，保证留下的样本服从目标分布。

这也提供了效率指标。若各轮试验相互独立，成功概率为 `1/C`，则平均要抽 `C` 次候选才能得到一个有效样本。<strong>覆盖函数越贴近目标密度、面积 `C` 越小，接受率越高。</strong>

### 4.5.3 Gamma 分布的参数约定

课件使用 `\Gamma(a,b)` 表示形状参数为 `a`、<strong>率参数</strong>为 `b` 的 Gamma 分布，其密度为：

```math
f(x)=
\begin{cases}
\dfrac{b^a}{\Gamma(a)}x^{a-1}e^{-bx},&x>0\\
0,&x\leq0
\end{cases}
\qquad a>0,\ b>0
```

其中 Gamma 函数定义为：

```math
\Gamma(a)=\int_0^\infty t^{a-1}e^{-t}\,dt,
\qquad
\Gamma(a+1)=a\Gamma(a)
```

它允许形状参数 `a` 取非整数值。对于正整数 `n`，有 `\Gamma(n)=(n-1)!`，因此 `\Gamma(n,b)` 与 `n` 阶爱尔朗分布相同。

利用缩放性质，如果已经生成 `X\sim\Gamma(a,1)`，就有：

```math
\boxed{Y=\frac{X}{b}\sim\Gamma(a,b)}
```

所以课件先讨论怎样生成 `\Gamma(a,1)`，最后再除以 `b`。特别注意，有的统计软件采用“形状—尺度”参数化，其第二个参数是 `1/b`；使用软件时需要核对参数定义。

按形状参数分情况，课件中的做法是：

| 形状参数 `a` | 对应方法 |
| --- | --- |
| `a=1` | `\Gamma(1,1)` 即指数分布 `E(1)` |
| `a=n>1` 且 `n` 为整数 | 生成 `n` 个 `E(1)` 变量并相加 |
| `a>1` 且不是整数 | GB 接受—拒绝算法 |
| `0<a<1` | GS 接受—拒绝算法 |

实际中 GB 算法也能用于满足其条件的整数形状参数，但整数情形用卷积法通常更容易手算。

### 4.5.4 `a>1`：GB 算法

这是课件第 36—40 页的重点。GB 算法以一个变换后的覆盖分布生成候选值，再根据条件接受或拒绝。为与课件记号一致，先计算常数：

```math
\begin{aligned}
\lambda&=\sqrt{2a-1}\\
\mu&=a^\lambda\\
\theta&=4.5\\
d&=1+\ln\theta
\end{aligned}
```

使用的建议分布密度和分布函数为：

```math
r(x)=\frac{\lambda\mu x^{\lambda-1}}{(\mu+x^\lambda)^2},
\qquad x>0
```

```math
R(x)=\frac{x^\lambda}{\mu+x^\lambda}
```

对 `R(x)=u` 反解：

```math
\begin{aligned}
u&=\frac{x^\lambda}{a^\lambda+x^\lambda}\\
\frac{u}{1-u}&=\left(\frac{x}{a}\right)^\lambda\\
x&=a\left(\frac{u}{1-u}\right)^{1/\lambda}
\end{aligned}
```

记：

```math
v=\frac{1}{\lambda}\ln\frac{u_1}{1-u_1},
\qquad x=ae^v
```

课件进一步给出了便于计算的接受条件。下面保留全部算法步骤，并说明两个判断各有什么作用。

<strong>GB 计算流程：</strong>

1. 预先计算 `\lambda=\sqrt{2a-1}`、`\theta=4.5`、`d=1+\ln\theta`。
2. 生成独立的 `u_1,u_2\sim U(0,1)`，并计算：

```math
\begin{aligned}
v&=\frac{1}{\lambda}\ln\frac{u_1}{1-u_1}\\
x&=ae^v\\
z&=u_1^2u_2\\
w&=(a+\lambda)v+a-\ln4-x
\end{aligned}
```

3. 如果 `w+d-\theta z\geq0`，直接接受，输出 `y=x`。
4. 如果上一步没有通过，再检查 `\ln z\leq w`。若成立，接受 `y=x`；否则舍弃这次 `u_1,u_2`，返回第 2 步。

第 4 步相当于完整的密度比检验；第 3 步是<strong>快速接受检验</strong>。一旦它成立，就能确定完整检验也会通过，因此不用继续计算 `\ln z`。但如果第 3 步不成立，不能立刻拒绝，仍需执行第 4 步。

GB 算法中的 `\lambda` 只是中间计算常数，不是前文指数分布的率参数；即使复用了同一个希腊字母，也不能混淆。

<strong>计算细节。</strong> 算式 `\ln(u_1/(1-u_1))` 需要 `0<u_1<1`，因此实现时应保证端点不会造成对数零或除零；表达式中 `z=u_1^2u_2` 为正。接受一个 `x` 后，若题目要求的分布是 `\Gamma(a,b)`，最后还要输出 `x/b`。

### 4.5.5 `0<a<1`：GS 算法

对于小于 1 的形状参数，目标 Gamma 密度在零点附近变化剧烈，课件第 41—44 页改用分段覆盖函数。先计算：

```math
\boxed{b_0=\frac{e+a}{e}=1+\frac{a}{e}}
```

这里暂用 `b_0` 记覆盖分布的常数，以免和目标分布 `\Gamma(a,b)` 的率参数 `b` 混淆。

覆盖函数设为：

```math
t(x)=
\begin{cases}
\dfrac{x^{a-1}}{\Gamma(a)},&0<x\leq1\\
\dfrac{e^{-x}}{\Gamma(a)},&x>1\\
0,&x\leq0
\end{cases}
```

其积分为：

```math
C=\int_0^\infty t(x)\,dx
=\frac{1}{a\Gamma(a)}
+\frac{1}{e\Gamma(a)}
=\frac{b_0}{a\Gamma(a)}
```

将 `t(x)` 除以 `C`，得到候选密度：

```math
r(x)=
\begin{cases}
\dfrac{a}{b_0}x^{a-1},&0<x\leq1\\
\dfrac{a}{b_0}e^{-x},&x>1\\
0,&x\leq0
\end{cases}
```

相应的分布函数为：

```math
R(x)=
\begin{cases}
0,&x\leq0\\
\dfrac{x^a}{b_0},&0<x\leq1\\
1-\dfrac{a}{b_0}e^{-x},&x>1
\end{cases}
```

反求 `R^{-1}(u)`，可以得到两个候选值公式。课件使用 `z=b_0u_1` 来判断落在哪一段，因此算法如下。

<strong>GS 计算流程：</strong>

1. 计算 `b_0=1+a/e`；生成两个相互独立的 `u_1,u_2\sim U(0,1)`。
2. 令 `z=b_0u_1`。
3. 若 `z\leq1`，计算 `x=z^{1/a}`。当 `u_2\leq e^{-x}` 时接受 `y=x`，否则重新抽样。
4. 若 `z>1`，计算 `x=-\ln((b_0-z)/a)`。当 `u_2\leq x^{a-1}` 时接受 `y=x`，否则重新抽样。

第 3 步之所以检查 `e^{-x}`，是因为在 `0<x\leq1` 这段，`f(x)/t(x)=e^{-x}`；第 4 步之所以检查 `x^{a-1}`，是因为在 `x>1` 这段，`f(x)/t(x)=x^{a-1}`。

这两段的检验条件不是随意设计的，而是严格来自 `f(x)/t(x)`。若最后要生成 `\Gamma(a,b)`，仍需将被接受的 `y` 除以目标率参数 `b`。

课件中的 GB 和 GS 部分公式涉及覆盖分布、阈值、分支以及额外的快速接受判据。复习时至少要能够解释：<strong>从哪里抽候选值、为什么要拒绝一部分样本、怎样比较接受概率、怎样处理 `a` 的不同取值。</strong>

## 4.6 连续经验分布抽样：没有理论分布时怎么办？（第 45—51 页）

前几节假定已经知道一个目标理论分布，例如指数、正态或 Gamma。实际仿真中有时只有历史数据，无法确定某个理论分布是否合适。此时可以直接用观测数据构造经验分布，再进行抽样。

课件讨论两种数据组织形式：<strong>已知每条原始观测值</strong>与<strong>只知道各区间的分组频数</strong>。两者都是分段线性逆变，但分段的依据不同。

### 4.6.1 已知原始观测值：按相邻排序值插值

设有 `n` 个历史观测值，先从小到大排序：

```math
x_{(1)}\leq x_{(2)}\leq\cdots\leq x_{(n)}
```

课件使用的<strong>连续插值型经验分布</strong>，将每个排序点对应的累计概率设为：

```math
F(x_{(i)})=\frac{i-1}{n-1},
\qquad i=1,\ldots,n
```

在相邻的两个排序值之间用直线连接：

```math
F(x)=\frac{i-1}{n-1}
+\frac{x-x_{(i)}}{(n-1)(x_{(i+1)}-x_{(i)})},
\quad x_{(i)}\leq x<x_{(i+1)}
```

在最小值左侧设 `F(x)=0`，最大值及其右侧设 `F(x)=1`。这样会得到由若干直线段组成的连续分布函数。

注意，这与统计学中常用的阶梯式经验分布函数 `F_n(x)=\#\{X_i\leq x\}/n` 并非完全相同。这里特意<strong>在相邻数据值之间插值</strong>，目的是生成连续变量，而不是每次只从原始观测值中抽一个已有的数。

<strong>抽样步骤。</strong> 先抽 `u\sim U(0,1)`，找到一个序号 `i`，使：

```math
\frac{i-1}{n-1}\leq u<\frac{i}{n-1},
\qquad i=1,\ldots,n-1
```

随后求该段的反函数：

```math
\boxed{
x=x_{(i)}
+\left[(n-1)u-(i-1)\right]
\left(x_{(i+1)}-x_{(i)}\right)
}
```

<strong>算例。</strong> 四个按升序排列的历史加工时间为 2、4、7、9 分钟。抽到 `u=0.5`。由于 `n=4`，有：

```math
\frac{1}{3}\leq0.5<\frac{2}{3}
```

所以 `i=2`，在第二个和第三个数据之间插值：

```math
\begin{aligned}
x&=4+\left[3\times0.5-(2-1)\right](7-4)\\
&=4+0.5\times3=5.5
\end{aligned}
```

生成值为 5.5 分钟，即使原始观测中没有 5.5，也能通过插值得到这个数。

适用前提值得注意：如果很多观测值重复，某些相邻区间长度为零，就不能简单套用带有 `x_{(i+1)}-x_{(i)}` 分母的密度表达式；应对重复值或零长度区间另作处理。课件这种连续插值法更适合连续测量数据。

### 4.6.2 已知分组频数：按累计频率选择区间

如果没有原始数据，只知道数据落在各个分组区间的频数，可以先将数据范围划分为：

```math
[a_0,a_1),\ [a_1,a_2),\ \ldots,\ [a_{m-1},a_m]
```

课件以等长区间讲解，记第 `i` 组的频数为 `n_i`，总样本数为：

```math
n=\sum_{i=1}^{m}n_i
```

定义前 `i` 组的累计频数：

```math
N_i=\sum_{k=1}^{i}n_k,\qquad N_0=0
```

若假定各组内部按均匀密度分布，则在 `[a_{i-1},a_i)` 内有：

```math
F(x)=\frac{N_{i-1}}{n}
+\frac{n_i}{n}\frac{x-a_{i-1}}{a_i-a_{i-1}}
```

也就是先累计前面各组的概率，再按照本组内的位置线性增加。

<strong>抽样步骤。</strong> 生成 `u\sim U(0,1)`，找到满足以下条件的组号 `i`：

```math
\frac{N_{i-1}}{n}\leq u<\frac{N_i}{n}
```

再反解：

```math
\boxed{
x=a_{i-1}
+\frac{nu-N_{i-1}}{n_i}
(a_i-a_{i-1})
}
```

对于 `n_i=0` 的空组，累计概率不增加，不会被具有正概率的均匀样本选中；算法应跳过空组，避免除以零。

<strong>算例。</strong> 某作业时间有如下分组频数：

| 时间区间（分钟） | 频数 | 累计频数 | 累计概率 |
| --- | ---: | ---: | ---: |
| [0,10) | 2 | 2 | 0.2 |
| [10,20) | 3 | 5 | 0.5 |
| [20,30] | 5 | 10 | 1.0 |

总数 `n=10`。假设抽到 `u=0.38`，由于 `0.2\leq0.38<0.5`，落入第 2 组。此时 `a_1=10`、`a_2=20`、`N_1=2`、`n_2=3`，故：

```math
\begin{aligned}
x&=10+\frac{10\times0.38-2}{3}(20-10)\\
&=10+\frac{1.8}{3}\times10\\
&=16
\end{aligned}
```

结果是 16 分钟。如果只按组频率抽取区间后固定使用“组中值 15”，就失去了课件要求的组内连续抽样效果。

虽然课件选用等宽组，以上分段插值公式在组宽不同时也成立，只要正确使用每组各自的宽度 `a_i-a_{i-1}`。

## 4.7 离散经验分布抽样（第 52—55 页）

如果 `X` 只可能取有限个离散值，例如某天需要 0、1、2、3 台设备，或者订单属于四种类型，就不需要连续插值。

设离散取值为 `x_1<x_2<\cdots<x_n`，对应概率满足：

```math
P(X=x_i)=p_i,\qquad
p_i\geq0,\qquad
\sum_{i=1}^np_i=1
```

定义累计概率：

```math
P_i=\sum_{k=1}^{i}p_k,\qquad P_0=0
```

抽取一个 `u\sim U(0,1)`，选择首个满足 `u\leq P_i` 的序号 `i`，令 `X=x_i`。等价地，对 `i\geq2` 可以用区间：

```math
P_{i-1}<u\leq P_i
```

<strong>算例。</strong> 某种零件的日需求分布如下：

| 日需求 `x_i` | 概率 `p_i` | 累计概率 `P_i` | 均匀数对应区间 |
| --- | ---: | ---: | --- |
| 10 | 0.20 | 0.20 | `0<u\leq0.20` |
| 20 | 0.50 | 0.70 | `0.20<u\leq0.70` |
| 30 | 0.30 | 1.00 | `0.70<u<1` |

若 `u=0.62`，有 `0.20<0.62\leq0.70`，因此生成 `X=20`。若 `u=0.91`，则生成 `X=30`。

概率解释很直接：`U` 落在区间 `(0.20,0.70]` 的概率为 0.50，因此值 20 正好以 0.50 的概率被抽中。对于连续均匀数，单个端点的概率为零，区间端点采用开闭形式不会改变目标概率，但写程序时应统一约定以避免遗漏。

如果某些 `p_i=0`，其累计区间长度为零，相应取值自然不会被抽中。若取值数量很多，可以通过累计概率表或二分查找提高查询效率，但原理仍是课件的“累计概率分段”。

## 4.8 七类方法如何选择？

理解各方法之间的关系，比机械记忆七套公式更重要。

| 已知信息或条件 | 优先考虑的方法 | 关键检查 |
| --- | --- | --- |
| 能求出目标分布函数及其反函数 | 逆变法 | 参数定义、支持集、分支条件 |
| 已知某些基础变量，经函数组合恰好产生目标分布 | 函数变换法 | 逆变换是否单值、Jacobian 绝对值 |
| 接受一定的分布近似误差 | 近似法 | 样本数及尾部误差 |
| 目标分布是独立变量的和 | 卷积法 | 独立性及各分量参数是否相同 |
| 目标密度易算，但反函数难求 | 取舍法 | 覆盖条件 `t\geq f`、接受率、拒绝循环 |
| 有连续原始数据，没有选定的理论分布 | 连续经验分布法 | 排序、累计位置、插值和重复值 |
| 只有连续变量的分组频数 | 分组连续经验分布法 | 累计频数、组内插值、空组 |
| 已知离散概率表 | 离散经验分布法 | 概率和为 1、累计区间无遗漏 |

这几种方法并非彼此排斥。例如，Box–Muller 生成标准正态时，既使用了函数变换与二维 Jacobian，也在过程中使用逆变法生成角度与半径；爱尔朗分布由卷积法生成，而每个指数分量又由逆变法生成。

## 4.9 课件内容对应的完整练习

以下练习是为理解课件方法而补充的演示题，不是原课件现成试题。采用“题目—答案—完整过程”的形式，适合直接用于笔记复习。

### 例题 1：指数分布逆变

<strong>题目：</strong> 已知故障间隔 `X\sim E(0.25)`，采用 `X=-\ln(1-U)/\lambda`。当 `u=0.6` 时，生成值是多少？

<strong>答案：</strong> `x\approx3.665`，时间单位与 `1/\lambda` 对应。

<strong>解析：</strong> 率参数为 `\lambda=0.25`，先求 `1-u=0.4`，再代入：

```math
x=-\frac{\ln0.4}{0.25}
\approx3.6652
```

这里的理论平均间隔为 `1/\lambda=4`，与单次生成结果 3.665 不同。

### 例题 2：三角分布先判分支

<strong>题目：</strong> `X\sim Tri(0,2,6)`，给定 `u=0.25`。求 `x`。

<strong>答案：</strong> `x=\sqrt3\approx1.732`。

<strong>解析：</strong> 先计算：

```math
c=\frac{2-0}{6-0}=\frac{1}{3}
```

因为 `0.25<1/3`，选择左侧：

```math
x=0+\sqrt{0.25\times6\times2}
=\sqrt3
```

最常见的错误是未经计算 `c` 就按 `u` 是否小于 0.5 决定分支。

### 例题 3：函数变换后的密度

<strong>题目：</strong> `U\sim U(0,1)`，令 `Y=1-U`。求 `Y` 的密度；再比较 `Y=U^2` 的情况。

<strong>答案：</strong> `1-U\sim U(0,1)`；`U^2` 的密度在 `0<y<1` 上为 `1/(2\sqrt y)`。

<strong>解析：</strong> `Y=1-U` 的反函数为 `u=1-y`，反函数导数为 `-1`，取绝对值得 1。对于 `Y=U^2`，反函数导数为 `1/(2\sqrt y)`，因此不是均匀分布。这个例题专门提醒：函数变换必须计算密度，不能只凭输入是均匀数就判断输出仍均匀。

### 例题 4：Box–Muller 正态生成

<strong>题目：</strong> 取 `u_1=1/2`、`u_2=e^{-2}`，生成一对标准正态实现值。

<strong>答案：</strong> `(z_1,z_2)=(-2,0)`。

<strong>解析：</strong>

```math
\begin{aligned}
R&=\sqrt{-2\ln(e^{-2})}=2\\
\Theta&=2\pi\times\frac{1}{2}=\pi\\
z_1&=2\cos\pi=-2\\
z_2&=2\sin\pi=0
\end{aligned}
```

注意输入的是两个相互独立的均匀数；`z_1,z_2` 的独立性来自生成算法本身。

### 例题 5：爱尔朗分布由指数变量相加

<strong>题目：</strong> 生成一个 `E_2(2)` 随机变量，给定 `u_1=0.5`、`u_2=0.25`。

<strong>答案：</strong> `y=\ln8/2\approx1.040`。

<strong>解析：</strong>

```math
y=-\frac{\ln(0.5\times0.25)}{2}
=-\frac{\ln0.125}{2}
=\frac{\ln8}{2}
```

两次指数间隔的率参数相同，且要彼此独立；不能把“二阶爱尔朗”误解为在一个指数抽样值上平方。

### 例题 6：取舍法的接受率

<strong>题目：</strong> 某取舍法所用覆盖函数为 `t(x)=2.5r(x)`，已知 `r` 是概率密度且对全部 `x` 满足 `t(x)\geq f(x)`。求单次候选的接受概率与平均尝试次数。

<strong>答案：</strong> 接受概率 0.4，平均尝试 2.5 次。

<strong>解析：</strong>

```math
P(\text{accept})=\frac{1}{C}=\frac{1}{2.5}=0.4
```

尝试次数服从成功概率为 0.4 的几何分布，期望为 `1/0.4=2.5`。这里 2.5 次是长期平均，不代表一定在第三次成功。

### 例题 7：连续分组经验分布

<strong>题目：</strong> 三组区间分别为 `[0,10)`、`[10,20)`、`[20,30]`，频数分别为 2、3、5，给定 `u=0.38`，求连续经验分布的生成值。

<strong>答案：</strong> 16。

<strong>解析：</strong> 累计概率为 0.2、0.5、1，因此选中第二组。在第二组内的相对位置为：

```math
\frac{0.38-0.2}{0.5-0.2}=0.6
```

于是：

```math
x=10+0.6(20-10)=16
```

这与前面的累计频数反解公式一致。

### 例题 8：离散经验分布

<strong>题目：</strong> `P(X=1)=0.1`、`P(X=2)=0.6`、`P(X=3)=0.3`。当 `u=0.70` 时取何值？

<strong>答案：</strong> 按课件 `P_{i-1}<u\leq P_i` 的约定，取 `X=2`。

<strong>解析：</strong> 累计概率为 0.1、0.7、1.0。因为 `0.1<0.70\leq0.7`，选择第二项。`u=0.70` 正好落在边界上，因此要使用明确的端点规则。对于理想连续均匀数，精确取到一个指定边界的概率为零，但手算题可能故意给出边界值来考查定义。

## 本讲速查公式

| 目标 | 生成公式 | 需要的独立均匀数 |
| --- | --- | --- |
| `U(a,b)` | `a+(b-a)U` | 1 个 |
| 指数 `E(\lambda)` | `-\ln(1-U)/\lambda` | 1 个 |
| `Tri(a,m,b)` | 根据 `U<(m-a)/(b-a)` 选平方根分支 | 1 个 |
| 精确标准正态 | `\sqrt{-2\ln U_2}\cos(2\pi U_1)` 与对应 `\sin` 项 | 2 个生成 2 个 |
| 近似标准正态 | `(\sum U_i-n/2)/\sqrt{n/12}` | `n` 个 |
| 爱尔朗 `E_n(\lambda)` | `-\ln(\prod U_i)/\lambda` | `n` 个 |
| Gamma `\Gamma(a,b)` | 依 `a` 选指数、卷积、GB 或 GS，再除以 `b` | 随算法变化 |
| 原始值构造的连续经验分布 | 在相邻排序值间做线性插值 | 1 个 |
| 分组频数构造的连续经验分布 | 先选组，再按组内累计概率插值 | 1 个 |
| 离散经验分布 | 找到累计概率首次不小于 `U` 的取值 | 1 个 |

<strong>本讲和第三讲的关系：</strong> 第三讲检验均匀随机数序列是否合格，第四讲把这些均匀数转换为仿真模型所需的分布。输入的随机数质量不合格，后续再精确的变换公式也无法自动修复它。至于变换后生成的数据是否符合指定分布，还可通过样本均值、方差、直方图、卡方或 K–S 检验作输出核验；这属于对生成算法的实证检验，与本讲的数学推导相互补充。
